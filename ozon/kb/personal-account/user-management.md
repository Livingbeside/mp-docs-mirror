# Управление доступами сотрудников в личном кабинете

_Главная / Настройки личного кабинета_

Какие роли есть в личном кабинете, как выдать доступ сотрудникам, изменить роль или отозвать приглашение

Вы можете дать доступ к личному кабинету любому количеству сотрудников своей компании. Для этого нужно создать учетную запись и назначить сотруднику роль, которая определяет доступные разделы личного кабинета.

# Какие бывают роли в личном кабинете

Доступ пользователей в разделы личного кабинета и функционал зависит от назначенной ему роли.

Чтобы у сотрудника был максимальный доступ ко всем разделам и функционалу, назначьте ему роль **Администратор **или **Управляющий**. Эти роли похожи, но у управляющего больше полномочий: такой сотрудник является создателем и владельцем личного кабинета, может менять реквизиты, удалить магазин, расторгнуть договор.

Роль **Технологический партнер **нельзя назначить — вы её увидите, только если подключали магазин через партнёра Ozon. Партнёрская программа закрыта с 5 июля 2023 года, но вы можете продолжить работу с партнёром согласно вашим договоренностям.

# Как работать с учётной записью сотрудника

## Как создать учётную запись сотрудника

Это может сделать сотрудник с ролью **Управляющий **или **Администратор**. Для этого:

1. Откройте раздел **[Настройки → Сотрудники](https://seller.ozon.ru/app/settings/employees)**.
2. Нажмите **Пригласить сотрудника**.
3. В открывшемся окне укажите электронную почту сотрудника и его права доступа и нажмите **Пригласить**.
4. На указанную почту отправим письмо со ссылкой для активации аккаунта — она действует 24 часа. Когда приглашение будет принято, на вкладке **Сотрудники** появится новая запись со статусом **Активен**. [Какие ещё статусы бывают](#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B-%D0%BF%D1%80%D0%B8%D0%B3%D0%BB%D0%B0%D1%88%D0%B5%D0%BD%D0%B8%D0%B8-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82)
  Если за сутки сотрудник не успеет перейти по ссылке, вышлите новое приглашение.
5. На вкладке **История приглашений** появится новая запись со статусом **Отправлено**. [Подробнее о том, как посмотреть историю приглашений](#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B-%D0%BF%D1%80%D0%B8%D0%B3%D0%BB%D0%B0%D1%88%D0%B5%D0%BD%D0%B8%D0%B8-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82)
  Приглашение можно отменить, пока оно не принято. [Как отозвать приглашение](#%D0%BA%D0%B0%D0%BA-%D0%BE%D1%82%D0%BE%D0%B7%D0%B2%D0%B0%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%B3%D0%BB%D0%B0%D1%88%D0%B5%D0%BD%D0%B8%D0%B5)

Если сотрудник не получил письмо об активации аккаунта, проверьте:

папку **Спам**;

ошибки в email — при неверной почте нужно создать новую учетную запись, а аккаунт с неправильным адресом удалить.

Если ни один из вариантов не помог, напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Личный кабинет → Настройка личного кабинета → Авторизация в ЛК → Добавить сотрудника**. Мы проверим информацию и поможем с активацией.

## Как изменить роль сотрудника

Это может сделать сотрудник с ролью **Управляющий **или **Администратор**. Для этого:

1. Откройте раздел **[Настройки → Сотрудники](https://seller.ozon.ru/app/settings/employees)**.
2. Найдите нужного сотрудника — можно воспользоваться поиском по имени, роли или статусу.
3. Нажмите на роль сотрудника.
4. Выберите новую роль.

## Как назначить роль аналитика

В Premium-подписке аналитика доступна только сотрудникам с ролью **Аналитик** — такую роль можно назначить двум сотрудникам, у которых есть есть любая роль из [таблицы](/personal-account/user-management#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82-%D1%80%D0%BE%D0%BB%D0%B8-%D0%B2-%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D0%BC-%D0%BA%D0%B0%D0%B1%D0%B8%D0%BD%D0%B5%D1%82%D0%B5). Добавить сотрудника только с ролью **Аналитик** не получится.

По умолчанию одна из ролей **Аналитик** назначена на **Управляющего**, а вторая не назначена ни на кого. Вот как назначить роль — сделать это может только **Управляющий**:

1. Выберите нужного сотрудника и нажмите на его роль или **⋮ → Изменить роль**.
2. Проставьте галочку в поле **Аналитик** — доступ к аналитике у сотрудника появится сразу же.

Если вы **Управляющий** и хотите снять с себя роль **Аналитик**, чтобы передать другому сотруднику, нажмите на свою роль (или **⋮ → Изменить роль**) и уберите галочку в поле **Аналитик**, а затем назначьте роль нужному сотруднику.

Если поле **Аналитик** в списке ролей недоступно, проверьте, что хотя бы одна из ролей свободна. Отсортируйте только сотрудников с ролью **Аналитик: **если роль уже есть у двух сотрудников, назначить её третьему не получится — сначала нужно снять роль с одного из сотрудников. Или оформите [подписку Premium Plus](/seller-rating/about-rating/subscription-premium-plus), чтобы неограниченный доступ к аналитике был у всей вашей команды.

## Как удалить учётную запись сотрудника

Это может сделать сотрудник с ролью **Управляющий **или **Администратор**. Для этого:

1. Перейдите на страницу **[Настройки → Сотрудники](https://seller.ozon.ru/app/settings/employees)**.
2. Найдите нужного сотрудника — можно воспользоваться поиском по имени, роли или статусу.
3. Нажмите **⋮** в строке сотрудника и выберите **Удалить пользователя**.
4. Нажмите **Подтвердить**.

Если хотите удалить сотрудника с правами управляющего, сначала передайте его права другому сотруднику. Передать права может только сотрудник с ролью **Управляющий**. [Как это сделать](#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%82%D1%8C-%D0%BF%D1%80%D0%B0%D0%B2%D0%B0-%D1%83%D0%BF%D1%80%D0%B0%D0%B2%D0%BB%D1%8F%D1%8E%D1%89%D0%B5%D0%B3%D0%BE-%D0%B4%D1%80%D1%83%D0%B3%D0%BE%D0%BC%D1%83-%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8E)

## Как передать права управляющего другому пользователю

Выдать роль **Управляющий **другому сотруднику может только действующий управляющий.

Для этого под учётной записью управляющего:

1. Откройте раздел **[Настройки → Сотрудники](https://seller.ozon.ru/app/settings/employees)**.
2. Найдите нужного сотрудника — можно воспользоваться поиском по имени, роли и статусу.
3. Нажмите **⋮** в строке сотрудника и выберите **Изменить роль**.
4. Поставьте галочку напротив роли  и нажмите **Подтвердить**.

Чтобы передать права управляющего новому сотруднику:

1. [Создайте учётную запись](/personal-account/user-management#%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%83%D1%87%D1%91%D1%82%D0%BD%D1%83%D1%8E-%D0%B7%D0%B0%D0%BF%D0%B8%D1%81%D1%8C-%D1%81%D0%BE%D1%82%D1%80%D1%83%D0%B4%D0%BD%D0%B8%D0%BA%D0%B0) с любой ролью.
2. Когда новый сотрудник активирует аккаунт, найдите его в разделе **Настройки → Сотрудники** и передайте ему права по алгоритму выше.

Если вы случайно передали права не тому сотруднику, их можно отозвать. Для этого ответьте на письмо, которое мы пришлём на почту прежнего управляющего сразу после назначения нового. Тогда мы вернём прежнего управляющего, а до этого момента заблокируем личный кабинет.

## Какие статусы приглашений бывают

На вкладке **Сотрудники**:

**Активен** — у пользователя есть доступ в личный кабинет;

**Не активирован** — пользователь не перешёл по ссылке в письме-приглашении.

На вкладке **История приглашений**:

**Отправлено** — пользователю отправлено приглашение;

**Принято** — пользователь перешёл по ссылке в письме и у него есть доступ в личный кабинет;

**Отозвано** — приглашение отменили до того, как пользователь ответил на него.

## Как посмотреть историю всех приглашений

1. Перейдите на страницу **[Настройки → Сотрудники](https://seller.ozon.ru/app/settings/employees)**.
2. Откройте вкладку **История приглашений**.

В истории можно:

посмотреть все приглашения, которые отправляли сотрудники магазина;

[отменить те, которые ещё не приняты](#как-отозвать-приглашение) — для этого нажмите **⋮** и выберите **Отозвать приглашение**;

найти нужное по адресу электронной почты;

отфильтровать по роли;

отправить приглашение.

Для каждого приглашение покажем:

кто его отправил;

какая роль предложена;

статус — приглашение может быть принято, отклонено или отозвано;

email, на которое отправлено письмо;

дату приглашения.

Можно найти нужное приглашение по имени или отфильтровать по роли.

## Как отозвать приглашение

Это может сделать только пользователь с ролью **Управляющий **или **Администратор**, если на приглашение ещё не ответили или прошло менее 24 часов с момента отправки.

1. Перейдите на страницу **[Настройки → Сотрудники](https://seller.ozon.ru/app/settings/employees)**.
2. Откройте вкладку **История приглашений**.
3. Нажмите **⋮** в нужной строке, а затем — **Отозвать приглашение**.
4. Подтвердите действие.

Ссылка, которая отправлена в письме, станет неактивной — по ней нельзя будет получить доступ в личный кабинет.

## Сколько действует ссылка в приглашении

24 часа. Если не успели перейти по ссылке, попросите выслать новое приглашение — это может сделать сотрудник с ролью **Управляющий** или **Администратор**.

# Какие данные доступны курьерам и сборщикам

Роли **Курьер**, **Сборщик **и **Сборщик-курьер **доступны продавцам на схемах FBO, FBS и realFBS.

Сотрудники с такими ролями могут работать в личном кабинете только через приложение Ozon Seller. Они увидят разделы:

главная — скрыта вся информация, кроме количества заказов и возвратов в разных статусах;

заказы — только часть данных;

возвраты — только часть данных.

Роли **Курьер**, **Сборщик **и **Сборщик-курьер **можно назначить любому количеству сотрудников. Для этого создайте новые учётные записи и укажите для них нужные роли. [Подробнее о том, как создать учётную запись](/personal-account/user-management?search=%D1%80%D0%BE%D0%BB%D0%B8#%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%83%D1%87%D1%91%D1%82%D0%BD%D1%83%D1%8E-%D0%B7%D0%B0%D0%BF%D0%B8%D1%81%D1%8C-%D1%81%D0%BE%D1%82%D1%80%D1%83%D0%B4%D0%BD%D0%B8%D0%BA%D0%B0)

## Роль «Курьер»

Роль доступна продавцам, которые работают по схемам FBO, FBS и realFBS. Курьер может работать в личном кабинете только через приложение Ozon Seller.

Какие разделы приложения видит сотрудник с такой ролью:
