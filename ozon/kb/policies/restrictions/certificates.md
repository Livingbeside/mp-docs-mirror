# Разрешено продавать после проверки документов качества

_Главная / Правила работы и контроль качества / Продажа товаров — что разрешено и запрещено_

В каких категориях нельзя продавать товары без документов качества, например, БАДы, пестициды и другие

Документы качества нужны для большинства товаров, кроме [категорий, где их не требуем](https://seller-edu.ozon.ru/policies/documents-violations/sertifikaty-kachestva#для-каких-категории-документы-не-запрашиваем). Продавать такие товары можно только после проверки и одобрения документов. В большинстве категорий вы сами определяете, какой документ подходит для вашего товара. ### Особенности продажи тестов на COVID-19

Если в инструкции к тесту в разделе «Назначение» указано:

для диагностики «in vitro» — такие товары можно продавать только юридическим лицам;

для самотестирования / использование товаров в домашних условиях — такие тесты могут приобрести любые покупатели.

В связи с этим оставляем за собой право определять товары, которые будут доступны к продаже только юридическим лицам, на основании информации из инструкции.
