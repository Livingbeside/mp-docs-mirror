# Начало работы с Seller API

_Главная / API Ozon и интеграции_

Как с помощью Seller API настроить интеграцию с вашими системами учёта и автоматизировать работу на площадке

Когда заказов и товаров становится много, продавцу приходится чаще вводить однотипные данные в личном кабинете. Загрузка карточек, работа с ценами, обновление остатков — на всё это нужно время. Чтобы автоматизировать этот процесс, можно использовать Ozon Seller API — он поможет загружать большие объёмы данных напрямую из ваших систем учёта.

Дальше расскажем — что такое Seller API, как с его помощью автоматизировать процесс работы на площадке и настроить интеграцию с вашими системами учёта.

Создали платформу [Ozon for dev](https://dev.ozon.ru/) для специалистов, которые работают с API и разрабатывают интеграции Ozon с другими продуктами. На ней:

размещаем новости API-продуктов Ozon — рассказываем об обновлениях, доработках и новых инструментах;

собираем практические кейсы и гайды по API. Например, как установить и отредактировать цены, обновить остатки, посмотреть отчёты и пояснения к кодам ошибок при выполнении разных операций и другие вопросы;

анонсируем ближайшие мероприятия и вебинары.

Задать вопросы, пообщаться с коллегами и представителями Ozon можно на [форуме](https://dev.ozon.ru/community).

# Что такое Seller API

API (Application Programming Interface) — программный интерфейс, некая надстройка над программой, которая позволяет другим системам с ней взаимодействовать без прямого доступа к коду. Простыми словами, это посредник между двумя несвязанными системами.

Seller API — это программный интерфейс, который передаёт информацию от системы продавца к системе Ozon и обратно. То есть, чтобы внести в Ozon информацию о товарах, вам достаточно интегрировать Seller API в свою систему и передавать данные через неё.

Seller API работает на HTTP-протоколе, следуя архитектурным принципам REST API. Для безопасности используется аутентификация через API-ключи, которые подтверждают подлинность запросов, и шифрование данных с помощью SSL/TLS, чтобы защитить данные от несанкционированного доступа.

[Документация Ozon Seller API](https://docs.ozon.ru/api/seller/)

# В чём преимущества Seller API

Основное преимущество Seller API — в автоматизации процессов. Продавцу не нужно искать карточки товаров и редактировать каждую в отдельности. Это позволит сэкономить время и направить его на развитие бизнеса.

Другой плюс автоматизации — сокращение ошибок. Поскольку данные загружаются сами, риск ввести неправильную команду сильно сокращается. Если обновлять остатки или загружать карточки у 10 000 единиц товара вручную, это займёт десятки человеко-часов, а с помощью API — всего несколько секунд. Так как самих операций тоже становится меньше, нагрузка на сотрудников продавца тоже снижается.

Благодаря Seller API, продавец может реже заходить в [Личный кабинет](https://seller.ozon.ru/app/settings/) Ozon. Вместо этого, он может работать в привычных для вас программах и системах учёта. Это тоже позволяет ускорить обработку данных и снизить нагрузку на сотрудников.

# Что нужно учесть перед подключением

Прежде чем запустить Seller API, нужно понять, как у вас устроены бизнес-процессы и ваша система учёта товаров. Если вы подключены к одной из таких программ и она собирает все данные о товарах и сделках, значит, ее можно подключить к Seller API.

Далее продавцу нужно узнать, как устроены бизнес-процессы Ozon: например, какие документы нужны на товары или как проходит модерация. Подробности можно узнать в нашей [Базе знаний](/).

На работу с API также влияет и ваша схема продаж на Ozon. Если вы продаёте со склада маркетплейса по **FBO**, вам нужно только добавлять товары и проверять их характеристики. Продавец может проверить статусы отправлений или скачать отчёты о движении товаров. Обновлять остатки на этой схеме не нужно, так как их учитывает система Ozon. Если же вы продаёте со своего склада по **realFBS** или **FBS**, то обновление остатков можно оптимизировать как раз через Seller API. Помимо этого, вы можете выгружать список всех складов и обновлять статусы отправлений.

# Как получить API-ключ

После регистрации в [Ozon Seller](https://seller.ozon.ru/app/signup) создайте свой уникальный API-ключ. Для этого:

1. Нажмите  в правом верхнем углу личного кабинета и выберите **Настройки**.
2. Перейдите в раздел **[Seller API](https://seller.ozon.ru/app/settings/api-keys)**.
3. Нажмите **Сгенерировать ключ**.
4. В открывшемся окне:
  укажите название для одного или нескольких API-ключей;
  
  выберите цель использования ключа;
  
  если ключ для внешнего сервиса, укажите его название — делитесь API-ключом только с проверенными сервисами;
  
  выберите роль — для большей безопасности каждый API-ключ может использовать только определённые методы в зависимости от выбранной роли. После создании ключа проверьте доступные роли в разделе [Seller API](https://seller.ozon.ru/app/settings/api-keys).
5. Нажмите **Сгенерировать**.

С 3 сентября 2026 года вступят в силу следующие изменения:

Новые ключи — создаются со сроком 3 месяца.

Текущие ключи со сроком 6 месяцев — действуют до текущей даты истечения, после чего новые ключи можно будет перевыпустить только на 3 месяца.

Старые «бессрочные» ключи — с 3 сентября у них появится дата окончания действия, и срок составит 3 месяца.

[Подробнее об изменениях](https://dev.ozon.ru/news/784-Izmeneniia-v-srokakh-deistviia-kliuchei-Seller-API/)

## Как задать диапазон IP-адресов для управления магазином

1. Нажмите **⋮ ****→ Редактировать **и перейдите в настройки API-ключа;
2. Нажмите **Добавить сеть **в разделе «Разрешённые сети»;
3. Введите название сети и укажите диапазон в поле «Адрес». Диапазон заполняется в структуре CIDR-нотации;
4. Сохраните изменения.

# Как работать с Seller API

Управляйте интерфейсом с помощью методов — текстовых команд, которые позволяют загружать и обновлять товары, получать информацию о складах, заказах, финансах. Все методы работы с данными можно разделить на несколько категории:

GET — получить;

POST — опубликовать;

PUT — изменить;

DELETE — удалить.

## Как посмотреть доступные методы

Для каждой роли можно посмотреть дерево доступных методов. Для этого нажмите на метод напротив роли при создании или редактировании ключа.

## Как протестировать методы

Методы можно протестировать прямо в[ документации](https://docs.ozon.ru/api/seller/#tag/Getting-started). Чтобы выполнить запрос, введите Client ID и API Key в консоль, выберите нужный метод и заполните тело запроса.

Можно выполнять запросы и в своём ПО. Собрали** коллекцию методов** для работы в Postman.

Перед началом работы определитесь, какие из методов будете использовать. Для этого изучите [Порядок работы с методами](https://docs.ozon.ru/api/seller/#tag/Process).

После настройки вы сможете автоматизировать больше десяти типичных [процессов](https://docs.ozon.ru/api/seller/#tag/Process), например:

[Выгрузить атрибуты и характеристики Ozon](https://docs.ozon.ru/api/seller/#section/Vygruzite-atributy-i-harakteristiki-Ozon). Это нужно, чтобы получить категорийное дерево и характеристики товаров.

[Загрузить и обновить товары](https://docs.ozon.ru/api/seller/#section/Zagruzite-i-obnovite-tovary). Методы позволяют загружать и редактировать товары и их изображения в пределах [лимитов](/work-with-goods/zagruzka-tovarov/creating-goods/limit#%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D0%B5%D1%82-%D0%BB%D0%B8%D0%BC%D0%B8%D1%82). [Посмотреть лимиты по API](https://docs.ozon.ru/api/seller/#operation/ProductAPI_GetProductInfoLimitV2)

[Обновить цены и остатки товаров](https://docs.ozon.ru/api/seller/#section/Obnovite-ceny-i-ostatki-tovarov). Когда товары и услуги загружены, продавец может узнать, сколько товаров осталось на складе и обновить их цены — с учётом скидок.

[Загрузить сертификаты брендов](https://docs.ozon.ru/api/seller/#section/Zagruzite-sertifikaty-brendov). Если продавец продаёт товары чужих брендов, ему нужно загрузить сертификаты и привязать их.

[Управлять заказами на FBO, FBS и realFBS](https://docs.ozon.ru/api/seller/#section/Upravlyajte-zakazami-FBO-FBS-i-rFBS). В случае с FBO логистикой занимается маркетплейс — продавцу достаточно видеть список отправлений и аналитику по ним. Для FBS и realFBS продавец проверяет необработанные отправления, маркировку, добавляет акты приёмки и другие документы.

Также методы Seller API позволяют [участвовать в акциях](https://docs.ozon.ru/api/seller/#section/Uchastvujte-v-akciyah) Ozon для покупателей, [получить информацию о складах](https://docs.ozon.ru/api/seller/#section/Poluchite-informaciyu-o-skladah), о [возвратах товаров](https://docs.ozon.ru/api/seller/#section/Poluchite-informaciyu-o-vozvratah-tovarov), [управлять чатами](https://docs.ozon.ru/api/seller/#section/Upravlyajte-chatami) с клиентами, [создавать и получать отчёты](https://docs.ozon.ru/api/seller/#section/Sozdajte-i-poluchite-otchyoty) по ценам, остаткам и отправлениям.

Если в процессе у вас возникли вопросы — напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Товары и цены → API Ozon** и выберите нужную подтему. В обращении укажите код запроса, при работе с которым возникла проблема.
