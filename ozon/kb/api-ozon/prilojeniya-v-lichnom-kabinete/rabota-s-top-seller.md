# Работа с приложением Top Seller

_Главная / API Ozon и интеграции / Приложения в личном кабинете_

Как с помощью нейросети создать уникальное описание товара, учитывающее правила модерации

Если во время работы с Top Seller возникли технические проблемы, обратитесь в поддержку [приложения](https://topseller.ru/).

# Что такое Top Seller

Приложение на базе искусственного интеллекта помогает создавать продающие описания товаров. Инструмент учитывает требования модерации и позволяет получить максимальную оценку для [контент-рейтинга карточки](/work-with-goods/reference-goods/content-rating). C приложением можно генерировать описания для всех категорий, кроме «Товаров для взрослых».

[Как подключить приложение](/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5)

# Как работать с приложением

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и выберите **Вручную**.
2. Заполните характеристики товара. Для генерации аннотации достаточно выбрать категорию и указать название позиции, но чтобы описание получилось более полным и уникальным, советуем заполнить как можно больше полей в карточке.
3. Под полем **Аннотация** нажмите **Сгенерировать с Topseller**
  Количество доступных генераций зависит от установленных разработчиком приложения тарифов. Они действуют 30 календарных дней с момента подключения приложения и могут быть бесплатными или платными. Описания тарифов можно найти в карточках приложений в разделе **[Приложения](https://seller.ozon.ru/app/appstore)**.
  После генерации текст описания можно поправить вручную. Также доступно переключение между двумя вариантами — текущим и предыдущим.

1. Подключите приложение. [Как это сделать](/api-ozon/prilojeniya#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5)
2. Откройте раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
3. В строке с нужным товаром нажмите **⋮** и выберите **Редактировать товар**.
4. Перейдите на вкладку **Характеристики** и под полем **Аннотация** нажмите **Сгенерировать с Topseller**
  Количество доступных генераций зависит от установленных разработчиком приложения тарифов. Они действуют 30 календарных дней с момента подключения приложения и могут быть бесплатными или платными. Описания тарифов можно найти в карточках приложений в разделе **[Приложения](https://seller.ozon.ru/app/appstore)**.
  После генерации текст описания можно поправить вручную. Также доступно переключение между двумя вариантами — текущим и предыдущим.

# Какие доступы запрашивает приложение

Чтобы создавать описания товара, необходимо разрешить приложению:

получать информацию о названии, категории и всех характеристиках вашего товара;

загружать сгенерированное описание в карточку товара.
