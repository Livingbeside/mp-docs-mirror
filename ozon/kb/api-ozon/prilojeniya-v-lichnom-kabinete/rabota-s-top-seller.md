# Работа с сервисом Top Seller

_Главная / API Ozon и интеграции / Сервисы для бизнеса в личном кабинете_

Как с помощью нейросети создать уникальное описание товара, учитывающее правила модерации

Если во время работы с Top Seller возникли технические проблемы, обратитесь в поддержку [сервиса](https://topseller.ru/).

# Что такое Top Seller

Сервис на базе искусственного интеллекта помогает создавать продающие описания товаров. Инструмент учитывает требования модерации и позволяет получить максимальную оценку для [контент-рейтинга карточки](/work-with-goods/reference-goods/content-rating). C сервисом можно генерировать описания для всех категорий, кроме «Товаров для взрослых».

[Как подключить сервис](https://seller-edu.ozon.ru/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#как-подключить-сервис)

# Как работать с сервисом

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и выберите **Вручную**.
2. Заполните характеристики товара. Для генерации аннотации достаточно выбрать категорию и указать название позиции, но чтобы описание получилось более полным и уникальным, советуем заполнить как можно больше полей в карточке.
3. Под полем **Аннотация** нажмите **Сгенерировать с Topseller**
  Количество доступных генераций зависит от установленных разработчиком сервиса тарифов. Они действуют 30 календарных дней с момента подключения сервиса и могут быть бесплатными или платными. Описания тарифов можно найти в карточках сервисов в разделе **[Каталог сервисов](https://seller.ozon.ru/app/appstore)**.
  После генерации текст описания можно поправить вручную. Также доступно переключение между двумя вариантами — текущим и предыдущим.

1. Подключите сервис. [Как это сделать](/api-ozon/prilojeniya#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5)
2. Откройте раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
3. В строке с нужным товаром нажмите **⋮** и выберите **Редактировать товар**.
4. Перейдите на вкладку **Характеристики** и под полем **Аннотация** нажмите **Сгенерировать с Topseller**
  Количество доступных генераций зависит от установленных разработчиком сервиса тарифов. Они действуют 30 календарных дней с момента подключения сервиса и могут быть бесплатными или платными. Описания тарифов можно найти в карточках сервисов в разделе **[Каталог сервисов](https://seller.ozon.ru/app/appstore)**.
  После генерации текст описания можно поправить вручную. Также доступно переключение между двумя вариантами — текущим и предыдущим.

# Какие доступы запрашивает сервис

Чтобы создавать описания товара, необходимо разрешить сервису:

получать информацию о названии, категории и всех характеристиках вашего товара;

загружать сгенерированное описание в карточку товара.
