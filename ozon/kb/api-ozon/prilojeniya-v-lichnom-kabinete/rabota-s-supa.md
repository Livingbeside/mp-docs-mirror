# Работа с приложением Supa

_Главная / API Ozon и интеграции / Приложения в личном кабинете_

Как создать профессиональную инфографику для карточек товаров, видеообложек или рекламных баннеров

Если во время работы с Supa возникли технические проблемы, обратитесь в поддержку [приложения](https://supa.ru/).

# Что такое Supa

Это инструмент, с которым можно создать профессиональную инфографику для карточек товара, видеообложек, рекламных баннеров и не только. Для этого не нужны специальные навыки — в приложении есть готовые шаблоны и библиотеки иллюстраций.

[Как подключить приложение](/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5)

# Чем отличаются тарифы в приложении

Перед началом работы нужно выбрать один из двух тарифов: бесплатный или премиум. Вот чем они различаются:

|  | Тариф бесплатный | Тариф премиум |
| --- | --- | --- |
| Удаление водяного знака Supa | ❌ | ✅ |
| Загрузка своих шрифтов | ❌ | ✅ |
| Добавление аудио и музыки | ❌ | ✅ |
| Шаблоны | Только базовые | Базовые и премиум |
| Библиотеки с иллюстрациями | Только базовые | Базовые и премиум |
| Длительность видеоролика | До 40 секунд | До 5 минут |
| Разрешение видеоролика | 480 пикселей | 1080 пикселей |
| Изменение размера иллюстраций | ❌ | ✅ |
| Удаление фона у изображений | ❌ | ✅ |
| История версий файлов | ❌ | ✅ |
| Синтезирование речи | ❌ | ✅ |
| Неограниченное хранилище файлов | ✅ | ✅ |
