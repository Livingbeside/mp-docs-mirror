# Работа с сервисом Supa

_Главная / API Ozon и интеграции / Сервисы для бизнеса в личном кабинете_

Как создать профессиональную инфографику для карточек товаров, видеообложек или рекламных баннеров

Если во время работы с Supa возникли технические проблемы, обратитесь в [поддержку сервиса](https://supa.ru/).

# Что такое Supa

Это инструмент, с которым можно создать профессиональную инфографику для карточек товара, видеообложек, рекламных баннеров и не только. Для этого не нужны специальные навыки — в сервисе есть готовые шаблоны и библиотеки иллюстраций.

[Как подключить сервис](https://seller-edu.ozon.ru/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#как-подключить-сервис)

# Чем отличаются тарифы сервиса

Перед началом работы нужно выбрать один из двух тарифов: бесплатный или премиум. Вот чем они различаются:

|  | Тариф бесплатный | Тариф премиум |
| --- | --- | --- |
| Удаление водяного знака Supa | ❌ | ✅ |
| Загрузка своих шрифтов | ❌ | ✅ |
| Добавление аудио и музыки | ❌ | ✅ |
| Шаблоны | Только базовые | Базовые и премиум |
| Библиотеки с иллюстрациями | Только базовые | Базовые и премиум |
| Длительность видеоролика | До 40 секунд | До 5 минут |
| Разрешение видеоролика | 480 пикселей | 1080 пикселей |
| Изменение размера иллюстраций | ❌ | ✅ |
| Удаление фона у изображений | ❌ | ✅ |
| История версий файлов | ❌ | ✅ |
| Синтезирование речи | ❌ | ✅ |
| Неограниченное хранилище файлов | ✅ | ✅ |
