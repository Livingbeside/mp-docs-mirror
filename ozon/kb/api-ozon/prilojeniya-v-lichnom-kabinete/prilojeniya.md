# Работа с сервисами для бизнеса в личном кабинете

_Главная / API Ozon и интеграции / Сервисы для бизнеса в личном кабинете_

Как управлять инструментами для работы на Ozon от сторонних разработчиков и как оплатить доступ к функционалу приложений

Если во время работы с сервисом возникли технические проблемы, обратитесь в поддержку этого сервиса.

# Что такое сервисы для бизнеса

Это специальные инструменты, которые помогут вам автоматизировать процессы в личном кабинете и оптимизировать работу на Ozon. Используя их, сможете освободить время для других важных задач.

Постепенно расширяем список сервисов в личном кабинете. Если вы уже пользуетесь подобными инструментами и хотите, чтобы они официально работали с Ozon, [сообщите нам](https://forms.ozon.ru/form/14ba33194cb97c18f23ed4b5d5bff47e18) об этом — свяжемся с их разработчиками.

# Как работают сервисы для бизнеса

Когда вы подключаете сервис, вы разрешаете ему работать с определёнными методами API (Application Programming Interface) — связываете инструмент с нашей системой. После подключения сервис интегрируется по уникальному API-ключу в ваш личный кабинет и дополняет его новыми полезными возможностями.

Сервисы создают сторонние разработчики, которые проходят наш отбор. Поэтому работать с официальными инструментами безопасно — проверяем, что сервисам будут доступны только те функции личного кабинета, которые есть в их описании. Например, если сервис генерирует описания товаров, он не сможет управлять вашими ценами, заказами и остатками.

# Как подключить сервис

Подключать сервисы могут только пользователи с ролью **Управляющий** или **Администратор**. [Подробнее о ролях в личном кабинете](/personal-account/user-management?search=%D1%80%D0%BE%D0%BB%D0%B8#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82-%D1%80%D0%BE%D0%BB%D0%B8-%D0%B2-%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D0%BC-%D0%BA%D0%B0%D0%B1%D0%B8%D0%BD%D0%B5%D1%82%D0%B5)

1. Перейдите в личном кабинете в раздел **[Товары → Каталог сервисов](https://seller.ozon.ru/app/appstore)**.
2. Выберите в каталоге нужный сервис, прочитайте его описание и нажмите **Запустить**.
3. Посмотрите, к какой информации о товарах у инструмента будет доступ, а затем нажмите **Разрешить**.

После подключения сервиса можно сразу начать пользоваться новыми функциями личного кабинета.

# Как отключить сервис

1. Откройте раздел **[Товары → Каталог сервисов](https://seller.ozon.ru/app/appstore)**.
2. Перейдите на вкладку **Подключённые**.
3. Выберите сервис, нажмите **Отключить**, а затем подтвердите действие.

Сервис можно будет снова подключить в любой момент.

# Как оплатить доступ к сервису

Приобрести доступ к платным сервисам могут только пользователи с ролью **Управляющий** или** Администратор**. [Подробнее о ролях в личном кабинете](/personal-account/user-management?search=%D1%80%D0%BE%D0%BB%D0%B8#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82-%D1%80%D0%BE%D0%BB%D0%B8-%D0%B2-%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D0%BC-%D0%BA%D0%B0%D0%B1%D0%B8%D0%BD%D0%B5%D1%82%D0%B5)

1. Перейдите в личном кабинете в раздел **[Товары → Каталог сервисов](https://seller.ozon.ru/app/appstore)**.
2. Откройте карточку сервиса и нажмите **Выбрать тариф**.
3. Выберите подходящий тариф и нажмите **Перейти к оплате**.
4. Выберите удобный способ оплаты. Например, можете указать данные вашей бизнес-карты.
5. Электронный чек от разработчика сервиса придёт на электронную почту, указанную в вашем личном кабинете — для этого передадим её [ООО «ОЗОН Банк»](https://finance.ozon.ru/business/acquiring).
  Чтобы получить квитанцию об оплате, отметьте пункт «Получить квитанцию» и напишите адрес вашей почты.
6. Нажмите **Оплатить**.

После успешной оплаты вы получите доступ к сервису.

Разработчики получают плату напрямую. Ozon не взимает комиссий за доступ к сервисам.

Отказаться от доступа к сервису можно в любой момент, нажав **Отключить** в его карточке. В этом случае сможете пользоваться сервисом до конца оплаченного периода.
