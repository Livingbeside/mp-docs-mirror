# Работа с приложением SplitTest

_Главная / API Ozon и интеграции / Приложения в личном кабинете_

Как запускать онлайн-опросы на реальную аудиторию, чтобы оценить эффективность магазина

Если во время работы со SplitTest возникли технические проблемы, обратитесь в поддержку [приложения](https://splittest.ru/).

# Что такое SplitTest

Это инструмент, с помощью которого можно проводить быстрые онлайн-опросы реальных людей, чтобы оценить эффективность гипотез о вашем магазине, товарах, ценах и т.п.  Алгоритмы оценят конверсию, восприятие, реакцию или поведение пользователей, а затем сформируют детальный отчёт — вам останется только принять решение.

[Как подключить приложение](/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5)

# Как работать с приложением

1. Перейдите в личном кабинете в раздел **[Товары → Все приложения](https://seller.ozon.ru/app/appstore)**, выберите SplitTest и нажмите **Запустить**.
2. Выберите тариф:
  «Базовый» — позволит посмотреть, какие онлайн-опросы можно запустить в приложении. Воспользоваться инструментами без оплаты не получится. Новые пользователи за первую активацию тарифа получат 650 бонусных рублей на первые опросы. Чтобы позже сменить тариф, [отключите приложение](/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#%D0%BA%D0%B0%D0%BA-%D0%BE%D1%82%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5), а затем подключите заново.
  
  «Пополнение баланса» — система предложит пополнить баланс на 1200 или 2400 рублей, которые можно потратить на исследования. Чтобы положить на счёт бо́льшую сумму, [отключите приложение](/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#%D0%BA%D0%B0%D0%BA-%D0%BE%D1%82%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5), а затем подключите заново. Повторите операцию необходимое количество раз.
  Цена за опрос зависит от типа теста, количества респондентов, привычек и интересов аудитории и других параметров.
3. Создайте онлайн-опрос:
  выберите тип теста:
  **Тест один из двух** — выбрать вариант обложки для карточки товара;
  
  **Приоритетный тест** — сравнить карточку товара с конкурентами;
  
  **Звёздный рейтинг** — протестировать идею нового продукта;
  
  **Открытый вопрос** — познакомиться с аудиторией.
  Также скоро можно будет оценить выбор продукта на полке (Клик-тест) и общую известность (Турнирный тест).
  
  напишите вопрос — алгоритм подскажет статистически нейтральную формулировку;
  
  загрузите материалы — подойдут изображения в форматах jpeg, png, webp, gif;
  
  выберите аудиторию — укажите количество респондентов, их пол, возраст и уровень образования.
4. Запустите онлайн-опрос. Система подберёт респондентов и проведёт тест.
5. Когда исследование закончится, в приложении сформируется детальный отчёт.

# Что ещё может быть полезно
