# Работа с сервисом SplitTest

_Главная / API Ozon и интеграции / Сервисы для бизнеса в личном кабинете_

Как запускать онлайн-опросы на реальную аудиторию, чтобы оценить эффективность магазина

Если во время работы со SplitTest возникли технические проблемы, обратитесь в [поддержку сервиса](https://splittest.ru/).

# Что такое SplitTest

Это инструмент, с помощью которого можно проводить быстрые онлайн-опросы реальных людей, чтобы оценить эффективность гипотез о вашем магазине, товарах, ценах и т.п.  Алгоритмы оценят конверсию, восприятие, реакцию или поведение пользователей, а затем сформируют детальный отчёт — вам останется только принять решение.

[Как подключить сервис](https://seller-edu.ozon.ru/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#как-подключить-сервис)

# Как работать с сервисом

1. Перейдите в личном кабинете в раздел **[Товары → Каталог сервисов](https://seller.ozon.ru/app/appstore)**, выберите SplitTest и нажмите **Запустить**.
2. Выберите тариф:
  «Базовый» — позволит посмотреть, какие онлайн-опросы можно запустить в сервисе. Воспользоваться инструментами без оплаты не получится. Новые пользователи за первую активацию тарифа получат 650 бонусных рублей на первые опросы. Чтобы позже сменить тариф, отключите сервис, а затем подключите заново.
  
  «Пополнение баланса» — система предложит пополнить баланс на 1200 или 2400 рублей, которые можно потратить на исследования. Чтобы положить на счёт бо́льшую сумму, отключите сервис, а затем подключите заново. Повторите операцию необходимое количество раз.
  Цена за опрос зависит от типа теста, количества респондентов, привычек и интересов аудитории и других параметров.
3. Создайте онлайн-опрос:
  выберите тип теста:
  **Тест один из двух** — выбрать вариант обложки для карточки товара;
  
  **Приоритетный тест** — сравнить карточку товара с конкурентами;
  
  **Звёздный рейтинг** — протестировать идею нового продукта;
  
  **Открытый вопрос** — познакомиться с аудиторией.
  Также скоро можно будет оценить выбор продукта на полке (Клик-тест) и общую известность (Турнирный тест).
  
  напишите вопрос — алгоритм подскажет статистически нейтральную формулировку;
  
  загрузите материалы — подойдут изображения в форматах jpeg, png, webp, gif;
  
  выберите аудиторию — укажите количество респондентов, их пол, возраст и уровень образования.
4. Запустите онлайн-опрос. Система подберёт респондентов и проведёт тест.
5. Когда исследование закончится, в сервисе сформируется детальный отчёт.

# Что ещё может быть полезно

Чтобы вам было легче создать первый онлайн-опрос, написали гайд, в котором собрали наиболее частые ошибки продавцов в карточках товаров. Рассказываем, как их исправить с помощью исследований.
