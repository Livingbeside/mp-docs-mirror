# Работа с сервисом Topseller PIM

_Главная / API Ozon и интеграции / Сервисы для бизнеса в личном кабинете_

Как с помощью приложения перенести карточки товаров с других маркеплейсов

Если во время работы с Topseller PIM возникли технические проблемы, обратитесь в [поддержку сервиса](https://topseller.ru/pim).

# Что такое Topseller PIM

Это сервис, с помощью которого можете скопировать на Ozon ваши карточки с других маркетплейсов.

[Как подключить сервис](https://seller-edu.ozon.ru/api-ozon/prilojeniya-v-lichnom-kabinete/prilojeniya#как-подключить-сервис)

# Как авторизоваться в сервисе

1. Перейдите в личном кабинете в раздел **[Товары → Каталог сервисов](https://seller.ozon.ru/app/appstore)**.
2. Выберите Topseller PIM и нажмите **Авторизация**.
3. Предоставьте доступ к вашему личному кабинета продавца с ролью sellerapi.product — нажмите кнопку «Разрешить».
4. После успешной авторизации автоматически откроется главная страница сервиса.

# Как перенести карточки

1. На вкладке «Анализ» выберите маркетплейс, с которого хотите перенести карточки на Ozon. Затем введите токен кабинета этой площадки. Чтобы посмотреть подробную инструкцию о том, как создать токен, нажмите на значок «i».
2. Убедитесь, что токен имеет разрешения на доступ к API, внесите его в поле «Токен» и нажмите **Запустить анализ**:
  если у токена не окажется необходимых прав — появится сообщение об ошибке. В этом случае запустить анализ карточек не получится;
  
  если всё в порядке — сервис начнёт анализировать карточки на выбранном маркетплейсе и копировать их на Ozon. Статус процесса можно увидеть в этой же вкладке.
3. Иногда сервису может потребоваться ваша помощь, чтобы правильно соотнести категории площадок. В этом случае появится окно «Связи категорий», где вы сможете указать, какая категория Ozon соответствует категории вашего товара на другом маркетплейсе. Заполните все поля и нажмите **Подтвердить**, чтобы продолжить копирование карточки.
4. Когда процесс анализа карточек завершится, отобразится отчёт с итогами. Если карточки:
  скопировались с ошибками — появится кнопка **Перейти к правке ошибок**. Нажмите на неё, чтобы перейти в раздел «Исправление ошибок». Внесите необходимые изменения, следуя подсказкам.
  
  созданы без ошибок — вы увидите кнопку **Перейти к предпросмотру**. Нажмите на неё, чтобы просмотреть созданные карточки и выбрать те, которые хотите разместить на Ozon.
5. Когда выберете карточки, которые хотите перенести, сервис предложит два варианта выгрузки:
  бесплатно — до 50 карточек. Выберите «Использовать бесплатные выгрузки» и нажмите **Выгрузить**;
  
  платно — если нужно выгрузить более 50 карточек или не хотите использовать бесплатные попытки. Нажмите **Выгрузить** и укажите адрес электронной почты для получения чека об оплате. Затем откроется платёжная форма. После оплаты выгрузка карточек запустится автоматически.
6. Когда процесс выгрузки карточек завершится, отобразится отчёт с итогами. Чтобы скачать текущий или любой предыдущий отчёт, нажмите **Перейти к отчётам по выгрузке** и выберите нужные документы.
