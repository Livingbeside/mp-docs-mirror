# Начало работы с Performance API

_Главная / API Ozon и интеграции_

Как самостоятельно автоматизировать работу с рекламным кабинетом Ozon

## Зачем нужен внешний API

Внешний API позволяет продавцам с широким ассортиментом и агентствам автоматизировать работу в рекламном кабинете Ozon. С помощью сторонних платформ через API можно автоматически:

собирать статистику по нескольким рекламным каналам;

добавлять товары в рекламу;

оптимизировать ставки.

Подключиться к API можно самостоятельно — для этого в личном кабинете нужно создать API-ключ и авторизоваться в сервисе. Если у вас уже есть ключ, но его срок истёк — деактивируйте его и создайте новый.

[Подробнее о внешнем API в документации](https://docs.ozon.ru/api/performance/)

## Как начать пользоваться внешним API для рекламы

1. Откройте страницу **[Настройки → Performance API](https://seller.ozon.ru/app/settings/performance-api)**.
2. Если у вас:
  есть сервисный аккаунт — выберите его;
  
  нет сервисного аккаунта — нажмите **Создать аккаунт**. Если вам нужно разграничить доступ для нескольких приложений или партнёров, с которыми вы интегрируетесь — создайте несколько аккаунтов.
  В сервисном аккаунте можно отправлять не больше 100 тысяч запросов в сутки.
3. Нажмите **Добавить ключ**. Можно выпустить несколько ключей, если вам так будет удобнее интегрироваться с системой.
4. Чтобы изменить название ключа — нажмите на него, введите новое название и нажмите **Сохранить**.
