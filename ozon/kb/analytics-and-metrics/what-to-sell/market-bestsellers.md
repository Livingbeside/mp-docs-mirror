# Недостающие товары

_Главная / Аналитика / Что продавать на Ozon — только для Premium-продавцов_

Как найти востребованные товары на российском рынке за предыдущий месяц, которых нет на Ozon

# Как работает инструмент Недостающие товары

В разделе **[Аналитика → Недостающие товары](https://seller.ozon.ru/app/analytics/what-to-sell/market-bestsellers)** показываем бестселлеры, которые продаются на других площадках, но ещё не появились на Ozon.

Анализируем информацию из открытых источников раз в месяц. Показываем приблизительные усреднённые значения метрик. Раздел работает в тестовом режиме — это значит, что мы будем его дорабатывать и дополнять данные по недостающим товарам.

Инструмент позволяет найти идеи для пополнения ассортимента и свободные ниши, которые можно быстро занять и получить хорошую прибыль.

Показываем в разделе данные за предыдущий месяц. Если хотите продавать уникальный товар, советуем проверить, что его по-прежнему нет на площадке.

# Где посмотреть список недостающих товаров

На странице **[Аналитика → Недостающие товары](https://seller.ozon.ru/app/analytics/what-to-sell/market-bestsellers)** можно:

**посмотреть готовый список** — в него включены популярные товары за предыдущий месяц, которые ещё не продаются на Ozon;

**найти товар по названию** — для этого укажите его в строке поиска;

**отфильтровать по категории** — для этого нажмите **Выбрать категорию** и выберите нужную, они сгруппированы по трём уровням от общего к частному;

**отфильтровать по бренду **— для этого сначала выберите категорию или укажите название товара, а затем выберите нужный бренд из списка;

**отфильтровать товары по цене **— для этого укажите диапазон в фильтре **Цена**.

Покажем в отчёте данные по выбранным товарам:

**Название столбца**

**Пояснение**

Название товара

Бренд

Фото

Полное название товара, которое указывают на других площадках, его фотография и бренд

Категория

Отображаем категорию до 3 уровня

Заказано на сумму

Суммарная стоимость заказанных товаров за последний месяц. Считаем по цене продажи

Динамика суммы заказов

Как изменилась суммарная стоимость заказов в сравнении с предыдущим месяцем

Заказано товаров

Общее количество заказанных товаров за последний месяц

Средняя цена на других площадках

Средняя цена продажи товара с НДС за месяц

Среднесуточные показатели

Заказано на сумму — средняя сумма заказов в сутки. Считаем так: делим сумму всех продаж за месяц на количество дней, когда товар был в наличии. Не вычитаем возвраты и отмены

Заказано товаров —  среднее количество заказов в сутки. Считаем так: делим количество всех заказов за месяц на количество дней, когда товар был в наличии

Нажмите **Добавить товар **или **Добавить **в таблице, чтобы создать новую карточку товара. Откроется раздел **[Товары → Добавить товары → Вручную](https://seller.ozon.ru/app/products/add/general-info)****.**

# Как сообщить, что товар есть на Ozon

Если вы заметили, что товар из списка недостающих есть на Ozon:

1. Нажмите .
2. Добавьте ссылку на товар или артикул.
3. Нажмите **Отправить**.

Мы проверим ваше обращение, и если товар действительно есть на Ozon, уберём его из раздела. Можно отправить до 5 обращений в сутки.
