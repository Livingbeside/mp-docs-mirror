# Что показывает инструмент Поисковые запросы

В разделе **[Аналитика → Поисковые запросы](https://seller.ozon.ru/app/analytics/what-to-sell/all-queries)** показываем статистику по самым популярным запросам, которые используют покупатели на Ozon. Они сохраняются в том же виде, в котором пользователи пишут их в поисковую строку на сайте. Например, если название иностранного бренда ввели по-русски, система сохранит этот запрос на русском языке.

Аналитика поможет понять, какой товар хотели купить чаще остальных и как его пытались найти. Так вы сможете:

сформировать или скорректировать ассортимент своего магазина;

понять, какую информацию стоит указать в карточке, чтобы она отображалась в поисковой выдаче.

Данные обновляются ежедневно. Максимальное количество запросов в списке — 1000.

# Как пользоваться аналитикой поисковых запросов

В разделе **[Аналитика → Поисковые запросы](https://seller.ozon.ru/app/analytics/what-to-sell/all-queries)** можно:

**Найти статистику по конкретному поисковому запросу** — для этого укажите его в строке поиска;

**Отсортировать значения по любой метрике** — для этого нажмите на иконку стрелки или кликните два раза на название метрики;

**Открыть на Ozon** — нажмите ⋮ в строке с любым запросом, чтобы открыть его и посмотреть, какие карточки будут в выдаче маркетплейса;

**Управлять отображением метрик в таблице** — некоторые из них могут быть скрыты. Чтобы появились столбцы с данными, наведите курсор на значок настройки и выберите метрики, которые вас интересуют;

**Выбрать группу метрик **— покажем метрики, относящиеся к одной из трёх категорий: сезонность, конкуренция и конверсия.

**Выбрать группу запросов **— выберите одну из групп, например, «дом и сад» или «электроника». Покажем популярные запросы в этой группе.

С подпиской **[Premium Plus](/seller-rating/about-rating/subscription-premium-plus)**** **можно:

**Выбрать период для показа статистики **— последние 28 дней или календарный месяц в течение последнего года;

**Скачать отчёт по поисковым запросам** — для этого нажмите** Скачать → Отчёт со всеми настройками**.

# По каким метрикам можно анализировать поисковые запросы

## Популярность запроса

Метрика показывает, сколько покупателей искали товары по этому запросу. Если за сутки пользователь несколько раз указывал этот запрос в поиске, учтём его в статистике один раз.

**Чем это полезно**: с помощью этой метрики можно определить, по каким запросам чаще ищут товары.

## Динамика за 7 дней

Метрика показывает в процентах, как росла или снижалась популярность запроса за последние 7 дней. Доступна с подпиской [Premium Plus](/seller-rating/about-rating/subscription-premium-plus).

**Чем это полезно: **с помощью этой метрики можно быстрее отреагировать на спрос и увеличить продажи.

## Динамика за 28 дней

Метрика показывает в процентах, как росла или снижалась популярность запроса за последние 28 дней. Доступна с подпиской [Premium Plus](/seller-rating/about-rating/subscription-premium-plus).

**Чем это полезно: **с помощью этой метрики можно быстрее отреагировать на спрос и увеличить продажи.

## Добавления в корзину

Метрика показывает, сколько покупателей добавили хотя бы один товар в корзину из результатов поиска по запросу или с карточки товара после перехода из результатов поиска.

Количество добавленных товаров не учитывается. Если пользователь за сутки добавил несколько единиц одного товара или несколько разных товаров, учтём только одно добавление.

## Конверсия в корзину

Метрика показывает долю покупателей, которые добавили хотя бы один товар из результатов поиска по запросу или с карточки товара после перехода из результатов поиска по запросу, по отношению к количеству тех, кто искал по запросу.

Количество добавленных товаров не учитывается. Если пользователь за сутки добавил несколько штук одного товара или несколько разных, учтём это только один раз. Например, если 5 покупателей добавили по 3 товара в корзину, а всего по этому запросу что-то искали  10 человек, то конверсия 5 / 10 = 50%.

**Чем это полезно**: метрики **Добавления в корзину** и **Конверсия в корзину** помогут оценить, по каким запросам большее количество покупателей готовы оформить заказ.

## Уникальные покупатели с заказами

Количество уникальных покупателей, которые оформили заказ из результатов поиска по этому запросу

## Конверсия в заказ

Метрика показывает процент покупателей, которые пришли по этому запросу из результатов поиска и заказали товар.

## Заказано на сумму

Метрика показывает общую стоимость товаров, заказанных из результатов поиска. Учитываем все заказы, включая отмены и возвраты. Для расчёта берем цену реализации с учётом стоимости обработки заказа в ПВЗ

## Средняя цена

Метрика показывает среднюю цену реализации товара, по которой покупатель купил товар с учётом стоимости обработки заказа в ПВЗ.

Рассчитываем значение от всех добавлений в корзину по поисковому запросу — оно не зависит от страницы, покупателя или сессии. Например, если два покупателя добавили три товара в корзину, первый — один товар на 500 рублей, второй — два товара по 1000 и 1200 рублей, то средняя стоимость = (500 + 1000 + 1200) / 3 = 900 рублей.

**Чем это полезно**. С помощью этой метрики можно оценить, на какую сумму в среднем добавляют в корзину товар, который находят по поисковому запросу. Если значение окажется меньше или больше предельной цены без акций, которую установили вы, возможно, стоит скорректировать её или проанализировать, чем отличаются товары в разных ценовых категориях по этому запросу — это поможет привлечь покупателей, которые отдают предпочтение другим продавцам.

## Показано товаров

Метрика показывает среднее количество товаров, которые просматривают покупатели по поисковому запросу.

## Конкуренты

Метрика показывает среднее количество продавцов, чьи товары покупатели посмотрели в поисковом запросе.

## Запросы без действий

Метрика показывает количество запросов, при которых покупатели не нажимали на товары из выдачи.

## Доля запросов без действий

Метрика показывает долю запросов, при которых покупатели не кликали на товары из выдачи, к общему количеству аналогичных запросов.

**Чем это полезно**: с помощью этой метрики можно оценить, у каких товаров низкий спрос.

## Запросы с похожими результатами

Метрика показывает количество запросов, для которых не нашлось точных совпадений, потому что в выдачу попали похожие товары.

## Запросы без результата

Метрика показывает количество запросов, для которых не нашлось подходящего товара.

## Доля запросов без результата

Метрика показывает долю поисковых запросов, по которым покупатели не нашли товар, к общему количеству аналогичных запросов.

**Чем это полезно**: с помощью этой метрики вы можете увидеть товары с высоким спросом, которые пользователи не находят на Ozon, и оценить какие товары вам выгодно продавать.
