# Видимость ваших товаров в поиске

_Главная / Аналитика / Аналитика продавца / Видимость в поиске_

Как проверить, как видят ваши товары покупатели в поиске, и сравнить показатели с конкурентами

# Что можно узнать из аналитики

Полная аналитика доступна с подпиской [Premium Plus](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/podpiska-premium-pro). С подписками [Premium](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/premium-program) и [Premium Lite](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-lite), а также без подписки можно посмотреть часть показателей.

С помощью инструмента можно проверить, сколько покупателей ищут и видят ваши товары в поиске, сколько из них переходят в карточку товара и делают заказ. По каждому товару показываем аналитику в сравнении с конкурентами. [Как сравнить показатели своего товара с конкурентами](#как-сравнивать-показатели-своего-товара-с-конкурентами)

Покажем в аналитике:

ваши товары, которые покупатели увидели или заказали из результатов поиска на Ozon;

запросы, по которым ваши товары увидели или купили;

показатели каждого товара в сравнении с товаром конкурента.

Данные рассчитываются с задержкой на 1-2 дня. Если вы добавили новый товар, покажем аналитику, как только появятся просмотры или продажи. Проверить, что у товара нет проблем и он доступен покупателям, можно в [отчёте «Ошибки индексации»](/analytics-and-metrics/fulfillment-reports/oshibki-indeksacii).

# Как проверить видимость товаров

1. Откройте раздел **[Аналитика → Видимость в поиске](https://seller.ozon.ru/app/analytics-search/search-results/apz)**** **и перейдите на вкладку **Мои товары**. Отобразятся все ваши товары — первыми покажем те, которые чаще замечали в поиске. [Какие показатели отображаются](https://seller-edu.ozon.ru/libra/analytics-and-metrics/graphs/vidimost-v-poiske/analitika-po-zaprosu#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D0%B0%D1%82%D0%B5%D0%BB%D0%B8-%D0%BC%D0%BE%D0%B6%D0%BD%D0%BE-%D1%83%D0%B7%D0%BD%D0%B0%D1%82%D1%8C-%D0%B2-%D0%B0%D0%BD%D0%B0%D0%BB%D0%B8%D1%82%D0%B8%D0%BA%D0%B5)
2. Используйте фильтры:
  Категория — товары в отдельных категориях.
  
  Признак товара — товары, которые продаются только на платформе Селект или одновременно на Селект и Ozon.
  
  Платформа — показатели для выбранной платформы: Селект или Ozon. Например, если выбрать «Селект», покажем в таблице данные только для этой платформы, без учёта данных с Ozon.
3. Нажмите **Посмотреть все запросы** — покажем запросы, по которым ваши товары чаще всего смотрели или заказывали, и статистику по ним.

С подпиской [Premium](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/premium-program), [Premium Lite](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-lite), [Premium Plus](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/subscription-premium-plus) или [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/podpiska-premium-pro) можно скачать в XLS-файл товаров со всеми запросами и показателями. Для этого выберите нужные товары и нажмите **Скачать XLS**.

В приложении раздел с аналитикой доступен только с подпиской [Premium](https://seller-edu.ozon.ru/seller-rating/about-rating/premium-program), [Premium Plus](https://seller-edu.ozon.ru/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](https://seller-edu.ozon.ru/seller-rating/about-rating/podpiska-premium-pro).

1. На вкладке **Товары** откройте нужную позицию. Аналитика отображается только у товаров с продажами за последнюю неделю.
2. В блоке **Место в поиске** отображается средняя позиция товара в поиске по 10 запросам, в которых было больше всего просмотров. Откройте блок **Место в поиске**, чтобы увидеть статистику.
3. В разделе **Общая статистика **отобразятся показатели за последние 7 дней:
  **сколько покупателей** искало эти запросы и увидело товар;
  
  **конверсия из поиска** в карточку или в заказ;
  
  **заказано по запросам** — количество товаров или прибыль** **от заказов с этих запросов.
4. Нажмите** Перейти в аналитику запросов **или кликните по любой из метрик, чтобы посмотреть подробности.** **

# Как работать с календарём

Без Premium-подписки можно посмотреть аналитику только за последнюю неделю.

C подпиской [Premium](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/premium-program), [Premium Lite](/seller-rating/podpiska-premium-lite), [Premium Plus](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/subscription-premium-plus) или [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/about-rating/podpiska-premium-pro) аналитику по запросам можно проверить за определенные даты. Для этого укажите нужный интервал в календаре.

Данные рассчитываются в течение 1-2 дней, поэтому аналитику за сегодня посмотреть не получится.

# Как сравнивать показатели своего товара с конкурентами

1. Откройте раздел **[Аналитика → Видимость в поиске](https://seller.ozon.ru/app/analytics-search/search-results/apz)**** **и в строке с нужным товаром нажмите **К аналитике товара.**
2. Выберите период и товар конкурента, с которым хотите сравнить показатели.
3. На странице покажем:
  В блоке **Показатели **— ваши данные в сравнении с товаром конкурента.
  
  В блоке **Динамика** — график изменений каждого показателя по дням или неделям.
  
  В блоке **Запросы товара** — поисковую статистику по всем запросам выбранного товара. Выберите вкладку **Товар конкурента** или **Сравнение**, чтобы увидеть показатели товара конкурента по тем же запросам.

# Какие показатели можно узнать в аналитике

Часть показателей доступна только с подпиской [Premium](/seller-rating/about-rating/premium-program), [Premium Lite](/seller-rating/podpiska-premium-lite), [Premium Plus](/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro).

| **Показатель** | **Что значит** |
| --- | --- |
| Сколько покупателей искало | Сколько уникальных пользователей проверяли такой запрос — без учёта, видели они его или нет. |
| Сколько покупателей увидело | Сколько уникальных пользователей увидели товар по этому запросу. |
| Позиция в поиске | На каком месте в среднем показывался товар в результатах поиска Ozon без учётом фильтров и сортировки по этому запросу. Считаем так: складываем все значения позиций и делим на количество запросов. |
| Конверсия из поиска в карточку | Отношение количества посещений карточки к количеству показов в поиске по этому запросу. |
| Конверсия из поиска в заказ | Отношение количества заказов к количеству показов в поиске по этому запросу. |
| Заказано товаров по запросам | Сколько товаров заказали по запросам, включая отмены и возвраты. |
| Заказано на сумму по запросам | Общая стоимость товаров, заказанных по запросам. Учитываем все заказы, включая отмены и возвраты. |

# Почему в аналитике не все данные

| Нет аналитики по новому товару | Если вы добавили новый товар, покажем аналитику, как только появятся просмотры или продажи. Проверить, что у товара нет проблем и он доступен покупателям, можно в [отчёте «Ошибки индексации»](/analytics-and-metrics/fulfillment-reports/oshibki-indeksacii). |
| --- | --- |
| Отображаются не все запросы, по которым можно найти товар | В аналитику попадают только запросы, из результатов поиска по которым товар увидели или купили. Если какого-то запроса нет в аналитике, значит никто из покупателей пока не долистал выдачу до вашего товара. |
| Отображается покупка товара, но нет просмотров | Покупатель может добавить товар в корзину и оформить заказ не сразу, а через несколько дней. |
