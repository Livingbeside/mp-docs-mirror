# Продажи по кластерам

_Главная / Аналитика / Аналитика продавца / Продажи моих товаров_

Как анализировать продажи товаров в разных регионах (кластерах Ozon) на основе спроса покупателей и как выгодно скорректировать географию

# Что показывает аналитика по кластерам

**Кластеры** — это зоны доставки ваших товаров по складам Ozon. В одну зону могут входить сразу несколько субъектов страны, поэтому кластеры не всегда совпадают с регионами. [Подробнее о кластерах](/commissions-tariffs/additional-information/table-klastery)

Аналитика по кластерам поможет проанализировать географию спроса на ваши товары. Она будет полезна:

на FBO — поможет решить, какие товары оставить на домашнем складе, а какие лучше перевезти в другие кластеры;

на FBS и realFBS — поможет понять, в каких регионах товары пользуются популярностью, и скорректировать географию.

Инструмент находится в разделе **[Аналитика ](https://seller.ozon.ru/app/analytics/graphs/geodata)**[→](https://seller.ozon.ru/app/analytics/graphs/geodata)**[ Продажи моих товаров](https://seller.ozon.ru/app/analytics/graphs/geodata)**[ → ](https://seller.ozon.ru/app/analytics/graphs/geodata)**[Продажи по кластерам](https://seller.ozon.ru/app/analytics/graphs/geodata)**. Данные обновляются раз в день.

# Как работать с графиком для аналитики по кластерам

С помощью графика **Аналитика по кластерам** можно выяснить, в каком из кластеров ваши товары продаются лучше всего. Инструмент состоит из нескольких блоков:

1. **Период отчёта**. Можно выбрать любой период для отчёта о продажах: за сегодня, вчера, неделю, месяц, квартал или год. Также можно настроить индивидуальный период с помощью календаря.
2. **Фильтры**. Можно выбрать, какие товары будут отражаться в графике. Есть три варианта:
  Артикул — его можно выбрать из выпадающего списка или указать вручную.
  
  Категории — можно проанализировать продажи целой категории товаров;
  
  Тип склада — этот фильтр покажет, как продавались товары со склада Ozon и с собственного склада продавца, а также импортированные товары.
3. **Детализация на графике**. Статистику на графике можно отобразить по дням, неделям и месяцам.
4. **Показатели (метрики)**. В этом разделе можно выбрать показатели, которые будут отражаться на графике — количество заказанных и доставленных товаров, общая стоимость товаров и затраты на логистику. Метрики можно выбрать как в поле **Настройка показателей**, так и в списке рядом с детализацией. [Как настроить показатели](#как-настроить-показатели-для-аналитики-по-кластерам)
5. **График**. Если навести курсор на сам график, можно проследить итоговое и среднее количество заказов в определённый день и посмотреть разницу с предыдущим днём.
6. **Настройка группировок**. Можно выбрать, каким образом товары будут отображаться на графике: по категориям, брендам, моделям или кластерам отгрузки. [Как настроить группировки](#как-настроить-группировки-для-аналитики-по-кластерам)
7. **Сравнение**. С помощью этого инструмента можно сравнить показатели двух товаров. [Как сравнить метрики](#как-сравнивать-метрики-для-аналитики-по-кластерам)

# Какие бывают группировки для аналитики по кластерам

Группировки — это то, как показаны данные в строках таблицы:

**товары по категориям 3 уровня** — позиции будут разбиты на группы по категориям 3 уровня (например, 1 категория — Одежда, 2 категория — Верхняя одежда, 3 категория — Пальто женское);

**товары по брендам** — разделим товары на группы по брендам;

**товары по всем уровням категорий** — позиции будут разделены на группы по категориям 1 уровня (раскройте их, чтобы увидеть вложенные подкатегории и товары);

**товары по категориям 2 уровня с учётом брендов** — разобьём позиции на группы по категориям 2 уровня, бренды и товары вложены;

**товары по моделям** — будут отражены продажи определённых моделей товаров;

**только товары** — данные будут показаны без разбивки на группы;

**по кластерам отгрузки** — товары будут разбиты на группы по кластерам, в которые продавец поставляет свои товары (FBO), либо по кластерам, из которых он продаёт товары со своего склада (FBS).

# Как настроить группировки для аналитики по кластерам

1. В левом нижнем углу графика в блоке **Настройка группировок** нажмите **Настроить**.
2. Нажмите  и просмотрите, какие данные будут отражены
3. Выберите группировку и нажмите **Применить**.

Выбранная группировка отразится на графике — например, в таблице ниже показана группировка **По кластерам отгрузки**. По умолчанию отображаются значения по полю **Итого и среднее**. Чтобы добавить на график дополнительные данные, нажмите  рядом с нужным полем. Чтобы очистить график, нажмите .

# Какие бывают показатели (метрики) для аналитики по кластерам

Показатели отвечают за набор данных, которые будут показаны в таблице и на графике для каждого кластера. Можно выбрать следующие метрики:

**Заказано товаров** — общее количество заказанных товаров, включая отмены и возвраты.

**Заказано на сумму** — общая стоимость заказанных товаров, включая отмены и возвраты.

**Доставлено (за выбранный период)** — учитываем в данных за день доставки.

# Как настроить показатели (метрики) для аналитики по кластерам

Выбрать показатели можно двумя способами:

1. В верхней части графика нажмите **Заказано товаров**. В выпадающем списке выберите нужный показатель.
2. В правой нижней части таблицы в поле **Настройка показателя** нажмите **Настроить**. Откроется окно— нажмите на название метрики, а затем **Применить**.

# Как сравнивать метрики для аналитики по кластерам

На графике можно сравнить показатели двух разных кластеров. Для этого:

1. Выберите первый кластер.
2. Активируйте переключатель **Сравнение **.
3. Выберите второй кластер.
4. Выберите, для каких товаров или групп хотите посмотреть статистику — для этого нажмите  рядом с ними. Товары можно сгруппировать по кластерам, в которых они размещены, брендам, моделям и категориям. [Как настроить группировки](#%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D0%B3%D1%80%D1%83%D0%BF%D0%BF%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B8-%D0%B4%D0%BB%D1%8F-%D0%B0%D0%BD%D0%B0%D0%BB%D0%B8%D1%82%D0%B8%D0%BA%D0%B8-%D0%BF%D0%BE-%D0%BA%D0%BB%D0%B0%D1%81%D1%82%D0%B5%D1%80%D0%B0%D0%BC)

**Пример.** Вы хотите сравнить как продаются товары со складов в Москве и области в кластерах Рязань и Тула. Для этого сначала выберите один из кластеров продажи, например, Рязань. Затем активируйте переключатель **Сравнение **. Выберите второй кластер — Тула. Чтобы посмотреть графики для товаров из Москвы и области, нажмите  рядом с нужной группой. Теперь можно сравнивать заказы на графиках.
