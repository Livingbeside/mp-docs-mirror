# Категории

_Главная / Аналитика / Аналитика площадки — только для Premium-продавцов_

Как анализировать товары в категории, выбирать популярные для продажи, оценить конкуренцию с помощью бесплатного отчёта для всех продавцов

# Вебинар «Выбор ниши для старта на Ozon»

В разделе **[Аналитика → Категории](https://seller.ozon.ru/app/analytics/what-to-sell/categories-comparison)** можно:

выбрать перспективную категорию или бренд для продажи;

оценить конкуренцию в категории;

узнать, по какой схеме выгоднее продавать товары категории;

посмотреть, в каких регионах товары категории заказывают чаще всего;

сравнить разные ценовые сегменты и выбрать, в каком из них продавать.

По подписке [Premium Brand](/account-brand/podpiska-premium-brand) представители бренда дополнительно смогут:

[определить ](#как-определить-долю-продаж-в-категории-для-представителеи-бренда)долю продаж бренда в категории;

отслеживать динамику продаж;

выбрать перспективную категорию для реализации;

сравнить цены разных брендов.

В блоке **Анализ конкурентов** в **Аналитике** сравниваем ваши продажи со средними показателями в категории. Проверяем 3 категории с самым большим суммарным оборотом.

Здесь отображается:

заказано на сумму — стоимость всех заказанных товаров без учёта возвратов и отмен;

доля моего магазина — сравниваем ваши показатели и среднее значение в категории;

заказано на сумму в категории — суммарная стоимость всех заказанных товаров в категории.

Показываем среднее значение за последние 7 дней и как показатель изменился с прошлой недели.

Ваша динамика покажет, верную ли стратегию вы выбрали, а разница с лидерами подскажет, насколько большой потенциал у категории и насколько ваши товары интересны.

# Как работать с отчётом «Категории»

1. Нажмите **Категория** и выберите категорию 1, 2 или 3 уровня, которую хотите проанализировать.
2. Если нужно, выберите конкретный бренд, продавца или страну — эти фильтры доступны с подпиской [Premium Plus](/seller-rating/about-rating/subscription-premium-plus) или [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro). Покажем данные только по обороту этого бренда, продавца или в этой стране, а не по всей категории.
  Если хотите посмотреть данные по всей категории, оставьте эти фильтры пустыми.
3. Чтобы посмотреть данные только по определённым ценовым диапазонам, настройте фильтр **Цена**.
4. Для категорий «Обувь», «Одежда», «Галантерея и аксессуары» и «Ювелирные изделия» можно выбрать фильтр **Пол**.
5. Выберите период — по умолчанию показываем данные за 28 дней, но можно выбрать год, квартал и 7 дней.
  Для каждой задачи подойдёт свой период: например, по данным за год можно проверить сезонность категории или оценить динамику продаж в долгосрочной перспективе. А чтобы посмотреть более свежие данные — например, сколько продавцов сейчас в конкретной категории и какой уровень конкуренции — выберите 7 или 28 дней.
6. Выберите разрез данных:
  **Категории** — покажем данные по выбранной категории. Если выбрали категорию 2 уровня — то покажем данные по более мелким категориям внутри.
  
  **Бренды** — по подписке [Premium Plus](https://seller-edu.ozon.ru/ru/seller-rating/about-rating/subscription-premium-plus) покажем данные по 30 брендам, которые лучше всего продаются в выбранной категории. По подписке [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro) — по всем брендам в категории.
  
  **Продавцы** — по подписке [Premium Plus](https://seller-edu.ozon.ru/ru/seller-rating/about-rating/subscription-premium-plus) показываем данные по 30 продавцам-лидерам в выбранной категории. По подписке [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro) — по всем продавцам в категории.
  
  **Ценовые сегменты** — сравните показатели разных ценовых сегментов категории. Это поможет понять, товары с какой стоимостью заказывают чаще и в каком сегменте ниже конкуренция.
  
  **География продаж** — сравните показатели по [кластерам](/fbo/warehouses/table-klastery?search=%D0%BA%D0%BB%D0%B0%D1%81%D1%82%D0%B5%D1%80) продаж. Посмотрите, где чаще всего заказывают товары выбранной категории — это поможет определиться, куда поставлять товары, если вы ещё не продавали такую категорию.
  
  **Схемы продаж** — сравните показатели для [FBO](/fbo) и [FBS](/fbs) внутри категории, чтобы определить более выгодную для себя схему.
7. Для продавцов с подписками [Premium Lite](/seller-rating/about-rating/podpiska-premium-lite?search=premium+lite), [Premium](/seller-rating/about-rating/premium-program), [Premium Plus](/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro) по умолчанию включим настройку **Мой магазин**. С ней вы сможете сравнивать показатели своего магазина в разрезе данных по:
  категориям;
  
  брендам — доступно только с подпиской [Premium Plus](/ru/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro);
  
  продавцам — доступно только с подпиской [Premium Plus](/ru/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro);
  
  странам продавца — доступно только с подпиской [Premium Plus](https://seller-edu.ozon.ru/ru/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](https://seller-edu.ozon.ru/seller-rating/about-rating/podpiska-premium-pro);
  
  ценовым сегментам;
  
  схемам продаж;
  
  географиям продаж.

В подписке [Premium Lite](/seller-rating/about-rating/podpiska-premium-lite?search=premium+lite) настройка **Мой магазин** доступна только пользователям с ролью «Аналитик».

1. Чтобы загрузить отчёт в формате XLSX, нажмите **Скачать**.

# На какие показатели обратить внимание

Если настроите фильтр по брендам, продавцам и странам — то покажем данные не по всей категории, а по объёму продаж выбранных брендов, продавцов и в выбранной стране.

Например, если выберете категорию «Канцелярия», период в 28 дней и отметите 5 брендов и 10 продавцов, а также выберете страну Китай — все данные будут считаться именно от продаж этих 5 брендов у тех продавцов из выбранных 10, которые зарегистрированы в Китае.

| **Показатель** | **Что означает** | **Как использовать** |
| --- | --- | --- |
| **Заказано на сумму, ₽** | Общая стоимость товаров, заказанных по категории, бренду или другому разрезу данных за период. Учитываем все заказы, включая отмены и возвраты. Для расчёта берём цену продавцов | Поможет сравнить потенциал категорий, брендов — и даже регионов, если нужно определиться с поставками |
| **Динамика суммы заказов****, %** | Как изменилась сумма заказов по отношению к предыдущему периоду. Например, если выбрали в фильтре период в год — покажем, насколько изменилась сумма заказов по сравнению с предыдущим годом | Поможет определить тренд и не ошибиться в нише. Например, если в какой-то категории небольшой объём продаж, но за последний год он сильно вырос — возможно, эта тенденция сохранится, и категория продолжит расти |
| **Заказано товаров, шт** | Общее количество товаров, заказанных по категории или другому разрезу данных за период. Учитываем все заказы, включая отмены и возвраты | Поможет оценить спрос в конкретной категории — чем больше товаров заказали, тем выше спрос |
| **Средняя цена, ₽** | Средняя цена, которую продавцы установили на товар, без учёта дополнительной скидки, за которую начисляем баллы. Если за период в категории продали 70 товаров по 1000 рублей и ещё 30 товаров по 1500 рублей, то средняя цена равна: (1000 × 70 + 1500 × 30) / 100 = 1150 рублей | Поможет рассчитать примерные доходы и расходы с помощью [онлайн-калькулятора](https://calculator.ozon.ru/) и сравнить разные категории |
| **Динамика средней цены, %** | Изменение средней цены по отношению к предыдущему периоду. Например, если выбрали в фильтре период в год — покажем, насколько изменилась средняя цена по сравнению с предыдущим годом | Покажет, как меняется средняя цена товара в категории — растёт или наоборот падает |
| **Число продавцов** | Количество продавцов, которые продавали товары в конкретной категории или другом разрезе данных | Поможет оценить уровень конкуренции и, например, посчитать средний оборот продавца в конкретной категории |
| **Число брендов** | Количество брендов, которые продавались в категории или у конкретного продавца | Поможет оценить, как много брендов уже есть в категории и стоит ли выводить туда новый бренд |
| **Число кластеров ** | Количество кластеров, где заказывали товары конкретного бренда или продавца | Можно посмотреть, как распределилась география продаж бренда или продавца. Чем больше зон продаж, тем больше разных регионов, в которых покупают товары — это поможет спланировать поставки, чтобы покрыть всю географию |
| **Доля выкупа, %** | Как часто покупатели выкупают товары категории, бренда или продавца, не отменяя заказ и не оформляя возврат. Чем выше процент, тем реже возвращают товары. Считаем так: например, если товар заказали 50 раз, но отменили 3 раза и вернули 2 раза — его уровень выкупа будет (50 – 3 – 2) / 50 = 90% | Метрика поможет точнее посчитать оборот категории, бренда или продавца, так как показатель **Заказано на сумму** не учитывает возвраты и отмены. |
| **Доля топ-5 продавцов, %** | Какой процент суммы заказов приходится на 5 лидеров категории | Поможет определить, выбирают ли покупатели других продавцов или предпочитают уже устоявшихся лидеров. Чем ниже процент, тем ниже уровень монополизации в категории и тем чаще покупатели выбирают товары других продавцов |
| **Доля в категории, % ** | Процент от суммы всех заказов в выбранной категории. Если выбрали в фильтрах конкретные бренды — будем считать процент от их продаж,  а не от всей категории. Долю можно посмотреть как для подкатегории, бренда или продавца, так и для схемы или зоны продаж | Например, если планируете продавать товары уже существующего бренда, можно оценить, насколько он востребован. А ещё посмотреть, как распределился оборот по продавцам этого бренда — есть ли лидер, которого будет сложно обогнать, или конкуренция более равномерная |

# Как сравнить показатели на графике

1. Настройте фильтры и разрезы под свою задачу.
2. В таблице включите переключатель для тех строк, которые хотите вывести на график (можно выбрать не больше 10 строк).
3. Слева от графика выберите метрику, которую хотите сравнить, и включите её.
4. Покажем на графике, как менялся показатель в течение выбранного периода. А разными линиями обозначим строки, которые вы выбрали в таблице.

# Как решать задачи бизнеса с помощью аналитики

## Как выбрать перспективную категорию для продажи

1. Выберите в фильтрах категорию 2 уровня, например, **Повседневная обувь** — сможете сравнить более маленькие подкатегории внутри и определить самую перспективную.
2. Выберите период и разрез **Категории**.
3. Сравните категории, которые входят в выбранную, используя сортировку в таблице и график.  Особенно обратите внимание на:
  общий оборот по категории в рублях и штуках, чтобы оценить объём категории в целом;
  
  долю выкупов, чтобы точнее посчитать потенциал категории с учётом возвратов и отмен, и найти категорию, товары которой реже всего возвращаются клиентами;
  
  динамику продаж — она покажет, растёт востребованность категории или наоборот снижается;
  
  среднюю цену товара, чтобы сделать примерные расчёты доходов и затрат;
  
  число продавцов — оно покажет, насколько высок уровень конкуренции в категории;
  
  долю топ-5 продавцов, чтобы узнать, насколько большой объём рынка забрали себе лидеры (или наоборот, конкуренция более равномерная, и покупатели выбирают разных продавцов).

С подпиской [Premium](/seller-rating/about-rating/premium-program) можно сравнить показатели своего магазина с данными по категории.

## Как выбрать перспективный бренд

1. Выберите в фильтрах категорию 1, 2 или 3 уровня, в которой хотите проанализировать бренды.
2. Выберите период и разрез **Бренды**.
3. Покажем в таблице топ-30 брендов категории по обороту. Сравните бренды, используя сортировку и график. Особенно обратите внимание на:
  общий оборот и динамику заказов, чтобы оценить востребованность бренда;
  
  число продавцов, чтобы оценить конкуренцию;
  
  долю оборота — она покажет, какую долю общего спроса по категории покрывает бренд.
  Можно проверить показатели конкретного бренда: для этого введите его название в фильтре **Бренд** и выберите разрез **Бренды** — покажем метрики в таблице.

С подпиской [Premium Plus](/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro) можно сравнить свою долю продаж конкретного бренда со всеми продажами в категории.

## Как оценить конкуренцию среди продавцов в категории

1. Выберите в фильтрах категорию 1, 2 или 3 уровня, с которой планируете выходить на маркетплейс.
2. Выберите период и разрез **Категории**, чтобы посмотреть общее число продавцов.
3. С подпиской Premium Plus можно посмотреть более детальные данные — для этого выберите разрез **Продавцы**. Покажем в таблице топ-30 продавцов категории по обороту. Можно посмотреть:
  какие показатели у лидера в категории;
  
  какой у него отрыв от конкурентов;
  
  какая у него доля оборота в категории.

С подпиской [Premium Plus](/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](/seller-rating/about-rating/podpiska-premium-pro) можно сравнить показатели своего магазина с продажами конкурентов в конкретной категории.

## Как сравнить разные схемы продаж

1. Выберите в фильтрах категорию 1, 2 или 3 уровня, с которой планируете выходить на маркетплейс.
2. Выберите период и разрез **Схемы продаж**.
3. В таблице и на графике посмотрите, как по разным схемам распределился оборот и количество продавцов.

С любой из подписок [Premium](https://seller-edu.ozon.ru/libra/seller-rating) можно сравнить оборот своего магазина по схемам продаж.

## Как определить, в какие регионы поставлять товары

1. Выберите в фильтрах категорию 1, 2 или 3 уровня, с которой планируете выходить на маркетплейс.
2. Выберите период и разрез **География продаж**.
3. Покажем в таблице данные по всем кластерам, в которых заказывают товары категории. Рекомендуем выбирать для поставок именно те регионы, где чаще покупают товар — так логистика будет дешевле, а доставка быстрее.

С подпиской [Premium Plus](https://seller-edu.ozon.ru/seller-rating/about-rating/subscription-premium-plus) и [Premium Pro](https://seller-edu.ozon.ru/seller-rating/about-rating/podpiska-premium-pro) можно выбрать в фильтре нужную страну — и посмотреть данные по продавцам только из этой страны.

## Как определить долю продаж в категории для представителей бренда

1. Выберите в фильтрах категорию 1, 2 или 3 уровня, в которой хотите проанализировать бренды.
2. Выберите период и разрез **Бренды**.
3. Покажем в таблице топ-30 брендов категории по обороту. Оцените конкуренцию в категории и определите свою долю на рынке — это поможет понять, какую часть общего спроса в категории занимает ваш бренд.
  Можно проверить показатели конкретного бренда: для этого введите его название в фильтре **Бренд** и выберите разрез **Бренды** — покажем метрики в таблице.

## Как выбрать, в каком ценовом сегменте продавать

1. Выберите в фильтрах категорию 1, 2 или 3 уровня, с которой планируете выходить на маркетплейс.
2. Выберите период.
3. Выберите разрез **Ценовые сегменты**.
4. Покажем в таблице данные по разным ценовым сегментам, в которых есть товары категории.
5. Если нужно, настройте вид графика. По умолчанию открыт столбчатый график (гистограмму), который покажет общие показатели по выбранным ценовым сегментам за период. Чем выше столбец сегмента — тем выше показатель. Можно переключиться на линейный график, где будут данные выбранных ценовых сегментов в динамике по дням.
