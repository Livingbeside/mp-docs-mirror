# Процент жалоб

_Главная / Аналитика / Качество работы_

Как рассчитывается процент жалоб по отправлениям (заказам) и как за ним следить

# Что такое процент жалоб

Это процент отправлений, которые вы доставили за последние 14 дней и на которые получили жалобы.

учитываем все [жалобы](https://seller.ozon.ru/app/complaints), кроме сообщений о подделках;

рассчитываем показатель для каждой схемы работы отдельно.

[Подробнее о жалобах](/seller-rating/additionally/complaint)

# Как следить за процентом жалоб

Есть несколько способов:

| Канал | Что узнаете |
| --- | --- |
| Отчёт в разделе **[Аналитика → Отчёты → Контроль качества → Процент жалоб](https://seller.ozon.ru/app/analytics/fulfillment-reports/complaints)** | Для каждой схемы работы сформируем отдельный отчёт. Покажем:      	какие отправления участвовали в расчёте;процент жалоб. |
| Разделы: **[Аналитика → Качество работы → Процент жалоб → Жалобы по FBS](https://seller.ozon.ru/app/rating/complaints)** или **[Товары → Отзывы → Жалобы](https://seller.ozon.ru/app/complaints)**;**[Аналитика → Качество работы → Процент жалоб → Жалобы по realFBS](https://seller.ozon.ru/app/rating/complaints)**;**[Аналитика → Качество работы → Процент жалоб → Жалобы по realFBS Express](https://seller.ozon.ru/app/rating/complaints)**. | Значение показателя для каждой схемы работы. |

# Как рассчитываем процент жалоб

Формула расчёта:

Количество отправлений за 14 дней — сколько всего отправлений вы доставили за последние 14 дней.

Количество отправлений с жалобами — сколько из этих отправлений получили жалобы. Не учитываем жалобы на подделки и те, которые вы [оспорили](/seller-rating/additionally/complaint#%D0%BA%D0%B0%D0%BA-%D0%BE%D1%81%D0%BF%D0%BE%D1%80%D0%B8%D1%82%D1%8C-%D0%B6%D0%B0%D0%BB%D0%BE%D0%B1%D1%83). Посмотреть все свои жалобы можно в разделе **[Товары → Жалобы](https://seller.ozon.ru/app/complaints)**.

Показатель рассчитываем для каждой схемы отдельно: FBS, realFBS Standard и realFBS Express, если на схеме было меньше 10 отправлений за последние 14 дней.

Процент жалоб рассчитывается для наглядности и не влияет на работу магазина. Но если показатель выше 20%, значит качество услуг ухудшилось и нужно отладить процессы. Для этого:

изучите комментарии и фото клиентов в жалобах;

воспользуйтесь [нашими рекомендациями](/seller-rating/additionally/complaint#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82-%D0%B6%D0%B0%D0%BB%D0%BE%D0%B1%D1%8B-%D0%B8-%D0%BA%D0%B0%D0%BA-%D0%B8%D1%85-%D0%B8%D0%B7%D0%B1%D0%B5%D0%B6%D0%B0%D1%82%D1%8C).
