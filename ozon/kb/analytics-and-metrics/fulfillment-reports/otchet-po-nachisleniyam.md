# Отчёт по начислениям

_Главная / Аналитика / Отчёты_

Как с помощью отчёта узнать, когда и за какую цену был оформлен заказ, размер вознаграждения Ozon и расходы на инструменты продвижения

Отчёт содержит информацию о начислениях по доставленным заказам, отменам и возвратам. В нём можно узнать, когда и за какую цену был оформлен заказ, каким было вознаграждение Ozon, расходы на инструменты продвижения и другие детали.

[Подробнее о финансах в личном кабинете](/finances-documents/calculations-documents/work-with-finance)

# Как скачать отчёт

После 3 августа 2026 года уберём отчёт по товарам — его полностью заменит отчёт по начислениям.

1. Перейдите в раздел **[Финансы ](https://seller.ozon.ru/app/finances/accruals)**[→](https://seller.ozon.ru/app/finances/accruals)**[ Экономика магазина](https://seller.ozon.ru/app/finances/accruals)**.
2. Нажмите **Скачать отчёт**.
3. Выберите **По начислениям**.
4. Укажите период, за который вам нужны данные. Данные доступны только с 2022 года.
5. Нажмите **Скачать**.

# Из чего состоит отчёт

В отчёте показываем услуги в строках, чтобы было удобнее анализировать данные в сводных таблицах в Exсel.

Пояснения к некоторым столбцам:

| Название столбца | Объяснение | Пример |
| --- | --- | --- |
| ID начисления | Идентификатор начисления. Это может быть номер заказа, отправления, поставки или период подписки | 11111111-111 01.08.25-01.09.25 |
| Группа услуг | Объединённые по группам виды начислений: продажи, возвраты, доставка, продвижение. Названия групп такие же, как и в других блоках раздела **Финансы** | Продажи Услуги партнёров |
| Тип начисления | Услуга, за которую начислили плату. Названия услуг такие же, как и в других блоках раздела **Финансы** | Обработка отправления Drop-off (СЦ) Эквайринг |
| Цена продавца | Цена, которую вы установили на товар | 1687,00 |
| Среднее время доставки, часы | Время перемещения товаров между кластерами по всем маршрутам за 28 дней | 29 |

# Как получить старый формат отчёта по товарам

Отчёт по товарам отражал в строке номер идентификатора, а в столбцах — сумму по некоторым услугам на единицу проданного товара. В отчёте по начислениям каждая услуга отражается отдельной строкой. Все суммы сходятся до копеек.

1. В разделе **[Финансы ](https://seller.ozon.ru/app/finances/accruals)**[→](https://seller.ozon.ru/app/finances/accruals)**[ Экономика магазина](https://seller.ozon.ru/app/finances/accruals)** на вкладке **Детализация начислений** скачайте отчёт по начислениям за нужный период.
2. Выделите все данные в таблице — для этого нажмите Ctrl+A или на левый верхний угол таблицы.
3. Выберите в меню вкладку **Вставка**, затем **Сводная таблица**. В открывшемся окне уже выбраны все данные и предустановлено, что сводная таблица будет на новом листе. Нажмите **ОК**.
4. Чтобы получить разбивку всех услуг на ID начисления, на новом листе в области **Поля сводной таблицы**:
  **ID начисления **перетаскиваем в блок **Строки**;
  
  **Тип начисления** перетаскиваем в блок **Столбцы**;
  
  **Сумму итого, руб** перетаскиваем в блок **Значения;**
  
  В блок** Фильтры** можно добавлять нужные параметры: схему работы, тип или дату начисления и другое.

Для удобства можно свернуть или развернуть все данные в строках — нажмите на нужную строку правой кнопкой мыши и выберите в **Развернуть/свернуть**.

Как сводную таблицу сделать обычной

1. Кликните по любому месту таблицы, чтобы активировать верхние вкладки.
2. Перейдите на вкладку **Конструктор**.
3. В группе **Макет **нажмите **Макет отчёта.**
4. Выберите **Показать в табличной форме.**

После этого каждое поле из области **Строки** будет отображаться в отдельном столбце.

Как убрать промежуточные или общие итоги

1. Кликните по любому месту таблицы, чтобы активировать верхние вкладки.
2. Перейдите на вкладку **Конструктор:**
  нажмите **Промежуточные итоги** и выберите **Не показывать промежуточные итоги**;
  
  нажмите **Общие итоги** и выберите **Отключить для строк и столбцов**.
