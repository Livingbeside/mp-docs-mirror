# Отчёты по продажам со склада Ozon

_Главная / Аналитика / Отчёты_

Как с помощью отчётов проверить, как менялся остаток товаров на складах Ozon, какие товары продаются с уценкой

Отчёт по клиентским возвратам и отменам теперь можно скачать в разделе **[Аналитика → Отчёты → Возвраты](https://seller.ozon.ru/app/analytics/fulfillment-reports/fbo-reasons)**. [Подробнее](/analytics-and-metrics/fulfillment-reports/otchet-po-vozvratam)

# Как скачать отчёты по продажам со склада Ozon

1. Перейдите на страницу **[Аналитика → Отчёты](https://seller.ozon.ru/app/analytics/fulfillment-reports/all-products)**** **и выберите **Продажи со склада Ozon**.
2. Выберите один из отчётов:
  [Оборотная ведомость по товарам](https://seller.ozon.ru/app/analytics/fulfillment-reports/stocks-and-movement-products);
  
  [Товары, уценённые Ozon](/analytics-and-metrics/fulfillment-reports/prodaji-so-sklada-ozon#%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D1%8B-%D1%83%D1%86%D0%B5%D0%BD%D1%91%D0%BD%D0%BD%D1%8B%D0%B5-ozon);
  
  [Управление остатками](#управление-остатками).
3. Выберите период, за который вам нужны данные. Если история их изменения недоступна, в периоде будет указано **На текущий момент** — изменить такой период нельзя. В отчёте будут указаны данные по состоянию на момент загрузки.
4. Нажмите **Скачать отчёт**.

# Что содержат отчёты по продажам со склада Ozon

## Товары, уценённые Ozon

[Отчёт в личном кабинете](https://seller.ozon.ru/app/analytics/fulfillment-reports/discount-products)

[Подробнее об уценённых товарах](/work-with-goods/ucenka/ucenka)

Отчёт содержит данные о товарах на складе Ozon, которые незначительно повреждены и продаются с уценкой.

Пояснения к некоторым полям:

| Название столбца | Объяснение | Пример |
| --- | --- | --- |
| Артикул | Идентификатор товарной позиции. | xxxx |
| FBO Ozon SKU ID | Идентификатор товара до уценки. | aaaaaaaaa |
| FBO Ozon SKU ID (уценённый товар) | Идентификатор, который товар получил после уценки. | bbbbbbbbb |
| Наименование товара | Название товара, отображающееся в его карточке. | Фен для волос Scarlett SC-074, серый |
| Бренд | Фирма товара. | NAME BRAND |
| Состояние товара | Текущее состояние уценённого товара по оценке сотрудника склада. | Как новый |
| Причина уценки | Причина, по которой товар был уценён на складе. Причин может быть несколько. | Механическое повреждение изделия, некомплект (менее 50%) |
| Дополнительная информация по уценённому товару | Более подробная информация о причине уценки. Если в поле **Причина уценки** пусто, то все причины будут здесь. | Отсутствует заводская упаковка. Товар не пострадал, потребительские свойства сохранены. |
| Статус товара | Продаётся ли уценённый товар на Ozon. | Продаётся |
| Видимость на сайте | Показывается ли товар на сайте Ozon. | Показывается |
| Доступно на складе Ozon, шт | Остаток уценённых товарных единиц. | 1 |
| Текущая цена с учётом скидок, руб. | Цена, по которой уценённый товар можно купить на Ozon. | 2449.00 |
| Текущая цена с учётом скидок, руб. | Цена, по которой товар можно купить на Ozon без уценки. | 3449.00 |

## Управление остатками

Отчёт показывает остатки товаров на складах и в пути на текущую дату. Обновляем его раз в сутки.

Чтобы скачать отчёт, выберите тип склада и нажмите **Скачать отчёт**.

[Какие товары показываем в отчёте](/fbo/rabota-so-stokom/upravlenie-ostatkami-i-likvidnost-tovarov#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D1%8B-%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D1%8B%D0%B2%D0%B0%D0%B5%D0%BC-%D0%B2-%D0%BE%D1%82%D1%87%D1%91%D1%82%D0%B5)

[Отчёт в личном кабинете](https://seller.ozon.ru/app/supply/stocks-management/reports) можно сформировать с 1 января 2022 года до даты на двое суток меньшей текущего числа. Максимальный период для выгрузки — 1 год. Отчёт будет пустым, если вы не продаёте товары по схеме FBO. Из отчёта можно узнать, сколько ваших товаров находится на складах Ozon, а также посмотреть движение остатков за выбранный период.

Пояснения к полям отчёта:

| **Общее название** | **Название столбца** | **Объяснение** | **Пример** |
