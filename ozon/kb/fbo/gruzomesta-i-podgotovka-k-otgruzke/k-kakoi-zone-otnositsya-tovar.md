# Как узнать, к какой зоне размещения относится товар

_Главная / Продажа со склада Ozon (FBO) / Грузоместа и подготовка к отгрузке_

Как определить зону размещения товара, чтобы не переплачивать за сортировку при приёмке

На складах распределяем товары из грузомест по зонам размещения. Чтобы не платить за сортировку по зонам при приёмке, не добавляйте товары из разных зон в одно грузоместо.

Например, вы хотите отгрузить на склад компьютерные мыши, клавиатуры и мониторы. Мыши и клавиатуры по своим габаритам подходят для зоны сортируемого товара — для них можно создать одно грузоместо. Мониторы отправятся в зону для несортируемого товара, поэтому для них нужно создать отдельное грузоместо.

# Какие бывают зоны размещения

Зоны размещения и характеристики товаров в них:

| **Зона размещения** | **Какие товары относятся** |
| --- | --- |
| Сортируемый товар | Небольшие товары с весом до 10 кг и габаритами: длина ≤ 450 мм ширина ≤ 320 мм высота ≤ 320 мм Разместим их в ячейках стандартного размера |
| Несортируемый товар | Крупные товары весом до 35 кг включительно и габаритами: 450 мм ≤ длина ≤ 1200 мм 320 мм ≤ ширина ≤ 600 мм 320 мм ≤ высота ≤ 500 мм Такие товары не размещаем в стандартных ячейках |
| Продукты | Пищевая продукция, для хранения которой нужен специальный температурный режим |
| Опасный товар | Газы, легковоспламеняющиеся жидкости, химикаты и другие [опасные товары](https://seller-edu.ozon.ru/policies/documents-violations/opasnie_tovary#%D1%87%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D1%8B%D0%B5-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D1%8B-%D0%B3%D1%80%D1%83%D0%B7%D1%8B) |
| Закрытая зона | Дорогие товары, товары 18+ и товары с повышенным риском утери — разместим в зоне с ограниченным доступом |
| Крупногабаритный товар | Крупные товары весом до 120 кг и габаритами: 450 мм ≤ длина ≤ 2200 мм320 мм ≤ ширина ≤ 1200 мм320 мм ≤ ширина ≤ 800 мм |
| Ювелирные изделия | Ювелирные изделия — можно поставлять только на [ювелирные склады](https://seller-edu.ozon.ru/jewerly/fbo/supply-jewelery#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D1%81%D1%82%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D1%8B-%D0%BD%D0%B0-%D1%81%D0%BA%D0%BB%D0%B0%D0%B4) |

# Как проверить зону размещения товара

### При создании заявки на поставку

Откройте список товаров для кластера и проверьте зону размещения для каждого товара.

### В черновике заявки на поставку

1. Откройте раздел** ****[FBO → Заявки на поставку](https://seller.ozon.ru/app/supply/orders)**.
2. Нажмите на номер нужной заявки.
3. Откройте вкладку **Отгрузка и список поставок.**
4. Нажмите **Управляйте товарным составом**.
5. В открывшемся окне нажмите **Скачать XLS.**

### В списке товаров в грузоместах

1. Откройте раздел** ****[FBO → Заявки на поставку](https://seller.ozon.ru/app/supply/orders)**
2. Нажмите на номер нужной заявки.
3. Откройте вкладку **Грузоместа**.
4. Откройте состав нужного грузоместа.
5. В открывшемся окне увидите, к каким зонам размещения относятся добавленные товары.

### В файле c составом товаров в грузоместе

1. Откройте раздел **[FBO → Заявки на поставку](https://seller.ozon.ru/app/supply/orders)**.
2. Нажмите на номер нужной заявки.
3. Откройте вкладку **Грузоместа. **
4. Нажмите **Скачать **и выберите **Состав через XLS**.
5. В таблице проверьте, к каким зонам размещения относятся товары.

### В разделе «Управление остатками»

1. Откройте раздел **[FBO → Управление остатками](https://seller.ozon.ru/app/fbo-stocks/stocks-management)**.
2. Найдите нужный товар.
3. Проверьте зону размещения под названием товара.

**В разделе «Управление остатками»**:

1. Откройте раздел **[FBO](https://seller.ozon.ru/app/fbo-stocks/stocks-management)**[ → ](https://seller.ozon.ru/app/fbo-stocks/stocks-management)**[Управление остатками](https://seller.ozon.ru/app/fbo-stocks/stocks-management)**.
2. Примените нужные фильтры.
3. Нажмите **Скачать отчёт**.

**Для заявки на поставку**:

1. Перейдите в раздел **[FBO](https://seller.ozon.ru/app/supply/orders)**[ → ](https://seller.ozon.ru/app/supply/orders)**[Заявки на поставку](https://seller.ozon.ru/app/supply/orders)** и выберите нужный номер заявки.
2. Откройте вкладку **Отгрузка и список поставок**, затем нажмите **Управляйте товарным составом**.
3. Нажмите **Скачать XLS** в появившемся окне.

**Для конкретного грузоместа**:

1. Перейдите в раздел **[FBO](https://seller.ozon.ru/app/supply/orders)**[ → ](https://seller.ozon.ru/app/supply/orders)**[Заявки на поставку](https://seller.ozon.ru/app/supply/orders)** и выберите нужный номер заявки.
2. Откройте вкладку **Грузоместа**.
3. Нажмите **Скачать** и выберите пункт **Состав через XLS** для проверки зон размещения позиций.
