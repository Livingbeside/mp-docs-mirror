# ГТД для продажи юрлицам

_Главная / Продажа со склада Ozon (FBO) / Документы при поставках_

В каких случаях нужен номер грузовой таможенной декларации, как его правильно указать и загрузить

# Что такое ГТД

Грузовая таможенная декларация (ГТД) — документ, который позволяет легально перевозить импортную продукцию через границу. Там содержится информация о грузе, транспорте, таможенной стоимости товара, отправителе и получателе.

Декларация нужна для продукции из любой страны, кроме России, Белоруссии, Казахстана, Армении и Киргизии и Узбекистана. ГТД не нужен, если вы производите продукцию самостоятельно.

ГТД могут предоставлять юрлица и физлица при любой схеме работы — FBO, FBS, realFBS.

При [поставках](/fbo/process-details/fill-in-application-form) указывать номер ГТД в личном кабинете или [УПД-2](/fbo/documents/hand-in-UPD-2) необязательно — примем товары на склад без него. Если декларацию запросит покупатель-юрлицо, чтобы вернуть НДС — сами напишем вам и попросим номер. Но мы всё равно советуем его указывать, потому что так клиенту не придётся ждать ответа — и в следующий раз он с большей вероятностью повторит заказ.

[Подробнее о продажах юрлицам](/finances-documents/sales-to-legal-entities/prodazhi-urlicam)

# Как узнать номер ГТД

Узнать номер ГТД можно:

из таможенной декларации, которую вы получили, когда ввозили продукцию из-за границы;

у поставщика, который продал вам товар и сам его растаможил.

# Как правильно указывать номер ГТД в шаблоне

[Подробнее о том, где скачать шаблон ГТД](/fbo/documents/upload-gtd#%D0%BA%D0%B0%D0%BA-%D0%B7%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%B8%D1%82%D1%8C-%D0%B3%D1%82%D0%B4)

Чтобы система правильно распознала номер ГТД, он должен:

Содержать до 29 символов.

Состоять только из цифр и символов «/» — без букв, точек и запятых.

Быть единственным в ячейке. Если в поставке есть позиции, у которых несколько номеров ГТД, не указывайте их совсем — мы сами запросим, когда они понадобятся.

Если в товарном составе заявки на поставку товары из России, оставьте поле ГТД в файле пустым.

| ЕАЭС N RU Д-RU.А.В.24485/19 |  |
| /090821/0245105, Китай |  |
| 10013250/151131/0715443, 10028160/151951/0715334 |  |

# Как загрузить ГТД

1. В разделе **[FBO → Заявки на поставку → Подготовка к поставкам](https://seller.ozon.ru/app/supply/orders?filter=SupplyPreparation)** выберите заявку или [создайте новую](/fbo/process-details/fill-in-application-form#%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B7%D0%B0%D1%8F%D0%B2%D0%BA%D1%83-%D0%BD%D0%B0-%D0%BF%D0%BE%D1%81%D1%82%D0%B0%D0%B2%D0%BA%D1%83).
2. В блоке с нужной поставкой выберите **Загрузить ГТД**.
3. В открывшемся окне нажмите **Скачать шаблон ГТД**.
4. Откройте скачанный файл XLSX и заполните:
  **Код страны происхождения** по [ОКСМ](https://ru.wikipedia.org/wiki/%D0%9E%D0%B1%D1%89%D0%B5%D1%80%D0%BE%D1%81%D1%81%D0%B8%D0%B9%D1%81%D0%BA%D0%B8%D0%B9_%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%BE%D1%80_%D1%81%D1%82%D1%80%D0%B0%D0%BD_%D0%BC%D0%B8%D1%80%D0%B0) — если в карточке товара указана страна-изготовитель, система сама добавит данные;
  
  **ГТД** — номер грузовой таможенной декларации.
5. Сохраните файл и загрузите в личном кабинете.

Сам файл с ГТД не будет отображаться в личном кабинете. Но система покажет сообщение, что документ успешно загружен, и изменит статус заявки. Если в файле будет ошибка, сможете добавить ещё один.
