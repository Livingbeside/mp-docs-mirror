# Ошибки в УПД и ЭДО

_Главная / Продажа со склада Ozon (FBO) / Документы при поставках_

Какие бывают ошибки при формировании УПД и как их исправить

Собрали на одной странице решения наиболее распространённых ошибок при формировании УПД и его отправке через ЭДО. Для некоторых ошибок указываем номер строки, в которой они обнаружены.

Чтобы быстрее найти нужную ошибку, скопируйте её текст и воспользуйтесь поиском по статье через комбинацию «Ctrl+F».

# При каких поставках могут возникнуть ошибки

## Поставки товаров, подлежащих обязательной маркировке

| Текст ошибки | Решение |
| --- | --- |
| Код маркировки находится в некорректном статусе: «перечисляем первые 5 КМ». Код маркировки должен быть в статусе «В обороте». Проверьте статусы кодов маркировки, указанных в УПД. Коды маркировки, находящиеся в статусе «Эмитирован. Получен» и «Эмитирован. Выпущен» необходимо ввести в оборот. Обработка УПД приостановлена. | Проверьте, что КИЗ (коды маркировки) в УПД указаны правильно. Если это не так —  отправьте новый УПД без КИЗ. Если КИЗ указаны верно, введите их в оборот в системе «Честный ЗНАК» (ЦРПТ) в соответствии с УПД. Затем: 1. Введите товар в оборот в ГИС МТ в системе «Честный ЗНАК» и смените статус товара на «В обороте». 2. Аннулируйте ошибочный УПД в ЭДО и загрузите новый. |
| Штрихкод товара (04620068073943) не соответствует GTIN (04620068073974) в коде маркировки. Загрузите его на карточку товара, где находится штрихкод, соответствующий данному товару GTIN. Обработка УПД приостановлена. | 1. Загрузите актуальные штрихкоды в карточку товара. 2. Аннулируйте ошибочный УПД в ЭДО и загрузите новый. |
| Количество кодов маркировки в документе УПД не совпадает с количеством маркируемых товаров. Обработка УПД приостановлена. Аннулируйте текущий УПД и отправьте новый с верным количеством кодов маркировки. | 1. Если товар должен маркироваться — укажите верное количество кодов маркировки, оно должно совпадать с числом маркируемых товаров в УПД. Аннулируйте ошибочный УПД в ЭДО, а затем загрузите новый. 2. Если товар не подлежит обязательной маркировке — напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Товары и цены → Обязательная маркировка → Товар подлежит / не подлежит обязательной маркировке**. |
| Указан товар, подлежащий обязательной маркировке, но в УПД отсутствуют коды маркировки к данному товару. | Если товар: должен маркироваться, но в УПД кодов нет — аннулируйте ошибочный УПД в ЭДО и отправьте новый УПД, в котором указаны КИЗ (коды маркировки) по товарам, подлежащим маркировке;не подлежит обязательной маркировке — напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Товары и цены → Обязательная маркировка → Товар подлежит / не подлежит обязательной маркировке**. |
| Количество кодов маркировки не соответствует количеству товара. | Отправьте новый УПД, в котором количество товара равно количеству КИЗ (кодов маркировки). В уведомлении можно увидеть в какой строке содержится ошибка. |
| Указан некорректный код маркировки. Длина кода маркировки может быть 31 или 38 символов. | Отправьте новый УПД с корректными кодами маркировки — их длина из сервиса «Честный ЗНАК» (ЦРПТ) должна быть от 31 до 38 символов. |
| Указан код маркировки, содержащий недопустимый символ. | Отправьте новый УПД с корректными КИЗ (кодами маркировки). Нельзя использовать символы # № ёЁ $ @ [ \ ] ^ ` { \| } ~ и буквы русского алфавита. |
| Код маркировки ... указан в документе более одного раза. | Отправьте новый УПД, в котором указаны корректные КИЗ (коды маркировки), уникальные для каждого товара. |
| В УПД не заполнен атрибут «ОбстрФормСЧФ» элемента «ДопСвФХЖ1». | Отправьте новый УПД, в котором заполнен признак «Обстоятельства формирования счёта-фактуры» со значением 4. |
| В УПД  заполнен атрибут «ОбстрФормСЧФ» элемента «ДопСвФХЖ1» с недопустимым значением. Ожидается ОбстФормСЧФ="4". |  |
| Укажите в КИЗ код маркировки для экземпляра товара в строке {1}. Коды маркировки для транспортных упаковок не принимаются. | Укажите в КИЗ (код маркировки) для экземпляра товара в строке. Коды маркировки для транспортных упаковок не принимаются. |
| Код(ы) маркировки {2} в УПД отсутствуют к данному товару в соответствующем акте приема товаров. | Аннулируйте ошибочный УПД и загрузите новый, указав коды маркировки согласно акту приёма товаров. |
| В УПД не указаны коды маркировки, но на товаре есть признак маркировки. Укажите экземплярные коды маркировки в документе и повторите отправку УПД, либо уберите признак маркировки в карточке товаров в ЛК. | Укажите коды в поэкземплярном формате или удалите признак маркировки из карточки товара и загрузите УПД ещё раз. |
| Необходимо указать экземплярные КИЗы в УПД. | Добавьте коды маркировки в поэкземплярном формате и загрузите УПД ещё раз. |
| В УПД указаны коды маркировки, но на товаре нет признака маркировки. Укажите признак маркировки в карточке товара в личном кабинете и повторите отправку УПД. | Добавьте признак маркировки в карточку товара и загрузите УПД ещё раз. |
| В УПД не указаны коды маркировки, но на товаре есть признак маркировки. Укажите коды маркировки в документе и повторите отправку УПД, либо уберите признак маркировки в карточке товаров в ЛК. | Добавьте коды маркировки в поэкземплярном или объёмно-сортовом формате (в зависимости от требований законодательства) или удалите признак маркировки из карточки товара и загрузите УПД ещё раз. |
| В УПД не заполнен атрибут «СпОбстФДОП» элемента «ДопСвФХЖ1». При агентской схеме работы этот атрибут обязателен для передачи. | Укажите признак «СпОбстФДОП» со значением «00005» и загрузите УПД ещё раз. |

## Поставки ювелирных изделий, подлежащих обязательной маркировке

| Текст ошибки | Решение |
| --- | --- |
| Общая стоимость с НДС спецификации не совпадает с итоговой суммой с НДС в УПД. | Укажите общую стоимость с НДС в спецификации в ГИИС ДМДК — она должна совпадать с итоговой суммой с НДС в УПД. Если стоимость совпадает, но ошибка сохраняется, напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Товары и цены → Обязательная маркировка → ГИИС ДМДК. Спецификации**. |
| Сумма НДС в спецификации не совпадает с итоговой суммой НДС в УПД. | Отправьте новый УПД, в котором итоговая сумма НДС совпадает с суммой НДС в спецификации. Если сумма совпадает, но ошибка сохраняется, напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Договор и ЭДО → Электронный документооборот (ЭДО) → Проблемы с УПД**. |
| Спецификация в системе ДМДК находится в состоянии черновика. Отправьте спецификацию, затем повторите отправку УПД. | Повторно загрузите УПД с теми же данными. |
| Спецификация: Номер не должен содержать кириллические символы. Например, символ 'T' должен быть латинским. | Проверьте номер спецификации — он не должен содержать лишние символы и кириллицу. |
| УПД содержит ювелирные изделия, но не содержит номер спецификации. Добавьте в УПД номер спецификации и повторите отправку. | Добавьте номер спецификации в УПД и повторите отправку. [Как указать номер спецификации в УПД](/fbo/jewelry/supply-jewelery#как-указать-номер-спецификации-в-упд) |
| В УПД не указаны банковские реквизиты продавца: номер счета, БИК, наименование банка. | Проверьте атрибуты — они должны быть заполнены: Документ/СвСчФакт/СвПрод/БанкРекв/НомерСчетаДокумент/СвСчФакт/СвПрод/БанкРекв/СвБанк/БИКДокумент/СвСчФакт/СвПрод/БанкРекв/СвБанк/НаимБанк |
| В УПД не указан номер документа-основания поставки. | Проверьте атрибуты — они должны быть заполнены: Документ/СвСчФакт/СвПрод/БанкРекв/НомерСчета |
| Спецификация {1}: ИНН грузоотправителя в спецификации не совпадает с ИНН продавца в УПД. | Отправьте новый УПД, в котором ИНН грузоотправителя и ИНН продавца совпадают. |
| Спецификация {1}: ИНН грузополучателя в спецификации не совпадает с ИНН покупателя в УПД (ожидается 7704217370). | Отправьте новый УПД, в котором ИНН грузополучателя совпадает с ИНН покупателя: «7704217370». |
| В УПД указана "Спецификация", но не указан ID товара или GTIN - не удалось определить товар как "Ювелирные изделия". | Проверьте, что спецификация внесена в УПД корректно. Если спецификация указана: ошибочно — отправьте новый УПД без неё;верно — отправить новый УПД с ID товара или GTIN. |
| В УПД указана "Спецификация", но ни один из указанных товаров не относится к категории "Ювелирные изделия". | Проверьте, что спецификация внесена в УПД корректно. Если спецификация указана: ошибочно — отправьте новый УПД без неё;верно — напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Товары и цены → Контроль качества → Доступ к скрытой категории товаров.** |

## Поставки товаров, подлежащих обязательной ветеринарной сертификации

| Текст ошибки | Решение |
| --- | --- |
| На указанный склад (наименование склада, определенное по ID) невозможна поставка весового товара. | Аннулируйте ошибочный УПД и загрузите новый, исправив количество товара на корректное. Должно быть указано целое число. |
| Тип транзакции, указанный в ветеринарном документе, не соответствует типу договорных отношений с ООО "Интернет решения". Измените тип транзакции и повторите отправку ветеринарного документа. | Направьте эСВД в УПД по товарам, которые должны получать ветеринарные сертификаты с корректным типом транзакции через сервис «Меркурий». |
| GTIN  товара в эВСД не соответствует ожидаемому. | Направьте эСВД в УПД по товарам, которые должны получать ветеринарные сертификаты с корректным GTIN через сервис «Меркурий». |
| Обработка УПД приостановлена, т.к. из системы \"Меркурий\" не поступили эВСД, к товарам подлежащим вет.сертификации. Ожидается 1 эВСД, получено 0. | Направьте эВСД в УПД по товарам, которые должны получать ветеринарные сертификаты через сервис «Меркурий». |

## Поставка без ЭДО

| Текст ошибки | Решение |
| --- | --- |
| УПД с указанным номером/датой был получен ранее и подписан со стороны ООО "Интернет решения". Не допускается дублирование УПД с идентичными реквизитами в рамках календарного года. | Сообщение информационное — ничего дополнительно делать не нужно. Поставка товара завершена, есть подписанный двумя сторонами УПД. |
| Состояние акта приема товаров, относящегося к указанному номеру заявки, не позволяет принять УПД. | Ошибка может возникнуть, когда акт приёма ещё не принят вами. Сообщение информационное — дублировать УПД по этому акту приёма не нужно, пока по нему не изменится статус. |
| УПД не соответствует акту приема товар (указан номер/дата исправления). | Отправьте новый УПД с корректными данными, совпадающими с актом приёма. Удалите из УПД номер/дату исправления. |
| УПД не соответствует акту приема товар (указан номер/дата платежно-расчетного документа). | Отправьте новый УПД с данными, совпадающими с актом приёма. Уберите из УПД реквизиты платёжно-расчётного документа. |
| ИНН продавца в УПД не соответствует ИНН продавца в акте приема товаров. | Отправьте новый УПД, в котором ИНН продавца соответствует указанному в акте приёма. |
| ИНН покупателя в УПД не соответствует ИНН покупателя в акте приема товаров. | Отправьте новый УПД, в котором ИНН покупателя соответствует указанному в акте приёма. |
| КПП покупателя в УПД не соответствует КПП покупателя в акте приема товаров. | Отправьте новый УПД, в котором КПП покупателя соответствует указанному в акте приёма. |
| В адресе покупателя указан некорректный код страны. Ожидается код - 643. | Отправьте новый УПД с правильным кодом страны покупателя — 643 (Россия). Адрес должен соответствовать указанному в акте приёма. |
| Адрес покупателя в УПД не соответствует адресу покупателя в акте приема товаров. | Отправьте новый УПД, в котором адрес покупателя соответствует указанному в акте приёма. |
| ИНН грузополучателя в УПД не соответствует ИНН грузополучателя в акте приема товаров. | Отправьте новый УПД, в котором ИНН грузополучателя соответствует указанному в акте приёма. |
| КПП грузополучателя в УПД не соответствует КПП грузополучателя в акте приема товаров. | Отправьте новый УПД, в котором КПП грузополучателя соответствует указанному в акте приёма. |
| В адресе грузополучателя указан некорректный код страны. Ожидается код - 643. | Отправьте новый УПД с корректным кодом страны покупателя — 643 (Россия). |
| Адрес грузополучателя в УПД не соответствует адресу грузополучателя в акте приема товаров. | Отправьте новый УПД, в котором адрес грузополучателя соответствует указанному в акте приёма. |
| Количество товара в УПД не соответствует количеству принятого товара, указанного в акте приема товаров. | Отправьте новый УПД, в котором количество товара соответствует указанному в акте приёма. |
| Цена товара за единицу в УПД не соответствует цене, указанной в акте приема товаров. | Отправьте новый УПД, в котором цена товара соответствует указанной в акте приёма. |
| Стоимость товара без налога в УПД не соответствует стоимости товара, указанной в акте приема товаров. | Отправьте новый УПД, в котором стоимость товара без налога соответствует указанной в акте приёма. |
| Налоговая ставка в УПД не соответствует налоговой ставке, указанной в акте приема товаров. | Отправьте новый УПД, в котором налоговая ставка соответствует указанной в акте приёма. |
| Стоимость товара с учетом налога в УПД не соответствует стоимости товара, указанной в акте приема товаров. | Отправьте новый УПД, в котором стоимость товара с учётом налога соответствует указанной в акте приёма. |
| Сумма акциза в УПД не соответствует сумме акциза, указанной в акте приема товаров. | Отправьте новый УПД, в котором сумма акциза соответствует указанной в акте приёма. |
| Сумма налога в УПД не соответствует сумме налога, указанной в акте приема товаров. | Отправьте новый УПД, в котором сумма налога указанной в акте приёма. |
| Единица измерения товара в УПД не соответствует единице измерения, указанной в акте приема товаров. | Отправьте новый УПД, в котором единица измерения товара соответствует указанной в акте приёма. |
| Ozon ID не указан или указан неправильно. | Отправьте новый УПД, в котором для каждого товара указан Ozon ID — уникальный код, присваиваемый со стороны Ozon. |
| Стоимость товаров без налога (всего) в УПД не соответствует стоимости товаров без налога, указанной в акте приема товаров. | Отправьте новый УПД, в котором стоимость товара без налога (всего) соответствует указанной в акте приёма. |
