# Ограничения при создании заявки

_Главная / Продажа со склада Ozon (FBO) / Заявки на поставку_

Какие постоянные и временные ограничения складов нужно учитывать при создании заявки на поставку

Некоторые товары не получится добавить в заявку, если:

их нельзя продавать на Ozon;

их нельзя продавать по схеме FBO;

у них отсутствует [обязательная маркировка](https://seller-edu.ozon.ru/libra/fbo/markirovka-tovarov/chestny-znak) или не указан код ТН ВЭД в карточке товара;

их не принимает склад, на который вы хотите сделать поставку.

# Видео «Как проверить ограничения на поставку товаров»

# Какие ограничения бывают

## Ограничения для схемы FBO

Некоторые товары не сможем принять для размещения на складах Ozon, но можно продавать их по схемам [FBS](https://seller-edu.ozon.ru/fbs) или [realFBS](https://seller-edu.ozon.ru/rfbs) с учётом [ограничений служб доставки](https://seller-edu.ozon.ru/policies/restrictions/prohibited-rfbs-partnery).

[Полный список товаров, запрещённых к продаже по схеме FBO](https://seller-edu.ozon.ru/policies/restrictions/only-fbs)

Товары со статусом ликвидности **Без продаж, ограничен **не получится добавить в заявку на поставку или увеличить их количество в уже созданной заявке. Рекомендуем удалить такие товары из заявки, так как их размещение на складе может принести вам убытки. [Подробнее о неходовых товарах](/fbo/rabota-so-stokom/nehodovye-tovary#какие-товары-считаем-неходовыми)

## Ограничения по складам

Ни на одном из складов не примем товары, которые превышают максимальные габариты:

длина — 220 см;

ширина — 120 см;

высота — 80 см;

вес — 120 кг.

Если склад может принять только часть товаров — это значит, что остальные попали под ограничения или в одну заявку попали обычные товары, [крупногабаритные](https://seller-edu.ozon.ru/kgt/fbo/postavka-kgt-fbo#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D1%8B-%D1%81%D1%87%D0%B8%D1%82%D0%B0%D1%8E%D1%82%D1%81%D1%8F-%D0%BA%D1%80%D1%83%D0%BF%D0%BD%D0%BE%D0%B3%D0%B0%D0%B1%D0%B0%D1%80%D0%B8%D1%82%D0%BD%D1%8B%D0%BC%D0%B8) и [товары с УПД](https://seller-edu.ozon.ru/fbo/documents/hand-in-UPD-2). Можно поставить только те товары, которые склад примет, а с остальными создать другую заявку — на склад, где нет таких ограничений.

Откройте список товаров в заявке и нажмите **Не сможем принять**, чтобы посмотреть и скачать список товаров, которые мы исключили из заявки — сможете создать с ними отдельную заявку на тот склад, который сможет их принять.

Если создаёте заявку в мобильном приложении, удалим из заявки все товары с ограничением по количеству — отменить это не получится.

## Временные ограничения по складам

Не сможем принять товары, для размещения которых закончилось место на складе. [Подробнее](https://seller-edu.ozon.ru/analytics-and-metrics/graphs/dostupnost-tovarov#%D0%B3%D0%B4%D0%B5-%D0%BF%D0%BE%D1%81%D0%BC%D0%BE%D1%82%D1%80%D0%B5%D1%82%D1%8C-%D0%BE%D0%B3%D1%80%D0%B0%D0%BD%D0%B8%D1%87%D0%B5%D0%BD%D0%B8%D1%8F-%D0%BD%D0%B0-%D0%BF%D0%BE%D1%81%D1%82%D0%B0%D0%B2%D0%BA%D1%83-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2)

## Ограничения из-за маркировки или кода ТН ВЭД

Проверяем, является ли товар прослеживаемым и требуется ли ему маркировка. Если это так, попросим [указать в карточке товара](https://seller-edu.ozon.ru/libra/work-with-goods/zagruzka-tovarov/creating-goods/sozdanie-tovarov-lk#как-изменить-один-товар).

**ТН ВЭД код ЕАЭС **— уникальный десятизначный цифровой код, который присваивается каждому виду товара для его международной классификации и идентификации при пересечении границы. [Подробнее о коде](/work-with-goods/trebovaniya-k-kartochkam-tovarov/product-information/tn-ved)

**Штрихкод GTIN** — глобальный номер товарной продукции в единой международной базе товаров GS1. Он состоит из 13 знаков и присваивается производителем.

**Количество товара в унифицированных единицах измерения (УЕИ)** — например, для футболки количество товара в УЕИ будет 1 штука. Но если продаёте комплект сразу из 3 футболок, то количеством продукции будет уже 3 штуки.

Без этой информации добавить товар в поставку не получится.

## Ограничения по количеству товаров

Иногда склады или кластеры могут принять только часть товаров.

Если вы создаёте заявку в личном кабинете на сайте, то в колонке **Товары **покажем знак. Нажмите, чтобы посмотреть, какие товары не примем, и отредактировать список. Если продолжите без изменений, исключим непрошедшие товары из заявки.

Чтобы отредактировать список товаров или посмотреть непрошедшие, нажмите на количество в столбце **Товары** напротив кластера или склада.

Вы также можете выбрать правило для всех товаров в заявке, чтобы не редактировать её вручную каждый раз.

### Как установить правило для частично прошедших товаров

Чтобы указать, что делать с частично прошедшими в заявку товарами во всех новых заявках:

1. Перейдите в раздел **[FBO → Заявки на поставку](https://seller.ozon.ru/app/supply/orders)**.
2. Нажмите на пункт **Частично прошедшие товары** в виджете **Настройки и тарифы.**
3. Выберите один из вариантов**:**
  **Удалить полностью **— удалим из заявки все SKU, которые сможем принять только частично;
  
  **Оставить количество, которое примет кластер **— в этом случае мы оставим в заявке SKU, но уменьшим количество.

Чтобы изменить это правило в момент работы с черновиком:

1. Откройте список товаров.
2. Перейдите на вкладку «Не сможем принять».
3. Нажмите **Настройки.**
4. Выберите один из вариантов — применим его для этой и всех новых заявок.

Для заявок в приложении Ozon Seller установить правило не получится — автоматически удалим частично прошедшие товары.
