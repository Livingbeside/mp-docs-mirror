# Как устроена маркировка «Медийной рекламы»

_Главная / Продвижение / «Медийная реклама»_

Рассказываем про маркировку «Медийной рекламы» на Ozon. Подробнее о том, что это такое и какие форматы есть в инструменте, можно узнать в [статье](/how-to-sell-effectively/media-advertising/mediinaya-reklama).

Вся реклама в интернете должна быть промаркирована — это требование закона о рекламе. При запуске медийной рекламы, мы автоматически присваиваем ERID-идентификатор каждому баннеру и видеобаннеру, а после передаём его в Роскомнадзор (ЕРИР). За это не берём плату.

Баннеры с местом размещения «Оффервол» не относятся к рекламе, поэтому мы не маркируем их и не передаём данные в ЕРИР.

## Как посмотреть ERID-идентификатор

ERID-идентификатор — уникальная цифровая метка интернет-рекламы. Она нужна для учёта рекламных материалов.

ERID можно посмотреть для баннеров и видеобаннеров, которые прошли модерацию. Для этого:

1. Перейдите в раздел **[Продвижение → Медийная реклама](https://seller.ozon.ru/app/advertisement/!#/media)**.
2. Откройте нужную кампанию и напротив баннера нажмите ⋮, а затем на номер идентификатора — скопируем его. Чтобы проверить ERID архивированного баннера, сначала восстановите его из архива.

## Как скачать отчёт с ERID-идентификаторами

Такой отчёт можно использовать для подтверждения того, что реклама не нарушает требования законодательства России, и информация о рекламе передана в Роскомнадзор (ЕРИР).

1. Откройте **[Продвижение → Медийная реклама](https://seller.ozon.ru/app/advertisement/!#/media)** и отфильтруйте те кампании, по которым хотите скачать отчёт.
2. Нажмите ** → Маркировка рекламы**.
3. На ваше устройство скачается отчёт по всем кампаниям, которые есть на странице. В отчёте будет:
  ID кампании;
  
  название кампании;
  
  ID баннера;
  
  название баннера;
  
  дата и время присвоения ERID (это дата, когда баннер прошел модерацию);
  
  ERID.
