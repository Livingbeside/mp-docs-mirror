# Продажа товаров по государственному электронному сертификату СФР

_Главная / Работа с товарами / Дополнительные материалы_

Как продавать товары с оплатой электронным сертификатом Социального Фонда России

Вы можете продавать товары на Ozon с оплатой электронным сертификатом Социального Фонда России. Для этого заполните xlsx-шаблон и отправьте его в поддержку, после проверки мы добавим эти позиции в [специальный раздел](https://www.ozon.ru/highlight/fss-788742/?redirect_query=%D1%82%D1%81%D1%80).

Люди, получающие льготы, — например, по инвалидности — могут покупать средства реабилитации из [списка социального Фонда России](https://ktsr.fss.ru/). Это требование [федерального закона «О приобретении отдельных видов товаров, работ, услуг с использованием электронного сертификата» № 491-ФЗ](http://www.consultant.ru/document/cons_doc_LAW_372676/). Средства реабилитации привязываются к карте МИР и содержат информацию о том, какие товары может купить человек за счёт фонда, в каком количестве и на какую максимальную сумму за штуку.

# Как работает электронный сертификат

Покупатель находит на площадке [в разделе «Электронный сертификат»](https://www.ozon.ru/highlight/fss-788742/?redirect_query=%D1%82%D1%81%D1%80) средство реабилитации, при оплате выбирает способ Карта МИР и соц. сертификат и указывает номер карты, к которой привязан сертификат — а если единица товара стоит дороже установленного фондом лимита, доплачивает разницу.

# Как начать продавать товары по электронному сертификату

1. Если ещё не регистрировались — зайдите на [сайт СФР](https://ktsr.fss.ru/), войдите в личный кабинет через Госуслуги и отправьте заявку на получение роли производителя, поставщика или импортёра технических реабилитационных средств.
  Если ваших товаров нет в каталоге, их нужно будет зарегистрировать.

1. Когда ваши товары появятся в каталоге фонда социального страхования, скачайте шаблон и заполните его. Если у вас несколько товаров, которые вы хотите продавать по электронным сертификатам СФР, их можно указать в одном шаблоне.
2. В столбце **SKU товара** укажите ID SKU из личного кабинета для каждого товара, который будет продаваться по сертификату. [Как найти SKU товара](/work-with-goods/zagruzka-tovarov/created-goods/spisok-i-statysi-tovara#%D0%BA%D0%B0%D0%BA-%D1%83%D0%B7%D0%BD%D0%B0%D1%82%D1%8C-ozon-sku-id-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0)
3. В столбце **Наименование товара** укажите такое же название, как в карточке товара на Ozon и в регистрационном удостоверении.
4. В столбце **ID Продавца **[укажите ID личного кабинета](/personal-account/settings?search=ID&page=2#%D1%80%D0%B5%D0%BA%D0%B2%D0%B8%D0%B7%D0%B8%D1%82%D1%8B-%D0%B8-%D0%B4%D0%BE%D0%B3%D0%BE%D0%B2%D0%BE%D1%80), как в разделе **Настройки → Информация о компании**.
5. В столбце **Поставщик (юр. лицо) **укажите наименование вашего юридического лица или наименование ИП, на который зарегистрирован личный кабинет.
6. В ТРУ коде должно быть тридцать знаков и точка после девятой цифры, которая тоже считается отдельным знаком. Измените код и укажите его в столбце **ТРУ (на товар)**. Для этого отсчитайте 19 знаков с начала кода, удалите остальные символы и вместо них добавьте 11 нулей.

| Без изменений | Изменён |
| --- | --- |
| 325022129.23000010503040002643 | 325022129.230000105**00000000000** |

1. В столбце **Код по приказу Минтруда** добавьте шестизначный код с двумя тире.
  Обратите внимание, пользователи используют код для поиска, поэтому, если он начинается с нуля — укажите пять цифр **без нуля**. Иначе они не смогут найти товар.
  Если продаёте обувь, укажите код и добавьте к нему «дети» или «взрослые»:
  код 9-01-01 дети;
  
  код 9-01-01 взрослые.

| Нельзя использовать | Можно использовать |
| --- | --- |
| 2301-05; 23-0105; 230105; 23-005; 06-01-02 | 23-01-05; 6-01-02 |

1. Укажите номер регистрационного удостоверения (РУ) в столбце **Номер РУ,** если товар относится к категории:
  впитывающее бельё для взрослых: подгузники, трусики и пелёнки;
  
  уход за стомой: калоприёмники, мочеприёмники, катетеры урологические;
  
  средства по уходу за стомой: герметик, зажим, пелёнка, очиститель, пудра;
  
  обувь ортопедическая;
  
  костыли;
  
  трости;
  
  кресла коляски;
  
  кресла туалеты;
  
  опоры;
  
  подъемники;
  
  ходунки;
  
  экзопротезы молочной железы;
  
  тонометры;
  
  термометры;
  
  глюкометры;
  
  параподиумы;
  
  вертикализаторы.
  Номер РУ должен совпадать с значением на сайте [Росздравнадзоре](https://roszdravnadzor.gov.ru/). Если товар не относится к категории, которая подлежит обязательной медицинской регистрации (РУ) — не заполняйте столбец.

1. Укажите ссылку на ваш товар [в каталоге технических средств реабилитации](https://ktsr.sfr.gov.ru/) в столбце **Ссылка на товар на сайте https://ktsr.fss.ru/.**
2. В столбце **Сертификат **введите слово **ТСР**.
3. Заполните столбец «Кол-во ТСР, штук» — укажите общее количество штук в одном товаре:
  Для подгузников, пелёнок, пары костылей, товаров для ухода за стомой и прокладок урологических нужно указать количество товаров в одной упаковке. Если продаёте комплект, укажите количество товаров во всех упаковках. Например, для одной упаковки с 15 подгузниками — укажите 15. Для комплекта из двух упаковок подгузников по 15 штук — укажите 30.
  
  Для остальных товаров, например, обуви, слуховых аппаратов, одежды, перчаток, колясок и прочего —  укажите 1.
  Указывать количество товара, которые у вас есть на стоке не нужно.
4. Создайте новое обращение в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Товары и цены → Карточка товара → Наполнение карточки → Создание и редактирование товаров** и приложите к заявке заполненный шаблон.

Мы проверим предоставленные данные. Если всё в порядке — товар появится в разделе **[Товары по электронному сертификату ТСР (ФСС)](https://www.ozon.ru/highlight/fss-788742/?redirect_query=%D1%82%D1%81%D1%80)** и для него будет доступна оплата **Карта МИР и соц. сертификат**. Если найдём ошибку — сообщим вам об этом в течение 5 рабочих дней.

# Как вы получите деньги за продажу товара по сертификату

Для продавцов получение выручки за товары, купленные по сертификатам СФР, не будет отличаться от обычного процесса — деньги поступят в полном объёме в соответствии с графиком выплат.

# Вопросы об электронных сертификатах

## Где посмотреть заказы, оплаченные электронным сертификатом?

Скачайте отчёт в разделе **Аналитика → Отчёты → Заказы → Заказы с моих складов  **или в разделе** Аналитика → Отчёты → Заказы → Заказы со складов Ozon**. У заказов, которые были оплачены социальным сертификатом, в столбце «Способ оплаты» будет указана **Карта МИР и соц. сертификат**.
