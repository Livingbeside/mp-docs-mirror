# Узнать SKU товаров

_Главная / Работа с товарами / Создание и редактирование товаров / Работа с созданными товарами_

Что такое SKU и где его посмотреть

SKU — уникальный идентификатор товара в системе Ozon. Создаём SKU автоматически после того, как товар пройдёт модерацию.

## В списке товаров

Перейдите **[Товары → Список товаров](https://seller.ozon.ru/app/products%D1%8D)** и найдите нужную позицию. SKU указаны в столбце **Артикул**.

В некоторых случаях не показываем SKU в списке товаров — например, для услуг.

## В отчёте по товарам

Можно скачать двумя способами:

в разделе **[Аналитика → Отчёты → Товары](https://seller.ozon.ru/app/analytics/fulfillment-reports/all-products)** нажмите **Скачать**;

в разделе **[Товары → Список товаров](https://seller.ozon.ru/app/products)** нажмите **Cкачать товары** и выберите **Товары CSV**.

В файле найдите строку с нужным товаром и посмотрите значение в столбце **SKU**.

[Подробнее о том, как скачать отчёт](/analytics-and-metrics/fulfillment-reports/otchet-po-tovaram)

## В заявке на поставку (для FBO)

1. Перейдите на страницу **[FBO → Заявки на поставку](https://seller.ozon.ru/app/supply/orders)**.
2. Найдите заявку с нужным товаром и откройте её — для этого нажмите на номер.
3. Откройте вкладку **Товары**.
4. Нажмите **Скачать расширенный XLS**.
5. Откройте файл и посмотрите значение в столбце **Ozon ID**.

## В карточке товара на Ozon

1. Откройте карточку товара на [сайте Ozon](https://www.ozon.ru/).
2. Посмотрите код в поле **Артикул**.
