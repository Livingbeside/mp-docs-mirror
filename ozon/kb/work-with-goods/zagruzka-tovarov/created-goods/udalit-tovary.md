# Удалить товары

_Главная / Работа с товарами / Создание и редактирование товаров / Работа с созданными товарами_

Какие товары можно удалить и как это сделать

Вы можете удалить только те позиции, которые ещё не прошли проверку. Если это случилось — товар нельзя удалить навсегда, можно только [архивировать](/work-with-goods/zagruzka-tovarov/created-goods/upravlyat-tovarami-v-arhive). Это поможет:

если вы передумаете и решите возобновить продажи;

избежать проблем при возвратах товаров.

Если кнопка удаления недоступна, значит позиция уже проходила модерацию и размещалась на Ozon.

Чтобы удалить товар без возможности восстановления:

1. [Перенесите в архив](https://seller-edu.ozon.ru/work-with-goods/zagruzka-tovarov/created-goods/tovary-v-arhive) позиции, которые хотите удалить.
2. Откройте страницу **[Товары → Список товаров → Архив](https://seller.ozon.ru/app/products?filter=archived)**. Если нужно удалить:
  один товар — нажмите **⋮** в строке с нужной позицией и выберите **Удалить товар**.
  
  несколько товаров — отметьте их, нажмите **Действия** и выберите **Удалить товары**.

После этого восстановить удалённые позиции будет нельзя.
