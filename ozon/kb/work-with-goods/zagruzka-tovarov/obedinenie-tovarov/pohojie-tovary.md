# Похожие товары

_Главная / Работа с товарами / Создание и редактирование товаров / Объединение товаров_

Как объединить товары, которые могут заменить друг друга, а также как изменить или удалить такую группу

# Видео «Как объединить аналогичные товары»

# Когда использовать

В группу **Похожие** объединяйте товары, которые могут заменять друг друга. В карточке каждого товара группы появится специальный блок — в нём покажем остальные товары из группы. Это поможет покупателям быстро находить аналогичные товары из вашего ассортимента — если один из товаров закончится, покупатель выберет похожий.

# Какие товары можно объединить в группу

В группу **Похожие** можно объединить карточки из одной категории второго уровня. Бренд у товаров может быть разным.

В группу можно добавить до 500 товаров.

Не получится добавить в группу товары без [SKU](/work-with-goods/zagruzka-tovarov/created-goods/spisok-i-statysi-tovara#%D0%BA%D0%B0%D0%BA-%D1%83%D0%B7%D0%BD%D0%B0%D1%82%D1%8C-ozon-sku-id-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0) и уценённые.

**Пример**

Карточку смартфона:

можно объединить с товарами из категорий **Электроника → Смартфоны, планшеты, мобильные телефоны**: например, **Смартфоны** или **Планшеты**;

нельзя объединить с товарами из категории **Электроника → Электронные книги** или **Электроника → Смарт-часы**.

Не добавляйте одинаковые товары во все виды групп — система отслеживает повторы и может скрыть их в некоторых группах. Например, если товар есть** **в группах **Похожие** и **Модель**, покупатели увидят его только в группе **Модель** — в объединённой с другими товарами карточке.

# Создать группу

Доступно только с подпиской [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-pro).

1. Перейдите в раздел **[Товары → Объединить товары → Похожие](https://seller.ozon.ru/app/products-merge?tab=series)**[.](https://seller.ozon.ru/app/products-merge?tab=series)
2. Нажмите **Создать группу**.
3. Укажите название группы. Покупатели увидят его на странице со всеми товарами группы. Все слова в названии, кроме первого, всегда отображаются с маленькой буквы.
4. Нажмите **Добавить товары**.
5. Выберите товары в открывшемся списке. Чтобы найти, используйте:
  поиск по названию, артикулу или SKU товаров;
  
  фильтры по бренду и категории;
  Нажмите **Показать выбранные**, если хотите посмотреть только те товары, которые уже отметили. Когда отметите первую карточку, автоматически обновим список остальных — предложим только те товары, с которым можно объединить выбранный.
6. Нажмите **Подтвердить**.
7. Проверьте список товаров. Чтобы удалить лишние, нажмите .
8. Когда всё будет готово, нажмите **Сохранить**.

Покупатели увидят группу в течение 24 часов — в карточках товаров группы появится специальный блок. [Как это выглядит](/work-with-goods/zagruzka-tovarov/obedinenie-tovarov/pohojie-tovary#%D0%BA%D0%BE%D0%B3%D0%B4%D0%B0-%D0%B8%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D1%8C)

1. В разделе **Товары **нажмите **Группы товаров **и выберите **Похожие**.
2. Нажмите **Создать группу **и выберите категорию, в которой находятся товары для объединения.
3. Найдите и выберите первый товар — покажем список, которые можно с ним объединить в одну карточку.
4. Отметьте товары и нажмите **Далее**.
5. Укажите название группы — покупатели увидят его на странице со всеми товарами группы.
6. Нажмите **Создать группу **—** **покупатели увидят группу в течение 24 часов.

# Посмотреть товары в группе

Проверьте, какие товары объединили в группу и как они отображаются.

1. Перейдите в раздел **[Товары → Объединить товары → Похожие](https://seller.ozon.ru/app/products-merge?tab=series)**[.](https://seller.ozon.ru/app/products-merge?tab=series)
2. Нажмите  в строке группы.

Отобразится название группы, количество товаров и их список. Рядом с каждым товаром покажем его статус.

Если карточка не отображается в группе, рядом появится значок  и причина — наведите на неё курсор, чтобы посмотреть подробности.

Посмотрите список товаров в группе одним из способов:

В разделе **Товары** нажмите **Группы товаров, **выберите **Похожие** и откройте группу.

Откройте карточку товаров и в блоке **Группы с этим товаром** нажмите **Похожие**.

Покажем список товаров в группе — рядом с каждым покажем его статус.

# Изменить группу

Доступно только с подпиской [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-pro).

Добавьте новые товары в группу или удалите лишние, чтобы карточка оставалась актуальной.

1. Перейдите в раздел **[Товары → Объединить товары → Похожие](https://seller.ozon.ru/app/products-merge?tab=series)**[.](https://seller.ozon.ru/app/products-merge?tab=series)
2. Нажмите  в строке группы.

Вы можете:

Изменить название группы.

Добавить в неё ещё товары — для этого нажмите **Добавить товары**.

Удалить товары:
нажмите  в строке товара;

отметьте несколько и нажмите **Удалить товары**.

1. В разделе **Товары** нажмите **Группы товаров **и выберите **Похожие**.
2. Откройте группу и нажмите **Редактировать товары**.
3. Вы можете:
  добавить ещё товары — для этого нажмите ;
  
  удалить товары:
  нажмите  в строке товара и выберите **Удалить из группы**;
  
  кликните **Выбрать товары**, отметьте несколько и нажмите **Удалить**.
4. Нажмите **Применить**.

# Удалить группу

Чтобы полностью расформировать объединение, удалите группу.

1. Перейдите в раздел **[Товары → Объединить товары → Похожие](https://seller.ozon.ru/app/products-merge?tab=series)**[.](https://seller.ozon.ru/app/products-merge?tab=series)
2. Нажмите  в строке группы.
3. Подтвердите действие.

В течение 24 часов скроем группу от покупателей. Статус товаров, которые были в группе, не изменится.

1. В разделе **Товары** нажмите **Группы товаров **и выберите **Похожие**.
2. Откройте группу и нажмите .
3. Выберите **Удалить группу **и подтвердите действие.

В течение 24 часов скроем группу от покупателей. Статус товаров, которые были в группе, не изменится.

# Почему товар не отображается в группе

Покупатели видят в карточках первые 12 товаров из группы. Чтобы увидеть остальные, нажмите **Ещё**.

Если в полном списке товаров тоже ничего нет, товар может быть скрыт по одной из причин:

Изменился его статус: например, товар не прошёл модерацию после редактирования или снят с продажи.

Вы добавили товар сразу в несколько групп. Чтобы показывать покупателям разные товары, [автоматически скрываем повторы](/work-with-goods/zagruzka-tovarov/obedinenie-tovarov/chto-takoe-obedinenie#%D0%BA%D0%BE%D0%B3%D0%B4%D0%B0-%D1%81%D0%BA%D1%80%D1%8B%D0%B2%D0%B0%D0%B5%D0%BC-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D1%8B).
