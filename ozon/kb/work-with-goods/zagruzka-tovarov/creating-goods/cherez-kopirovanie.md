# Как устроено копирование чужих товаров

Перед тем, как создать товар, поищите его на Ozon: если другие продавцы уже добавляли такую карточку, можно быстро скопировать её и не заполнять параметры вручную.

Есть пара ограничений — скопировать товар не получится, если:

карточку создал продавец из другой страны;

карточку создали вы из другого личного кабинета — дубли своих же товаров создавать нельзя.

Продавцы могут [запретить копирование](#%D0%BA%D0%B0%D0%BA-%D0%B7%D0%B0%D0%BF%D1%80%D0%B5%D1%82%D0%B8%D1%82%D1%8C-%D0%BA%D0%BE%D0%BF%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2) некоторых атрибутов своих товаров в настройках. Если запрет на карточке есть, можно перенести всё, кроме артикула, цены, НДС, аннотации и медиа.

Если у карточки есть запрет на копирование, главное фото перенести не получится, но вы можете запустить генерацию нового фото по описанию:

при копировании одной карточки — чтобы начать генерацию, выберите товар и начните его копировать;

при копировании нескольких товаров — нажмите **Сгенерировать фото **над списком скопированных карточек.

Если результат не подойдёт, фото можно перегенерировать. Количество генераций ограничено — не более 10 раз в сутки суммарно для всех товаров, включая повторные попытки.

# Скопировать чужой товар вручную

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)**** **и нажмите **Скопировать готовые товары**.
2. Найдите подходящую карточку. Для этого в строке поиска можно указать:
  название товара;
  
  ссылку на товар на сайте Ozon;
  
  штрихкод товара;
  
  [SKU товара](/work-with-goods/zagruzka-tovarov/created-goods/uznat-sku-tovarov).
3. Система подберёт товары по запросу. Нажмите **Добавить** около товаров, которые хотите скопировать.
4. Нажмите **Продолжить**.
  Если нет запрета на копирование, то скопируем все атрибуты, кроме артикула, цены и НДС.
  
  Если запрет есть, заполним всё, кроме артикула, цены, НДС, аннотации и медиа. При переходе на этот шаг вы запустите генерацию главного фото — обычно это занимает от 20 секунд до 5 минут. Если результат не подходит, сгенерируйте фото заново. Количество генераций ограничено — не более 10 раз в сутки суммарно для всех товаров, включая повторные попытки.
5. Укажите оставшиеся характеристики для каждого товара. Если работаете по упрощенной системе налогообложения (УСН), в поле НДС выберите «Не облагается».
6. Нажмите** Сохранить**.

После копирования карточки товара в категориях: «Сахаросодержащие напитки», «Моторные масла», «Безалкогольное пиво», проверьте, чтобы у них был указан тип подакцизного товара. [Подробнее про подакцизные товары](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-kopirovanie)

# Скопировать чужой товар через шаблон

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Через шаблон**.
2. Выберите категорию, кликните **Excel** в выборе типа шаблона и нажмите **Скачать шаблон**.
3. Откройте файл и на вкладке **Шаблон для поставщика** заполните:
  [SKU товара](/work-with-goods/zagruzka-tovarov/created-goods/uznat-sku-tovarov);
  
  [артикул](/work-with-goods/trebovaniya-k-kartochkam-tovarov/articyl-tovara);
  
  цену;
  
  НДС — если работаете по упрощенной системе налогообложения (УСН), в поле НДС выберите «Не облагается».
4. Сохраните файл. Вернитесь в раздел **[Товары → Добавить товары→ Через шаблон](https://seller.ozon.ru/app/products/import/file)****, **загрузите заполненный файл и нажмите **Опубликовать**.

[Подробнее о работе с XLS-шаблоном](/work-with-goods/zagruzka-tovarov/cherez-xls-shablon)

После копирования карточки товара в категориях: «Сахаросодержащие напитки», «Моторные масла», «Безалкогольное пиво», проверьте, чтобы у них был указан тип подакцизного товара. [Подробнее про подакцизные товары](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-kopirovanie)

# Скопировать чужой товар через API

Для копирования товара другого продавца через API используйте метод [/v1/product/import-by-sku](https://docs.ozon.ru/api/seller/#operation/ProductAPI_ImportProductsBySKU) — он создаёт товар по указанному SKU. Cоветуем использовать API продавцам с большим ассортиментом.

[Подробнее о работе с API](/api-ozon/how-to-api)

# Запретить копирование атрибутов товаров

При включении запрета другие продавцы не смогут скопировать с ваших карточек артикул, цены, НДС, аннотацию и медиа.

1. Откройте раздел **[Товары → Управление карточками товаров](https://seller.ozon.ru/app/products/items-management)**.
2. В поле **Запрет на копирование карточке товаров** нажмите переключатель — он должен стать синим.
