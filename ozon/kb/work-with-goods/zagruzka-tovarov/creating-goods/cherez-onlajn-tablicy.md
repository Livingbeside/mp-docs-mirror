# Создание и редактирование товаров через онлайн-таблицы

# Видео «Как загрузить товары через онлайн-таблицы»

# Что такое онлайн-таблицы

Онлайн-таблицы — шаблон для загрузки товаров, который не нужно скачивать. Вся работа происходит в окне браузера.

Почему онлайн-таблицы удобнее обычных XLS-файлов:

автоматически проверяем ошибки и подсказываем, как их исправить;

все недочёты можно исправить до отправки шаблона на модерацию;

не нужно скачивать и загружать файл — вся работа с шаблоном идёт внутри личного кабинета;

в одной таблице можно создавать товары из разных подкатегорий — например, «Робот-пылесос» и «Ручной пылесос»;

можно массово заполнить одинаковые значения;

шаблон всегда актуальный и обновляется автоматически — не будет ситуаций, когда кто-то случайно взял устаревший файл;

в режиме редактирования черновик доступен 24 часа — можно вернуться к работе с ним позже.

Чтобы работать с онлайн-таблицами, отключите **Tracking prevention, **если используете браузер **Edge.**

# Как загрузить товар через онлайн-таблицу

1. Откройте раздел **[Товары → Добавить товары → Через шаблон](https://seller.ozon.ru/app/products/import/file)**.
2. Укажите категорию — достаточно выбрать первые два уровня.
3. Нажмите **Заполнить**.
4. Дождитесь загрузки таблицы.
5. Заполните шаблон. [Подробнее о том, как работать с таблицей](#как-работать-с-таблицеи)
  У [подакцизных товаров](/work-with-goods/additional-materials/podakciznye-tovary) укажите их тип в поле **Подакцизные товары**.
6. Когда всё будет готово, нажмите **Отправить**. Система проверит таблицу.
  Если всё в порядке, откроется раздел **Загрузить товары через шаблон**. Шаблон появится в блоке **Шаг 3. История обновлений** со статусом «Проверяем».
  
  Если есть ошибки, подсветим их. Все позиции с ошибками отобразятся на вкладках **Дубли** и **С ошибками**. Исправьте их и снова нажмите **Отправить**.

# Как работать с таблицей

В онлайн-таблице можно:

Указать значения по одному — для этого нажмите на ячейку дважды. Некоторые поля нужно заполнить вручную, в других предложим варианты — начните писать значение, чтобы быстро найти нужное в списке.

Добавить одно значение сразу для всех товаров — нажмите **Заполнить массово**.

Скопировать строку — нажмите **⋮** и выберите **Создать копию**.

Удалить строку — нажмите **⋮** и выберите **Удалить**. Чтобы удалить сразу несколько строк, отметьте их и нажмите **Удалить строки**. Они переместятся на вкладку** Будут удалены**.

[Сохранить черновик](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-onlajn-tablicy#%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D1%82%D1%8C-%D1%81-%D1%87%D0%B5%D1%80%D0%BD%D0%BE%D0%B2%D0%B8%D0%BA%D0%BE%D0%BC) и вернуться к таблице позже.

## Как создать описание товара

Прокрутите таблицу вправо до столбца **Аннотация** и нажмите ячейку. Вы можете написать аннотацию самостоятельно или сгенерировать с помощью нейросети. Для этого:

1. Добавьте особенности товара, которых нет в характеристиках, чтобы нейросеть учла в описании — нажмите  и введите слова или фразы на русском языке через точку с запятой, например: молния; прямой крой; для школьников. Не пишите артикул товара, хештеги или другие символы, которые не являются словами. Нажмите **Применить**.
2. Кликните **Сгенерировать** — через несколько секунд появится текст.
3. Вы можете отредактировать его или сгенерировать ещё варианты, между ними можно переключаться с помощью кнопки . Сравните результат и сохраните самый удачный вариант.

## Как добавить медиа в таблице

Прокрутите таблицу вправо и нажмите:

**Иконки  **** **или  — чтобы добавить или изменить медиа для одной позиции.

**Заполнить массово**, если хотите загрузить одинаковое фото или видео для всех вариантов.

Используйте клавиши **Ctrl+C** и **Ctrl+V**, чтобы быстро скопировать все фото или видео из одного товара в другой. Для этого выделите ячейку с медиа и нажмите **Ctrl+C**. Затем выделите ячейку, куда нужно добавить медиа, и нажмите **Ctrl+V**.

## Как подключить продвижение в таблице

Прокрутите таблицу вправо до столбца **Платное продвижение, **нажмите поле **Акция** и выберите:

**[Рассрочка](/how-to-sell-effectively/loyalty/besprotsentnaya-rassrochka)** — помогает увеличить продажи: покупателям проще купить товар, оплачивая его частями без переплаты. Дисконт удерживается только за проданные товары вместе с другими комиссиями, а полную стоимость Ozon переводит вам сразу. Изменить список товаров, для которых доступна рассрочка, можно в разделе **[Цены и акции → Мои акции](https://seller.ozon.ru/app/highlights/my-highlights/list)**.

**[Ускоренный сбор отзывов](https://seller-edu.ozon.ru/libra/work-with-byuers/otzyvy-za-bally/chto-takoe-otzyvy-za-baly)**** **— с помощью инструмента можно быстрее собрать отзывы и повысить продажи: товары с отзывами покупают значительно чаще. Изменить список товаров, участвующих в акции, можно в разделе **[Товары → Ускоренный сбор отзывов](https://seller.ozon.ru/app/reviews/promotions)****.**

## Как ускорить работу с таблицей

Собрали несколько способов, которые ускорят работу с таблицей, даже если в ней десятки товаров.

| Что сделать | Простой способ |
| --- | --- |
| Изменить значение в ячейке | Нажмите на неё дважды |
| Копировать и добавлять одно и то же значение, в том числе фото или видео | Используйте сочетание клавиш **Ctrl+C** и **Ctrl+V** |
| Перемещаться по ячейкам таблицы | Используйте стрелки на клавиатуре |
| Уменьшить масштаб страницы, если на экране видно не все параметры | Нажмите **Ctrl** и **–** |

## Как работать с черновиком

Черновик можно сохранить, если заполните хотя бы одно поле с артикулом в онлайн-таблице. Для этого нажмите **Сохранить черновик** над таблицей.

Будем хранить черновик 14 дней. Его можно найти в разделе **[Товары → Добавить товары → Через шаблон](https://seller.ozon.ru/app/products/import/file)** в блоке **Шаг 3. История обновлений **на вкладке **Черновики**.

После редактирования черновика можно опубликовать таблицу или снова сохранить её в черновик.

После каждого изменения и сохранения черновика появится новый файл в таблице, который будет доступен 7 дней.

# Какие ошибки автоматически проверяют онлайн-таблицы

Шаблон проверит:

название, цену и ОВХ;

заполнение обязательных характеристик;

правильность ссылок на фото и образцы цвета;

соответствие изображений техническим требованиям — формат, размер и разрешение.

# Как отредактировать онлайн-шаблон и исправить ошибки

Если ещё не загрузили таблицу

Подсветим ошибки в шаблоне, когда нажмёте **Отправить**. Все карточки с ошибками можно найти на вкладках **Дубли** и с **Ошибками**.

Через раздел «Загрузить товары через шаблон»

Все обработанные шаблоны отображаются в разделе **[Товары → Добавить товары → Через шаблон](https://seller.ozon.ru/app/products/import/file)** в блоке **Шаг 3. История обновлений**. Вы можете:

посмотреть товары с ошибками — нажмите на статус «Есть ошибки»;

исправить онлайн товары с ошибками или весь шаблон — нажмите **⋮** и выберите нужное действие;

скачать товары с ошибками — нажмите на **⋮ **или статус «Есть ошибки», а затем** Скачать товары с ошибкой**.

# Как посмотреть историю загрузок

Все шаблоны, с которыми вы работали, можно посмотреть в разделе **[Товары → Добавить товары → Через шаблон](https://seller.ozon.ru/app/products/import/file)** в блоке **Шаг 3. История обновлений**. Файлы хранятся 14 дней.

В истории можно:

посмотреть список шаблонов и информацию них — дату загрузки, название файла, статус;

скачать товары с ошибками или исходный файл — нажмите **⋮ **и выберите  нужное действие;

исправить онлайн товары с ошибками или весь шаблон — нажмите **⋮** и выберите нужное действие.

Список доступных действий зависит от статуса файла.

Если ошибок немного, исправьте товары по одному через раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**. Лишние позиции можно [убрать в архив](/work-with-goods/zagruzka-tovarov/created-goods/spisok-i-statysi-tovara#%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D1%82%D1%8C-%D1%81-%D0%B0%D1%80%D1%85%D0%B8%D0%B2%D0%BE%D0%BC), если случайно добавили одинаковые товары.

Какие статусы бывают:

| Статус | Что значит |
| --- | --- |
| Скоро проверим | Шаблон в очереди — система начнёт проверять его, как только обработает другие файлы. |
| Проверяем | Система проверяет шаблон. Обычно это занимает до 12 часов. |
| Проверен | Позиции из шаблона загружены в список ваших товаров. |
| Не загружен. Попробуйте ещё раз | Не удалось загрузить файл, загрузите шаблон повторно. |
| Есть ошибки | Некоторые поля заполнены неправильно. Нажмите на статус, чтобы посмотреть описание ошибок. |
