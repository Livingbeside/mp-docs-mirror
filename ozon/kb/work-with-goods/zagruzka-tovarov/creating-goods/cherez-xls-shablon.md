# Как работать с XLS-шаблоном

## Скачивайте актуальный шаблон в личном кабинете

Это нужно делать перед каждой загрузкой товаров, потому что мы регулярно обновляем шаблоны. Не используйте старые версии или файлы из других источников.

## Сохраняйте структуру файла и не пропускайте листы

Нельзя добавлять, перемещать или удалять листы и столбцы, а также скрывать ячейки или менять их тип.

Часто в шаблоне больше одного листа — заполните каждый из них. Например, есть отдельные листы:

**Документация PDF** — для сертификатов и других документов на товар. Укажите прямые ссылки на файлы в формате PDF — по ним должны открываться и скачиваться сами документы. Обычно такие ссылки заканчиваются символами *.pdf. Ссылки на облачные хранилища не подойдут.

**Озон.Видео** — здесь можно добавить ссылки на видео о товаре. В конце проверьте, чтобы в тексте не было ссылок на другие файлы.

**Озон.Видеообложка** — здесь можно добавить ссылки на короткие видео, которые будут проигрываться вместо главного фото в карточке товара.

## Правильно заполняйте строки

Для каждого артикула должна быть своя строка. Например:

| № | Артикул | Название | Размер |
| --- | --- | --- | --- |
| 1 | R17 | Кольцо «Романтика» | 17 |
| 2 | R18 | Кольцо «Романтика» | 18 |

## Заполняйте нужные поля

Разные регистры букв в характеристиках не делают карточку товара уникальной и приводят к созданию не похожей позиции, а дубля. Например, если для одного продукта указать цвет «белый», а для другого «Белый» — столкнётесь с ошибкой «Такой товар уже существует».

**Если товара ещё нет на Ozon**, укажите все возможные характеристики — они будут использоваться для поиска и фильтров по параметрам. Чем подробнее вы опишете товар, чем проще покупателям его найти. Красные поля заполнять обязательно.

**Если товар уже есть на Ozon**, и вы хотите его скопировать, заполните блок «Название и цены» и укажите SKU — по нему система сама найдёт товар и добавит его в ваш каталог.
Свой товар скопировать нельзя, даже если он продается в другом вашем личном кабинете. Такая карточка не пройдёт модерацию — на Ozon нельзя продавать дубли. Если у вас несколько магазинов, их ассортимент должен отличаться. [Как узнать SKU](https://seller-edu.ozon.ru/work-with-goods/zagruzka-tovarov/created-goods/uznat-sku-tovarov)

## Используйте подсказки

Они есть над каждым полем в шаблоне. Там мы даём советы и ссылки на **Базу знаний**. Если подсказка не видна целиком, растяните строку.

## Не меняйте тип значений

Используем в шаблоне несколько видов полей. Если заполните их данными другого формата, система выдаст ошибку.

Вот какие есть варианты:

**Число**. Впишите только числа, без единиц измерения. Например, в поле **Вес**, напишите **606**, без **грамм** или **г.**

**Текст**. В таких полях пишите информацию, которая нужна для параметров. Примеры полей: **Название товара**, **Бренд**, **Подробное описание**.

**Выбор из списка**. При нажатии на такую ячейку появляется знак  и подсказка **Выберите значение из списка**.

Если в столбце есть пометка **Множественный выбор**, можно указать сразу несколько значений. Для этого:

1. Нажмите  и посмотрите доступные варианты. Например, в поле **Цвет** есть «белый», «голубой», «зелёный».
2. Выберите первое значение, а остальные напишите в ячейке через точку с запятой без пробелов — так же, как они записаны в выпадающем списке. Например: «белый;голубой;зелёный».

# Как добавить товары через XLS-шаблон

Вы можете загрузить сразу все товары из одной категории через XLS-шаблон или [онлайн-таблицу](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-onlajn-tablicy).

Если потом понадобится отредактировать несколько товаров, в менеджере загрузок можно открыть загруженный XLS-файл через онлайн-таблицы — так вам не придётся снова его загружать.

## Шаг 1. Скачайте XLS-шаблон

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Через шаблон**.
2. Выберите категорию товара и нажмите **Скачать шаблон**. Если товар можно отнести к нескольким категориям, выберите одну наиболее подходящую. [Подробнее о категории товара](/work-with-goods/trebovaniya-k-kartochkam-tovarov/product-information/kategoriya-tovara#%D0%BA%D0%B0%D0%BA-%D0%B2%D1%8B%D0%B1%D1%80%D0%B0%D1%82%D1%8C-%D0%BA%D0%B0%D1%82%D0%B5%D0%B3%D0%BE%D1%80%D0%B8%D1%8E-%D0%B8-%D1%82%D0%B8%D0%BF-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0)

## Шаг 2. Заполните XLS-шаблон

В файле:

заполните все поля с пометкой **Обязательное поле**;

добавьте ссылки на фото товаров;

подключите продвижение, если хотите сделать товары заметнее;

укажите дополнительные характеристики — с ними товар привлекательнее для покупателей и его будет легче найти в поиске.

[Подробнее о характеристиках товара](/work-with-goods/reference-goods/avto#%D1%83%D0%BF%D1%80%D0%BE%D1%89%D1%91%D0%BD%D0%BD%D1%8B%D0%B8-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD-%D0%B4%D0%BB%D1%8F-%D0%B0%D0%B2%D1%82%D0%BE%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2)

Для категории «Автотовары» товары можно загрузить по упрощённому шаблону. [Как это сделать](/work-with-goods/reference-goods/avto#%D1%83%D0%BF%D1%80%D0%BE%D1%89%D1%91%D0%BD%D0%BD%D1%8B%D0%B8-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD-%D0%B4%D0%BB%D1%8F-%D0%B7%D0%B0%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B8-%D0%B0%D0%B2%D1%82%D0%BE%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2)

### Блок Название

**Артикул** — номер товара в вашей базе. Он должен быть уникальным для вашего ассортимента. Например, тетрадь с обложкой красного цвета и такая же тетрадь с обложкой синего цвета — это разные товары, поэтому их артикулы будут отличаться. [Подробнее об артикуле товара](/work-with-goods/trebovaniya-k-kartochkam-tovarov/articyl-tovara)
Если в вашей базе артикулы повторяются, сделайте их уникальными. Например, добавьте к артикулам цвета товаров, размеры или «_1», «_2», «_3».
**Пример**

Вы продаёте тетради разных цветов с одним артикулом DSPSWW. Укажите артикул:

DSPSWW_red для красной тетради,

DSPSWW_blue для синей,

DSPSWW_green для зелёной.

**Название **может формироваться автоматически на основе обязательных характеристик или вручную — в этом случае вы можете самостоятельно указать название, которое отображается на карточке товара. Названия, указанные вручную, попадают на модерацию. [Подробнее о требованиях к названиям](/work-with-goods/trebovaniya-k-kartochkam-tovarov/nazvanie-tovara)

### Блок Цены

**Предельная цена **— установите стоимость товара без учёта акций, выше этого значения цена не поднимется.

**Зачёркнутая цена** — это значение показываем рядом с ценой и считаем от неё процент скидки. Чтобы зачёркнутая цена отображалась в карточке, добавьте товар в [акцию от Ozon](https://seller-edu.ozon.ru/ceny-i-akcii/akcii-skidki-i-kupony/akcii-ozon) или в [собственную](https://seller-edu.ozon.ru/ceny-i-akcii/akcii-skidki-i-kupony/my-promo) с механикой **Скидка**. Зачёркнутая цена должна быть выше предельной цены.

**НДС** — выберите из списка значение ставки:
**Не облагается** — если вы работаете по УСН (Упрощённой Системе Налогообложения);

**10%** или **22%** — если ваша продукция облагается НДС. На большинство товаров действует ставка в 22%, но [некоторые позиции](https://nalog-nalog.ru/nds/stavka_nds/perechen-tovarov-oblagaemyh-nds-po-stavke-10/) облагаются НДС в 10%: например, мясо, детская продукция и т. д.

### Блок Платное продвижение

С помощью таблицы можно подключить:

**[Рассрочка](/how-to-sell-effectively/loyalty/besprotsentnaya-rassrochka)** — помогает увеличить продажи: покупателям проще купить товар, оплачивая его частями без переплаты. Дисконт удерживается только за проданные товары вместе с другими комиссиями, а полную стоимость Ozon переводит вам сразу. Изменить список товаров, для которых доступна рассрочка, можно в разделе **[Цены и акции → Мои акции](https://seller.ozon.ru/app/highlights/my-highlights/list)**.

**[Ускоренный сбор отзывов](https://seller-edu.ozon.ru/work-with-goods/reviews/otzyvy-za-bally/chto-takoe-otzyvy-za-baly)**** **— с помощью инструмента можно быстрее собрать отзывы и повысить продажи: товары с отзывами покупают значительно чаще. Изменить список товаров, участвующих в акции, можно в разделе **[Товары → Ускоренный сбор отзывов](https://seller.ozon.ru/app/reviews/promotions)****.**

В столбце выбранной акции укажите значения:

**Да**, чтобы включить продвижение;

**Нет **или оставьте пустым, чтобы акции не подключать.

### Блок Информация о товаре

Штрихкод (Серийный номер / EAN) — это код, по которому товар принимают на складе, поле обязательно для всех схем продаж. Без штрихкода не сможем выплатить компенсацию при утере. Может быть от производителя или сгенерированный в личном кабинете. Если их несколько, укажите все через точку с запятой.

Добавить штрихкод можно при создании товара или позже — в момент оформления заявки на поставку. [Подробнее про штрихкоды](/work-with-goods/trebovaniya-k-kartochkam-tovarov/rabota-so-shtrihkodami)

### Блок Дополнительная информация о товаре

**Вес в упаковке, г**; **Ширина упаковки, мм**; **Высота упаковки, мм**; **Длина упаковки, мм**. Укажите в полях только числа, без единиц измерения. Длина упаковки не обязательно должна быть наибольшей стороной, а высота — наименьшей.
Для каждой категории товаров есть максимальные и минимальные значения. Если вес и габариты от них отличаются, добавить позицию не получится.
Габариты товара без упаковки вы можете указать в разделе **Характеристики**.

**Ссылка на главное фото** — одна прямая ссылка на изображение в формате JPEG, JPG, PNG или на Яндекс.Диск. Можно загрузить шаблон без фото и добавить его позже в личном кабинете. [Подробнее о загрузке фото и видео](/work-with-goods/zagruzka-tovarov/media)

Если не укажете главное фото, выберем его из дополнительных. Такая карточка попадёт на вкладку **[Товары → Список товаров → Требует доработки](https://seller.ozon.ru/app/products?filter=partial_approved)**.

[Подробнее о требованиях к фото и ссылкам](/work-with-goods/trebovaniya-k-kartochkam-tovarov/foto-i-video-tovara)

### Блоки с характеристиками

Они собраны в четыре группы:

**Одинаковые характеристики** для всех вариантов товара, которые вы хотите объединить на одной карточке — в этих полях нужно указать одинаковые значения.

**Бренд**. Заполните поле, если вашего бренда ещё нет на Ozon — укажите **Нет бренда**. [Как проверить наличие бренда на Ozon](/work-with-goods/trebovaniya-k-kartochkam-tovarov/characteristics/brendy#%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%BD%D0%BE%D0%B2%D1%8B%D0%B8-%D0%B1%D1%80%D0%B5%D0%BD%D0%B4-%D0%BD%D0%B0-ozon)

**Характеристики вариантов** — значения могут быть одинаковыми или разными в зависимости от того, чем отличаются варианты. По этим параметрам сформируем переключатели на карточке товара.

**Дополнительные характеристики** — сопутствующая информация о товаре. Советуем заполнять все ячейки, потому что это сделает товар привлекательнее для покупателей и удобнее для поиска.

**Набор характеристик «Для чего подходит»** — его можно заполнить, если продаёте сопутствующие товары (например, аксессуары для смартфонов, стержни для ручек, автозапчасти). Укажите там бренд, модель и модификацию (если она предусмотрена) товара, для которого продаёте аксессуар. [Подробнее о наборе «Для чего подходит»](/work-with-goods/trebovaniya-k-kartochkam-tovarov/characteristics/harakteristiki-tovara#%D0%BA%D0%B0%D0%BA-%D0%B7%D0%B0%D0%BF%D0%BE%D0%BB%D0%BD%D1%8F%D1%82%D1%8C-%D0%BA%D0%B0%D1%80%D1%82%D0%BE%D1%87%D0%BA%D0%B8-%D0%B4%D0%BB%D1%8F-%D1%81%D0%BE%D0%BF%D1%83%D1%82%D1%81%D1%82%D0%B2%D1%83%D1%8E%D1%89%D0%B8%D1%85-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2)

Вот ещё несколько правил, чтобы загрузка товаров прошла без накладок:

Если планируете продавать несколько единиц в одном товаре (например, 3 пачки фруктовых чипсов в одной упаковке), укажите в поле **Единиц в одном товаре** нужное количество штук — например, «3». [Подробнее о создании комплектов товаров](/work-with-goods/zagruzka-tovarov/komplekty)

Если планируете продавать товары поштучно, укажите «1» в поле **Единиц в одном товаре**. Не пишите количество товара, которое планируете поставлять на склад.

Если загружаете товары категорий «шубы», «обувь», «одежда», «лекарства», «фотоаппараты и лампы-вспышки», «шины и покрышки», «товары лёгкой промышленности», «духи и туалетная вода», обязательно заполните поле **Код ОКПД/ТН ВЭД** — по нему мы определяем, подлежит ли позиция обязательной маркировке в системе «Честный ЗНАК». [Что такое ОКПД](/work-with-goods/trebovaniya-k-kartochkam-tovarov/product-information/obyazatelnaya-markirovka-tovarov#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D1%82%D0%B5%D1%80%D0%BC%D0%B8%D0%BD%D1%8B-%D0%BD%D1%83%D0%B6%D0%BD%D0%BE-%D0%B7%D0%BD%D0%B0%D1%82%D1%8C-%D0%B4%D0%BB%D1%8F-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%8B-%D1%81-%D0%BE%D0%B1%D1%8F%D0%B7%D0%B0%D1%82%D0%B5%D0%BB%D1%8C%D0%BD%D0%BE%D0%B8-%D0%BC%D0%B0%D1%80%D0%BA%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%BE%D0%B8) и [ТН ВЭД](/work-with-goods/trebovaniya-k-kartochkam-tovarov/product-information/tn-ved)

Если забудете указать ставку НДС при загрузке товара через XLS-шаблон Ozon, система автоматически поставит **Не облагается** — но вы в любой момент можете это отредактировать.

Если загружаете товары категорий: «сахаросодержащие напитки», «моторные масла», «безалкогольное пиво», укажите их тип в поле **Подакцизные товары.** [Подробнее про подакцизные товары](/work-with-goods/additional-materials/podakciznye-tovary)

Если заполните набор характеристик «Для чего подходит» и укажете некорректные данные — например, бренд Apple, а модель 13 Ultra, которая есть только у бренда Xiaomi — отправим товар на вкладку **Требует доработки** и отметим, что удалили некорректное значение.

## Шаг 3. Загрузите XLS-шаблон

Когда заполните шаблон:

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Через шаблон**.
2. В блоке **Шаг 2. Загрузите шаблон** выберите **Excel**.
3. Добавьте файл.
4. Включите **Открывать загружаемые шаблоны в режиме онлайн проверки** — пока доступно не всем продавцам. Настройка позволяет ещё раз [проверить шаблон перед публикацией](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-xls-shablon#%D1%88%D0%B0%D0%B3-4-%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D1%8C%D1%82%D0%B5-%D1%82%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%83): откроем его в онлайн-таблице и подсветим ошибки.
5. Нажмите **Опубликовать**.

## Шаг 4. Проверьте таблицу

Пока доступно не всем продавцам.

Если в шаблоне до 3 000 товаров, предложим проверить данные через онлайн-таблицу. На вкладке **С ошибками** покажем карточки, которые нужно исправить. Это можно сделать:

Через онлайн-таблицу — просто начните вносить изменения в нужных ячейка. [Как работать в онлайн-таблице](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-onlajn-tablicy#%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D1%82%D1%8C-%D1%81-%D1%82%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D0%B5%D0%B8)

Через файл. Для этого нажмите **Файл XLS → Скачать в XLS файл**, исправьте ошибки и сохраните файл. Затем нажмите **Файл XLS → Загрузить из в XLS файла** и добавьте отредактированный шаблон.

Автоматически проверим все поля заново. Если обнаружим ошибки, покажем их на вкладе **С ошибками**.

Когда всё будет готово, нажмите **Отправить**.

# Как изменить товары через XLS-шаблон

1. Перейдите в раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
2. Отметьте товары.
3. Нажмите **Действия **и выберите **Скачать шаблон по категориям XLS.**
4. Нажмите **Скачать шаблоны**. Найдите в списке шаблон и нажмите .
5. Внесите правки в шаблон и сохраните файл.
6. Когда всё будет готово, загрузите его в разделе **[Товары → Добавить товары → Через шаблон](https://seller.ozon.ru/app/products/import/file)**.

# Где посмотреть результаты загрузки XLS-шаблона

Если в шаблоне до 3 000 товаров, сразу после его загрузки предложим проверить данные через онлайн-таблицу. [Подробнее](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-xls-shablon#%D1%88%D0%B0%D0%B3-4-%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D1%8C%D1%82%D0%B5-%D1%82%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%83)

Все шаблоны, с которыми вы работали, можно посмотреть в разделе **[Товары → Добавить товары → Через шаблон](https://seller.ozon.ru/app/products/import/file)** в блоке **Шаг 3. История обновлений**. Файлы хранятся 14 дней.

В истории можно:

посмотреть список шаблонов и информацию них — дату загрузки, название файла, статус;

скачать товары с ошибками или исходный файл — нажмите **⋮ **и выберите  нужное действие;

исправить онлайн товары с ошибками или весь шаблон — нажмите **⋮** и выберите нужное действие.

Список доступных действий зависит от статуса файла.

Если ошибок немного, исправьте товары по одному через раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**. Лишние позиции можно [убрать в архив](/work-with-goods/zagruzka-tovarov/created-goods/spisok-i-statysi-tovara#%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D1%82%D1%8C-%D1%81-%D0%B0%D1%80%D1%85%D0%B8%D0%B2%D0%BE%D0%BC), если случайно добавили одинаковые товары.

Какие статусы бывают:

| Статус | Что значит |
| --- | --- |
| Скоро проверим | Шаблон в очереди — система начнёт проверять его, как только обработает другие файлы. |
| Проверяем | Система проверяет шаблон. Обычно это занимает до 12 часов. |
| Проверен | Позиции из шаблона загружены в список ваших товаров. |
| Не загружен. Попробуйте ещё раз | Не удалось загрузить файл, загрузите шаблон повторно. |
| Есть ошибки | Некоторые поля заполнены неправильно. Нажмите на статус, чтобы посмотреть описание ошибок. |

# Как загрузить автотовары по упрощённому шаблону

Упрощённый шаблон позволяет быстро загружать ассортимент. В нём можно завести разные категории товаров и затем дополнять их информацией, менять фотографии, добавлять видео и атрибуты.

1. Скачайте шаблон для нужной категории автотоваров.
2. Заполните только следующие столбцы: артикул, название, цена, НДС, бренд, партномер (артикул производителя), [подакцизные товары](/work-with-goods/additional-materials/podakciznye-tovary) (если загружаете моторное масло для дизельных, карбюраторных и инжекторных двигателей).
3. Вернитесь в раздел **[Товары → Добавить товары→ Через шаблон](https://seller.ozon.ru/app/products/import/file)**. Добавьте заполненный файл и нажмите **Опубликовать**.
