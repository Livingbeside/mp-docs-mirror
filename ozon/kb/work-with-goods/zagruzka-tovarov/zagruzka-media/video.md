# Как добавить видео в карточку товара

Убрали возможность загрузить видео с Youtube из-за технических проблем на стороне видеохостинга. Это никак не повлияет на уже загруженные ролики. Рекомендуем перенести видео на другие платформы:

[Инструкция для VK Видео](https://vk.com/@youtubetransfer-kak-skopirovat-video-iz-youtube-v-vk);

[Инструкция для Rutube](https://rutube.ru/info/youtube/).

1. [Заполните характеристики товара](/work-with-goods/zagruzka-tovarov/creating-goods/sozdanie-tovarov-v-lk), а затем:
  в упрощённой форме — нажмите **Заполнить больше**, перейдите на вкладку **Медиа** и в поле **Видео** нажмите **Добавить видео**;
  
  в полной форме — на вкладке **Медиа** в поле **Видео** нажмите **Добавить видео**.
2. Загрузите не больше 5 роликов одним из способов:
  перетащите файл в дропзону;
  
  нажмите на **+** и добавьте видео с компьютера;
  
  укажите ссылку на Яндекс Диск, VK Видео и Rutube. Чтобы добавить несколько, прикрепляйте их по очереди — ссылки через запятую система не поймёт.
  На VK Видео и Rutube копируйте ссылку на само видео, на Яндекс Диске — на файл или папку с несколькими роликами. [Какой должна быть ссылка и как её скопировать](/work-with-goods/trebovaniya-k-kartochkam-tovarov/media/foto-i-video-tovara#%D1%82%D1%80%D0%B5%D0%B1%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F-%D0%BA-%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B0%D0%BC-%D0%BD%D0%B0-%D0%B2%D0%B8%D0%B4%D0%B5%D0%BE)
  Добавленные видео можно удалять и менять местами.
3. Когда всё будет готово, нажмите **Сохранить**. Ждать загрузки не нужно — начнём скачивать ролики только после создания товара.
4. Заполните остальные характеристики товара и нажмите **Добавить**.

Скачаем ролик, чтобы он надёжно хранился на сайте Ozon и быстрее открывался у покупателей. Загруженное видео легко добавить в другие карточки с помощью [шаблонов](#как-добавить-видео-через-шаблон). Так не придётся снова ждать, когда ролик скачается.

Загружаемый вами оригинал мы обрабатываем и сжимаем для удобного отображения в карточках товара. Оригинал храним не более 180 дней, после этого можем удалить файл. Само видео при этом остаётся в карточке, запускается у покупателей и хранится у нас в сжатом виде.

Перед публикацией проверяем каждое видео — если оно нарушает наши требования, товар будет продаваться, но попадёт в раздел **[Товары → Список товаров → Ошибки](https://seller.ozon.ru/app/products?filter=validation_state_fail)**.

1. Перейдите в раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**. В нужной строке нажмите **⋮** и выберите **Редактировать медиа**.
2. На вкладке **Видео** загрузите не больше 5 роликов одним из способов:
  перетащите файл в дропзону;
  
  нажмите на **+** и добавьте видео с компьютера;
  
  укажите ссылку на Яндекс Диск — чтобы добавить несколько, прикрепляйте их по очереди. Ссылки через запятую система не поймёт.
  Копируйте ссылку на файл или папку с несколькими роликами. [Какой должна быть ссылка и как её скопировать](/work-with-goods/trebovaniya-k-kartochkam-tovarov/foto-i-video-tovara#%D1%82%D1%80%D0%B5%D0%B1%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F-%D0%BA-%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B0%D0%BC-%D0%BD%D0%B0-%D0%B2%D0%B8%D0%B4%D0%B5%D0%BE)
  Добавленные видео можно удалять и менять местами.
3. Когда всё будет готово, нажмите **Сохранить**. Ждать загрузки не нужно.

После этого скачаем ролик, чтобы он надёжно хранился на сайте Ozon и быстрее открывался у покупателей. Загруженные видео легко добавить в другие карточки с помощью [шаблонов](/work-with-goods/zagruzka-tovarov/zagruzka-media/video#как-добавить-видео-через-шаблон). # Как добавить видео через шаблон

[Какие видео подходят для карточки](/work-with-goods/trebovaniya-k-kartochkam-tovarov/foto-i-video-tovara#%D0%BA%D0%B0%D0%BA%D0%B8%D0%BC-%D0%B4%D0%BE%D0%BB%D0%B6%D0%BD%D0%BE-%D0%B1%D1%8B%D1%82%D1%8C-%D0%B2%D0%B8%D0%B4%D0%B5%D0%BE)

1. Откройте шаблон через [XLS-файл](/work-with-goods/zagruzka-tovarov/cherez-xls-shablon) и [онлайн-таблицу](/work-with-goods/zagruzka-tovarov/creating-goods/cherez-onlajn-tablicy).
2. Перейдите на вкладку **Озон.Видео**. Укажите ссылку на видео с Яндекс Диска, VK Видео, Rutube или из другой карточки своего товара. Чтобы добавить несколько роликов, укажите каждую ссылку с новой строки.
  **С Яндекс Диска, ****VK Видео и Rutube **добавляйте видео, которого ещё нет в ваших карточках. Скачаем ролик, чтобы он надёжно хранился на сайте Ozon и быстрее открывался у покупателей. Создадим прямую ссылку на видео, чтобы вы могли использовать его для нескольких товаров и не ждать загрузки.
  
  **С Ozon** добавляйте видео, которое уже есть в других ваших карточках — ролик загрузится моментально. [Как скопировать видео из другой карточки](#как-скопировать-видео-из-другои-карточки)
3. Загрузите XLS-файл или сохраните онлайн-таблицу.

Перед публикацией проверяем каждое видео — если оно нарушает наши требования, товар будет продаваться, но попадёт в раздел **[Товары → Список товаров → Ошибки](https://seller.ozon.ru/app/products?filter=validation_state_fail)**.

# Как скопировать видео из другой карточки

1. Перейдите на вкладку **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
2. Найдите товар, у которого есть нужное видео.
3. Нажмите **Действия** и выберите **Скачать шаблон по категориям XLS**.
4. Нажмите** Скачать шаблоны**.
5. Разверните список шаблонов, возле нужного нажмите . Файлы хранятся в истории 15 дней.
6. Откройте файл. На вкладке **Озон.Видео** скопируйте ссылку.
