# Таблица размеров

_Главная / Работа с товарами / Создание и редактирование товаров / Загрузка медиа_

Как создать свою таблицу размеров и добавить её в карточку товара

# Что такое таблица размеров

В карточках одежды, обуви, спорттоваров и других товаров с размерными сетками покупатели видят кнопку **Таблица размеров**. Если продаёте такие товары, рекомендуем:

создать таблицу размеров с помощью [конструктора](#как-пользоваться-конструктором-таблицы-размеров);

[добавить JSON-код](/work-with-goods/zagruzka-tovarov/zagruzka-media/size-constructor#%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%82%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%83-%D1%80%D0%B0%D0%B7%D0%BC%D0%B5%D1%80%D0%BE%D0%B2-%D0%B2-%D0%BA%D0%B0%D1%80%D1%82%D0%BE%D1%87%D0%BA%D1%83-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0) — если у вас уже есть готовая таблица;

[загрузить картинку](/work-with-goods/zagruzka-tovarov/zagruzka-media/foto) с размерной сеткой.

С помощью таблицы можно показать соответствие своей линейки с другими размерами по разным параметрам. В результате покупатели будут реже возвращать товары по причине «Не подошёл размер».

Что увидят покупатели по нажатию на кнопку **Таблица размеров**:

Если вы создали таблицу размеров с помощью конструктора** **или JSON, то откроем именно её — даже если в карточке есть картинка с таблицей размеров.

Если вы не создавали таблицу, но добавили картинку с размерной сеткой — автоматически покажем её под кнопкой.

Если вы не создавали таблицу, не добавили или удалили картинку с размерами — покупатели увидят стандартную таблицу.

# Зачем нужен конструктор

Для продавцов одежды, обуви, спорттоваров и другой продукции с размерными сетками мы добавили визуальный конструктор для таблицы размеров. Так вы сможете показать соответствие своей линейки с другими размерами по разным параметрам — в результате покупатели будут реже возвращать товары по причине «не подошёл размер».

Чем ещё хорош конструктор:

можно всё сделать самостоятельно — и не нужно просить добавить таблицы через поддержку;

не обязательно делать всё за раз — мы сохраняем черновик, чтобы вы могли к нему вернуться;

размерные сетки подстроятся под размер экрана — на этапе предпросмотра можно проверить, как они выглядят с компьютера и смартфона.

# Как пользоваться конструктором таблицы размеров

## Шаг 1. Открыть конструктор

Это можно сделать [на отдельном сайте](https://table-constructor.ozon.ru/visual-editor) или из вашего личного кабинета.

Чтобы попасть в конструктор из кабинета:

1. Откройте раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
2. В строке с нужным товаром нажмите ⋮ и выберите **Редактировать товар**.
3. Откройте вкладку **Медиа** и в блоке **Таблица размеров** нажмите **Открыть визуальный редактор**.
4. Нажмите **Создать** — конструктор откроется в панели справа.

Если вы внесёте изменения и закроете конструктор, браузер сохранит черновик — так вы сможете продолжить позже. При работе в личном кабинете сохраняем черновики для каждого товара, на внешнем сайте — только одну последнюю версию.

## Шаг 2. Добавить виджеты

Мы советуем создавать таблицы размеров в визуальном редакторе, но ваш программист может воспользоваться и вкладкой **Песочница** — там можно написать таблицу сразу в JSON.

В редакторе несколько типов блоков:

**таблица** — сетка размеров и объёмов. Названия строк можно менять и к каждой добавить подсказку при необходимости;

**инструкция по обмерам**  — готовые рекомендации для покупателей о том, как снимать мерки, изменить текст в этом блоке не получится;

**предупреждение** — дополнительная информация об особенностях ваших товаров. Вы можете выбрать готовый вариант или написать свой, а ещё решить, какие блоки вам нужны: заголовок и основной текст.

Чтобы создать размерную сетку, перетащите любой блок в рабочую область. Их количество и порядок могут быть любыми, но обязательно должна быть хотя бы одна **Таблица**.

### Настройки блока Таблица

Это основной блок в таблице размеров, поэтому он сразу будет в рабочей области. Чтобы открыть настройки, кликните на любую ячейку.

Есть три способа добавить контент:

использовать универсальный вид таблицы — мы подготовили шаблоны для разных типов товаров, от женской одежды до детских носков;

выбрать свой вариант — в этом случае сможете создать её полностью с нуля;

загрузить из Excel — нужно будет выбрать файл на компьютере, и он добавится в редактор. [Скачать шаблон и пример заполнения](https://cdn.ozone.ru/s3/ozon-disk-api/Seller-edu/files/work-with-goods/trebovaniya-k-kartochkam-tovarov/size-konstruktor/shablon-tablicy-razmerov_1678460781.xlsx)

При любом варианте вы сможете управлять содержимым таблицы. Например:

решать, нужен ли заголовок — есть специальный переключатель;

редактировать текст — для этого нажмите на ячейку;

добавлять и удалять колонки — для этого выделите столбец и нажмите иконку соответствующего действия;

делать подсказки к параметрам в первом столбце — для этого включите галочку и напишите текст;

менять количество строк. Чтобы удалить, нажмите иконку корзины, чтобы сделать новую — кнопку **Добавить строку**.

В первом столбце нужно прописывать параметры, а в соседних — соответствующие значения. Столбец с параметрами будет закреплён, чтобы при прокрутке страницы он всегда был на виду у покупателя.

Максимальное количество символов для всей таблицы — 10 000.

## Шаг 3. Проверить результат

Чтобы посмотреть, как готовая таблица размеров будет отображаться на сайте, нажмите кнопку **Предпросмотр**. Там можно переключать режимы с десктопного на мобильный с помощью иконок.

Чтобы вернуться к редактированию, нажмите **Назад**.

# Как добавить таблицу размеров в карточку товара

Что важно знать перед добавлением:

Если в карточке есть картинка с таблицей размеров — когда добавите новую таблицу из конструктора или JSON-код, она заменит картинку.

Если уже добавляли таблицу через конструктор или JSON-код, новая таблица заменит старую — вернуть её уже не получится. Чтобы не потерять данные, советуем сначала сохранить код в любом текстовом редакторе или скопировать размеры прямо с карточки товара на сайте и зафиксировать их в Excel.

Когда всё будет готово:

1. Нажмите **Скачать JSON** в правом верхнем углу конструктора.
2. Откройте полученный файл любым текстовым редактором и скопируйте код.
3. Перейдите в раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**, в строке с нужным товаром нажмите **⋮** и выберите **Редактировать товар**.
4. Откройте вкладку **Медиа** и вставьте код в поле **JSON таблицы размеров**.
5. Нажмите **Далее**, а затем **Сохранить товар**.

Сразу для нескольких позиций добавить таблицу размеров можно через XLS-шаблон (в столбце **Таблица размеров JSON**) или API.

Когда всё будет готово, нажмите **Сохранить** в правом верхнем углу конструктора — код автоматически появится в поле **JSON таблицы размеров**. Останется нажать **Далее**, а затем **Сохранить товар**.

Если таблица размеров подходит для нескольких товаров, добавьте код JSON каждому из них в личном кабинете на вкладке **Медиа** или в шаблоне XLS в столбце **Таблица размеров JSON**. Это относится и к вариациям по цвету, размеру и другим характеристикам — даже если позиции объединены в одну карточку.
