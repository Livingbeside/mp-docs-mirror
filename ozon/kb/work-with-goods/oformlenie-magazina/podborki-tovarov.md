# Подборки товаров

_Главная / Работа с товарами / Оформление магазина_

Как создать страницу с вашими товарами, чтобы делиться ей в рассылках, соцсетях и акциях

Это бесплатный инструмент, который позволяет продавцам самостоятельно формировать страницы с определёнными товарами для рекламных кампаний, внешних коммуникаций и акций. Подборка будет доступна на сайте по прямой ссылке — её можно добавить на [витрину магазина](/personal-account/showcase), в [баннер](/how-to-sell-effectively/media-advertising) на Ozon, указать в рассылке, разместить в своих соцсетях или у популярного блогера.

# Создать подборку

Если вы зарегистрированы как представитель бренда, можете создать подборку из товаров одного или нескольких брендов. [Как это сделать](/account-brand/podborki-tovarov-brenda)

1. Откройте раздел:
  на сайте — перейдите на страницу **[Товары → Подборки товаров](https://seller.ozon.ru/app/seller-highlights/list)**;
  
  в мобильном приложении — нажмите **Меню** и в разделе **Развитие бизнеса** выберите **Подборки товаров.**
2. Нажмите **Создать подборку **и выберите тип подборки:
  Автоматическая — сформируем подборку c товарами по фильтрам, которые вы выберете. Когда в магазине появятся новые товары с подходящими параметрами, автоматически добавим их в подборку;
  
  Ручная — вы самостоятельно выберете список товаров для подборки.
  
  Акционная — добавим в подборку все товары из акции, которую вы создадите сами. [Подробнее о собственных акциях](https://seller-edu.ozon.ru/ceny-i-akcii/akcii-skidki-i-kupony/my-promo)

1. Укажите:
  название подборки, которое поможет вам быстро ориентироваться в списке. Например, «Подборка для соцсетей»;
  
  дату начала и окончания — период, в течение которого страница с подборкой товаров будет размещена на Ozon.

1. Уточните список товаров для подборки с помощью фильтров:
  выберите категорию;
  
  настройте ценовой диапазон;
  
  укажите бренды;
  
  определитесь с ограничениями по ценам;
  
  настройте другие фильтры, зависящие от категории товара.
2. Когда нужный список сформируется, нажмите **Создать подборку**.

В блоке **Основные настройки** появится ссылка на страницу с выбранными товарами. Её можно скопировать и разместить в нужном канале коммуникации с покупателями.

2. Выберите товары для подборки, для этого нажмите **Добавить из списка**.

# Настроить порядок товаров в подборке

Управлять порядком товаров в подборке могут только продавцы с [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-pro) и только в личном кабинете на сайте.

1. Откройте подборку.
2. В блоке **Меняйте товары местами** нажмите **Настроить**.
3. В новом окне нажмите **Добавить товары** и выберите не больше 100 позиций из подборки, для которых хотите настроить порядок.
4. Распределите товары по порядку: зажмите  и перетащите товар на нужное место или укажите позицию в столбце **№**.
5. Когда настроите порядок у товаров, нажмите **К подборке.**

Покупатели могут видеть товары в подборке в разном порядке. Например, если в каком-то регионе товар недоступен для продажи — он не отобразится в подборке.

# Отредактировать подборку

Отредактировать акционную подборку не получится, чтобы изменить список товаров или период, перейдите в акцию.

1. Откройте раздел:
  на сайте — перейдите на страницу **[Товары → Подборки товаров](https://seller.ozon.ru/app/seller-highlights/list)**;
  
  в мобильном приложении — нажмите **Меню** и в разделе **Развитие бизнеса** выберите **Подборки товаров.**
2. На вкладке **Активные** нажмите подборку.
3. Вы можете:
  поменять название;
  
  изменить период;
  
  изменить настройки фильтров — у автоматической подборки;
  
  добавить или удалить товары — у ручной подборки.
  Когда внесёте изменения, нажмите **Сохранить**.

Подборка обновится, ссылка на страницу с ней останется прежней.

Изменения у ручной подборки появится на сайте в течение 24 часов.

# Удалить подборку

Чтобы удалить акционную подборку, перейдите в акцию и удалите её.

1. Откройте раздел:
  на сайте — перейдите на страницу **[Товары → Подборки товаров](https://seller.ozon.ru/app/seller-highlights/list)**;
  
  в мобильном приложении — нажмите **Меню** и в разделе **Развитие бизнеса** выберите **Подборки товаров.**
2. На вкладке **Активные** нажмите на нужную подборку.
3. Нажмите **Удалить** и подтвердите действие.
