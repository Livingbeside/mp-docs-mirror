# Штрихкоды

_Главная / Работа с товарами / Требования к карточкам товаров / Информация о товаре_

Какие есть требования к штрихкодам, как их добавлять и генерировать, как наносить на товары

Если вы продаёте товары по схемам [FBO](/libra/fbo), [FBS](/libra/fbs) и [realFBS](/libra/rfbs) вам понадобятся штрихкоды для всех товаров. Вы можете использовать:

ваши штрихкоды (например, от производителя) — если они соответствуют [требованиям](#%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D1%82%D1%80%D0%B5%D0%B1%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F-%D1%83-%D1%88%D1%82%D1%80%D0%B8%D1%85%D0%BA%D0%BE%D0%B4%D0%BE%D0%B2);

уникальные штрихкоды Ozon — их можно сгенерировать в личном кабинете.

# Зачем нужны штрихкоды

На FBO по штрихкодам принимаем продукцию на складе, поэтому:
товары без штрихкода не получится добавить в [заявку на поставку](/fbo/process-details/fill-in-application-form) и не сможем выплатить компенсацию при утере;

если штрихкод на товаре и в личном кабинете отличается, товар не примут на складе и его придётся [забрать](/fbo/warehouses/zabrat-tovary-so-sklada).

На FBS товары без кодов будут продаваться как обычно, но при недостаче или утере на складе или АПВЗ не сможем возместить их стоимость. Проверим, есть ли штрихкод на товаре и в карточке, только если продукцию вернут, но она не придёт вам за 60 дней.

При работе на realFBS без штрихкода на товаре не сможем выплатить компенсацию при утере во время логистических процессов: при выдаче в ПВЗ Ozon или при возврате силами Ozon.

# Требования к штрихкодам

Ozon поддерживает штрихкоды в форматах:

EAN-8

EAN-13

EAN-14 (GTIN-14)

ISBN-10

ISBN-12

UPC-12

Code 39 — к шифрованию допускаются только символы: заглавные латинские буквы (от A до Z), цифры (от 0 до 9), специальные символы: - . $ / + % и пробел.

Форматы Data Matrix ECC 200 и GS1 DataBar ES больше не поддерживаются.

В начале штрихкода не указывайте сочетания букв: BP, BX, BXDC, CB, CL, OZN, II, PL, PLDC, SC, SR, US. Система может неправильно обработать их.

Для штрихкодов есть пара правил:

один продавец не может добавить одинаковые штрихкоды для разных товаров;

два продавца могут добавить одинаковые штрихкоды для одного и даже для разных товаров;

нельзя добавить штрихкод для уценённого товара на FBS.

# Добавить штрихкоды

Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды**, [вручную](#вручную) или в [XLS-шаблоне](/work-with-goods/zagruzka-tovarov/cherez-xls-shablon) можно:

указать или сгенерировать штрихкоды при загрузке товаров;

добавить новый штрихкод при обновлении загруженных позиций.

У одного товара может быть не больше 100 штрихкодов.

Если продаёте маркированные товары

Для товаров на FBS и FBO в поле «Штрихкод» укажите GTIN из [кода маркировки](https://seller-edu.ozon.ru/libra/work-with-goods/trebovaniya-k-kartochkam-tovarov/product-information/obyazatelnaya-markirovka-tovarov#%D0%BA%D0%B0%D0%BA-%D1%83%D0%BA%D0%B0%D0%B7%D0%B0%D1%82%D1%8C-gtin-%D0%B2-%D0%BA%D0%B0%D1%80%D1%82%D0%BE%D1%87%D0%BA%D0%B5-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0-%D0%BF%D1%80%D0%B8-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B5-%D0%BD%D0%B0-fbo).

GTIN — 14-значный номер из кода маркировки, который хранится в международной базе GS1 и описывает сразу несколько параметров товара.

Проверка в «Честном знаке» работает в тестовом режиме.

Все добавленные GTIN в карточку отправляем на проверку в «Честный знак». Если хотя бы один из них зарегистрирован в системе, отобразим это в карточке товара. Если GTIN не прошёл проверку — мы пришлём уведомление в личном кабинете. Результаты проверки кодов по всем товарам [можно узнать в отчёте](/work-with-goods/trebovaniya-k-kartochkam-tovarov/product-information/rabota-so-shtrihkodami#посмотреть-результаты-проверки-кодов-в-«честном-знаке»).

Если добавляете свой штрихкод

Он проходит автоматическую проверку. Результат отобразим цветом:

чёрный — штрихкод успешно прошёл проверку, товар готов к продаже;

серый — штрихкод находится на проверке;

красный — штрихкод нельзя использовать, потому что:
он уже указан для другого вашего товара;

для него не найден SKU ID — например, если вы добавили штрихкод вручную и неправильно указали Ozon SKU ID после OZN.

Чтобы посмотреть, почему штрихкод не прошёл проверку откройте страницу **Товары → Добавить товары** и нажмите **Обновить штрихкоды** или **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**:

наведите курсор на красный штрихкод;

перейдите на вкладку **С ошибками** — причина будет указана в поле «Описание ошибки».

## Вручную

При работе на FBS добавить штрихкод нужно до отгрузки на пункт — только в этом случае сможем компенсировать вам стоимость потерянных возвратов.

Для всех товаров без штрихкода

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды**.
2. Выберите вкладку **Без штрихкода**.
3. Вы можете:
  автоматически сгенерировать штрихкоды для всего списка — для этого нажмите** Сгенерировать для всех** и подтвердите действие;
  
  указать штрихкоды вручную — нажмите **Добавить **в строке нужного товара.
  [Как генерируются штрихкоды](#%D0%BA%D0%B0%D0%BA-%D0%B3%D0%B5%D0%BD%D0%B5%D1%80%D0%B8%D1%80%D1%83%D1%8E%D1%82%D1%81%D1%8F-%D1%88%D1%82%D1%80%D0%B8%D1%85%D0%BA%D0%BE%D0%B4%D1%8B)

Для отдельных товаров

Если вы хотите добавить или сгенерировать штрихкоды для отдельных товаров:

1. Перейдите на страницу **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды** или **[Товары](https://seller.ozon.ru/app/products?filter=all)**[ → ](https://seller.ozon.ru/app/products?filter=all)**[Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
2. В столбце **Штрихкод** нажмите:
  кнопку **Добавить** — если штрихкода нет;
  
  на штрихкод — если хотите его изменить.
3. Добавьте один или несколько штрихкодов:
  если у вас есть штрихкод, укажите его — чтобы добавить ещё один, нажмите ;
  
  если нет — нажмите **Сгенерировать**, чтобы система создала уникальный штрихкод. [Как генерируются штрихкоды](#%D0%BA%D0%B0%D0%BA-%D0%B3%D0%B5%D0%BD%D0%B5%D1%80%D0%B8%D1%80%D1%83%D1%8E%D1%82%D1%81%D1%8F-%D1%88%D1%82%D1%80%D0%B8%D1%85%D0%BA%D0%BE%D0%B4%D1%8B)
  Для одного товара можно добавить не больше 100 штрихкодов.
4. Проверьте: введённые штрихкоды указаны внизу. Если всё верно, нажмите **Сохранить**.

Если добавляете свой штрихкод, он проходит автоматическую проверку.

## Через XLS-файл

1. Перейдите на страницу **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды**.
2. Нажмите **Ещё**, выберите **Скачать в XLS** и откройте загруженный файл.
3. Выберите, что нужно сделать:
  чтобы сгенерировать штрихкод, укажите «да» в поле **Сгенерировать штрихкод**. [Как генерируются штрихкоды](#%D0%BA%D0%B0%D0%BA-%D0%B3%D0%B5%D0%BD%D0%B5%D1%80%D0%B8%D1%80%D1%83%D1%8E%D1%82%D1%81%D1%8F-%D1%88%D1%82%D1%80%D0%B8%D1%85%D0%BA%D0%BE%D0%B4%D1%8B)
  
  чтобы указать штрихкод вручную, введите его в поле **Ввести штрихкод вручную**. Если вы хотите добавить несколько штрихкодов для одного товара, скопируйте и вставьте строку с товаром. В каждой строке — один штрихкод.
4. В личном кабинете нажмите **Загрузить штрихкоды** и загрузите заполненный файл.

Если добавляете свой штрихкод, он проходит автоматическую проверку.

# Как генерируются штрихкоды

Система создаёт уникальный штрихкод для каждого товара. Он состоит из символов «OZN» и идентификатора товара SKU товара.

[Чем отличаются штрихкод, артикул и Ozon ID](#%D1%87%D0%B5%D0%BC-%D0%BE%D1%82%D0%BB%D0%B8%D1%87%D0%B0%D1%8E%D1%82%D1%81%D1%8F-%D1%88%D1%82%D1%80%D0%B8%D1%85%D0%BA%D0%BE%D0%B4-%D0%B0%D1%80%D1%82%D0%B8%D0%BA%D1%83%D0%BB-%D0%B8-ozon-id)

**Пример**

SKU — 1234567891. Система сгенерирует штрихкод OZN1234567891.

Генерация штрихкодов занимает некоторое время. По окончании в «OZNXXXXXXXXXX» будут подставлены сгенерированные цифры.

# Посмотреть список штрихкодов товара

Перейдите на страницу **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды **или **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)** и нажмите на штрихкод — откроется список штрихкодов данного товара. Они сгруппированы по статусам:

**На проверке** — штрихкоды ещё не прошли проверку;

**Действующие** — штрихкоды прошли проверку и готовы к продаже;

**Непринятые** — штрихкоды нельзя использовать для продажи товаров.

# Как проверить штрихкод в приложении Ozon Seller

Штрихкоды товаров можно проверить с телефона — в мобильном приложении.

1. Перейдите в** Меню → Сканер.**
2. Выберите **Товары**.
3. Отсканируйте этикетку — покажем название, штрихкод товара, цену и остатки, если вы продаёте товары по схеме FBS. Чтобы узнать подробности, нажмите **Перейти в карточку товара**. Здесь же вы можете выбрать **Изменить остатки FBS**.

# Посмотреть результаты проверки кодов в «Честном знаке»

Результаты проверки не влияют на приёмку товара. Для поставок действуют [текущие требования](https://seller-edu.ozon.ru/fbo/markirovka-tovarov/chestny-znak) к маркировке.

Если товар подлежит обязательной маркировке, отправим его GTIN на проверку в систему «Честный знак». Если всё в порядке, покупатели увидят в карточке значок «Товар зарегистрирован», а в информации о продавце появится строчка о вашей регистрации в системе маркировки. Такая отметка — плюс к доверию клиентов. Информация о маркировке в карточке появляется не сразу. Если прошло много времени, а отметка так и не появилась, обратитесь в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM).

Пока проверка необязательна и носит информационный характер. [Как это работает](/work-with-goods/trebovaniya-k-kartochkam-tovarov/product-information/obyazatelnaya-markirovka-tovarov#как-получить-отметку-о-регистрации-в-«честном-знаке»-блок-в-самом-конце-статьи)

Чтобы узнать результаты проверки:

1. Перейдите в раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды**.
2. Нажмите **Ещё**, выберите **Скачать в XLS** и откройте загруженный файл.
3. В столбце **Статус проверки в Честный знак** посмотрите результат проверки.

| **Статус** | **Что значит** |
| --- | --- |
| **Проверка пройдена** | GTIN прошёл проверку, товар зарегистрирован в «Честном знаке». Отобразим это в карточке товара. |
| **Проверка не пройдена** | GTIN не найден в «Честном знаке», товар не зарегистрирован по данным системы. Рекомендуем узнать причину, исправить данные и пройти проверку повторно, чтобы в карточке товара появилась отметка. |
| **Не применимо** | Вы не добавили GTIN товара в карточку или товар не подлежит маркировке. GTIN не отправлен на проверку в «Честный знак».Штрихкод товара сгенерирован автоматически в личном кабинете — такие штрихкоды начинаются с OZN***.Штрихкод больше 14 символов. |

# Изменить или удалить штрихкод

Непринятые или штрихкоды на проверке можно удалить или изменить в любой момент.

1. Перейдите на страницу **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды **или **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
2. Найдите нужный товар и нажмите на его штрихкод.
3. В открывшемся окне справа от штрихкода нажмите **⋮** и выберите нужное действие.

## Как поменять два штрихкода местами

Удалите штрихкод у одного из товаров перед тем, как добавить его для второго — система не даст сохранить один код для обоих.

Как это сделать:

1. Перейдите на страницу **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды **или **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
2. Найдите один из товаров и нажмите на его штрихкод.
3. В открывшемся окне скопируйте штрихкод, затем нажмите **⋮** и выберите **Удалить**.
4. Найдите второй товар и нажмите на его штрихкод.
5. В открывшемся окне нажмите **Добавить штрихкод** и укажите правильный код. Второй штрихкод скопируйте и удалите.
6. Вернитесь к первому товару — укажите верный штрихкод.

**Пример**

Вы указали для чайника штрихкод H123456, а для холодильника — CH789012, и хотите их поменять.

1. Для чайника скопируйте и удалите штрихкод H123456.
2. Для холодильника добавьте H123456 и сохраните. Скопируйте и удалите CH789012.
3. Для чайника добавьте CH789012 и сохраните.

Не забудьте до поставки распечатать новые штрихкоды и наклеить их на товары.

## Когда не получится удалить и изменить штрихкод

Действующий штрихкод нельзя отредактировать и удалить, если товар продавался по схеме FBO и его остатки закончились меньше, чем 6 месяцев назад.

Нельзя отредактировать штрихкоды, сгенерированные автоматически. Пример такого штрихкода: OZN32322342.

# Скачать и наклеить штрихкоды

Если в вашем личном кабинете привязано несколько действующих штрихкодов, на складе ваши товары примут с любым из них.

Если вы работаете по схеме FBS, без штрихкода на товаре не сможем:

перепродать возвраты;

выплатить компенсацию при утере.

На распечатанном штрихкоде будет:

код, указанный вами или сгенерированный Ozon;

артикул товара;

название товара или альтернативное название товара, если позиция из категории «Товары для взрослых».

Категории товаров, для которых можно выбрать альтернативное название

БДСМ;

Интимная косметика;

Кондитерские изделия 18+;

Контрацептивы;

Лубрикант;

Мебель и текстиль для секса;

Одежда и аксессуары эротические;

Парфюмерия с феромонами;

Секс-игрушки;

Сувениры и игры эротические;

Уход и хранение секс-игрушек.

Альтернативное название помогает покупателям сохранить анонимность при доставке и получении эротических товаров. Выбрать его можно при создании или редактировании карточки из выпадающего списка характеристики **Альтернативное наименование товара в накладной**. [Подробнее о характеристиках товара](/work-with-goods/trebovaniya-k-kartochkam-tovarov/characteristics/harakteristiki-tovara)

Если альтернативное название для эротических товаров не выбрано, система автоматически подставит значение из нашего списка.

## Скачать штрихкоды для отдельных товаров

Подходит, если нужно скачать штрихкоды только для части товаров — поштучно, для каждого отдельно.

1. Откройте раздел **[Товары → Добавить товары](https://seller.ozon.ru/app/products/create)** и нажмите **Обновить штрихкоды** или **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**, в строке товара нажмите **⋮** и выберите **Скачать PDF**.
2. Выберите тип принтера. Для специального система адаптирует размер штрихкодов под печать на ленте.
  Для обычного офисного нужно указать количество и размер, он зависит от формата бумаги, заводского штрихкода и самого товара. Есть такие варианты:
  маленький — 30х20 мм;
  
  средний — 43х25 мм;
  
  большой — 58х40 мм.
3. Нажмите **Скачать в PDF**. Готовые штрихкоды нужно наклеить на каждый товар. Если печатали на обычном принтере, предварительно вырезать вручную.

## Как наклеить штрихкоды

На FBO — наклейте штрихкод на каждый товар на этапе подготовки. Если товару нужна дополнительная упаковка, наклейте на неё такой же штрихкод, как и у товара в личном кабинете. [Подробнее о требованиях к упаковке](/fbo/process-details/package)

На FBS — наклейте штрихкод на каждую позицию. Если товар небольшой, и штрихкод больше него — можете упаковать его в дополнительную упаковку — например, стретч-плёнку. Тогда код нужно наклеить именно на неё. Главное, не наносите штрихкод на транспортировочную упаковку с логистической маркировкой. [Подробнее о требованиях к упаковке](/fbs/ozon-logistika/trebovaniya-k-upakovke)

Штрихкод на товаре должен:

быть только один, располагаться на видном месте и не перекрывать сроки годности и описание товара;

полностью закрывать старый и правильно считываться (например, не должен быть смят) — если вы наклеиваете новый штрихкод.

Во всех случаях штрихкод на товаре должен совпадать со штрихкодом в личном кабинете на момент поставки.
