# Кратность покупки

_Главная / Работа с товарами / Требования к карточкам товаров / Характеристики_

Как продавать автотовары партиями по несколько штук на FBS и realFBS

Если вы хотите продавать товары партиями по несколько штук, в карточке товара можно указать **Кратность покупки** — минимальное количество товаров для одного заказа. Например, если укажете 2 в этом поле, покупатели смогут заказать 2, 4 или 6 штук, а 1 или 3 — не смогут.

На товарах с кратностью покупатели будут видеть соответствующий значок, но в карточке стоимость указывается за один товар — пересчитаем её уже в корзине.

# У каких товаров можно устанавливать кратность

Кратность работает только на схемах FBS и realFBS, для товаров из категорий:

комплект болтов-секреток для колес;

автозапчасти подвески;

болты/гайки крепления колеса;

основные автозапчасти;

датчик для авто;

тормозные колодки дисковые;

колпаки на колеса;

глушитель, гофры трубы резонаторы;

автомобильные лампы;

защита внешних частей автомобиля;

подшипники;

предохранители;

автопроводка, провода;

свеча зажигания;

свеча накаливания;

тормозные диски и барабаны;

автомобильные фары.

# Как добавить кратность покупки

1. Если хотите указать кратность для уже существующего товара, откройте раздел **[Товары → Список товаров](https://seller.ozon.ru/app/products)** в личном кабинете, выберите карточку и нажмите **Редактировать товар** в меню. Если хотите указать кратность у нового товара — нажмите **Добавить товар**.
2. В разделе **Характеристики** в поле **Кратность покупки** укажите целое число — минимальное количество товаров для одного заказа.
3. Заполните остальные характеристики и нажмите **Сохранить товар**.

# Что будет с кратными товарами на FBO

Создать заявку на поставку с кратными товарами не получится. Но вы можете заполнить поле для товаров, которые уже есть на складах Ozon — тогда продадим остатки партиями нужного размера.

Когда на каком-то из наших складов остатки окажутся меньше указанной кратности, покупатели не смогут заказать такой товар: например, если при кратности 4 останется 3 тормозных диска. В таком случае вы можете:

забрать их со склада — чтобы не платить за размещение;

убрать в карточке кратность — тогда распродадим продукцию поштучно.

Если хотите продавать на FBO товары с кратностью, временно уберите из карточки эту информацию. Когда создадите заявку на поставку, верните кратность. Но обязательно упаковывайте продукцию по требованиям FBO — каждый товар должен быть в отдельной коробке. Однако мы не рекомендуем пользоваться этим способом, чтобы не возникло путаницы при продаже товаров. [Как собирать поставки](/fbo/process-details/prepare-supply)
