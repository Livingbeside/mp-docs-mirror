# Детализация по скидкам, за которые начисляем баллы

_Главная / Финансы, налоги и документооборот / Дополнительная информация_

Как посмотреть детализацию по скидкам за баллы и что влияет на размер скидок

# Что такое Баллы за скидки

Чтобы привлечь больше покупателей к вашему магазину или бренду, иногда мы устанавливаем дополнительную скидку на товары. Если их купят дешевле с одной из таких скидок — сделаем её за ваш счёт, а разницу между суммой продажи и вашей ценой вернём баллами. Эти баллы дадут вам скидку до 99% на услуги площадки.

Чтобы узнать, действует ли на ваш товар скидка, которую вернём баллами, откройте **[Товары и цены → Цены на товары](https://seller.ozon.ru/app/prices/control?filter=all)** — цена для покупателя будет ниже **Вашей цены**.

[Подробнее о баллах за скидки](/finances-documents/additional-information/bally-za-skidki)

# Как перейти к детализации по скидкам

На **[главной странице](https://seller.ozon.ru/app/dashboard/main)** личного кабинета — через специальный виджет с количеством начисленных баллов и другой информацией;

В разделе **[Товары и цены → Цены на товары](https://seller.ozon.ru/app/prices/control)** — через ссылку «Как влиять на размер скидок» в подсказке, которая появляется при наведении на цену со значком  в столбце** Цена для покупателя**;

В разделе **[Товары и цены → Список товаров](https://seller.ozon.ru/app/products)** — через ссылку «Как влиять на размер скидок» в подсказке, которая появляется при наведении на цену в карточке товара со скидкой.

## Какие метрики показываем в детализации

| **Метрика** | **Как считаем** | **Пример расчёта** |
| --- | --- | --- |
| **1. Добавили товарам скидки ** |  |  |
| **Средняя скидка** по всем товарам, которым добавили скидку | Сумму всех скидок по доступным* к продаже товарам делим на количество товаров из акции «Баллы за скидки». | К продаже доступны 3 разных товара из акции «Баллы за скидки»: 1 товар — скидка 15%;2 товар — скидка 5%;3 товар — скидка 10%. Тогда «Средняя скидка»: (15 + 5 +10) / 3 = 10% |
| **Максимальная скидка** самая большая скидка, которую добавили одному из товаров | Выбираем наибольшую скидку, сравнив скидки по всем доступным к продаже товарам из акции «Баллы за скидки». | К продаже доступны 3 разных товара из акции «Баллы за скидки»: 1 товар — скидка 15%;2 товар — скидка 5%;3 товар — скидка 10%. Получается, «Максимальная скидка»  — 15% |
| **2. Доля товаров со скидкой** |  |  |
| процент товаров с дополнительной скидкой, за которую начисляем баллы от общего числа ваших товаров | Количество доступных* к продаже товаров из акции «Баллы за скидки» делим на общее количество доступных к продаже товаров. | К продаже доступны 10 разных товаров, 9 из них участвуют в акции «Баллы за скидки». Тогда «Доля товаров со скидкой»: 9 / 10 = 90% |
| **3. Продажи со скидками ** |  |  |
| **Выручка от продаж** сумма общей выручки с продажи товаров с дополнительными скидками за период | Складываем выручку от продаж товаров из акции «Баллы без скидки» (без учёта скидки). | Вы установили на два разных товара цены в 1000 ₽. Один из товаров участвует в акции «Баллы за скидки» — скидка 15%. После покупки обоих товаров по 850 ₽ и 1000 ₽ ваша общая выручка по ценам, установленным вами — 2000 ₽. Но только 1 товар из двух был продан со скидкой,  поэтому в расчёт метрики «Выручка от продаж» попадёт 1000 ₽ |
| **Доля от всех продаж** процент выручки с продажи товаров с дополнительными скидками за период | Складываем выручку от продаж товаров из акции «Баллы без скидки» (без учёта скидки), а затем делим на общую выручку от продаж. | Вы установили на два разных товара цены в 1000 ₽. Один из товаров участвует в акции «Баллы за скидки» — скидка 15%. После покупки обоих товаров по 850 ₽ и 1000 ₽ общая выручка по ценам, установленным вами — 2000 ₽. Тогда «Доля от всех продаж»: 1000 / 2000 × 100% = 50% |
| **4. Начислили баллов** |  |  |
| общее количество начисленных баллов за период | Если количество баллов отрицательное, значит продаж со скидками за баллы в этом периоде меньше, чем возвратов. Так бывает, когда покупатели возвращают товары, купленные в прошлом периоде. Баллы за скидки могут быть начислены не только за дополнительную скидку, но и в рамках других акций. Для расчёта метрики учитываем общее количество баллов. | Вы установили цену на товар 1000 ₽. Мы добавили дополнительную скидку на товар и его новая стоимость составила 850 ₽. В случае покупки разница между вашей ценой и ценой реализации составит 150 ₽ — столько баллов начислим вам. Начисленные баллы отразим в столбце** Баллы за скидки** в [отчёте о реализации](https://seller-edu.ozon.ru/finances-documents/documents/otchet-o-realizacii-tovarov), а спишем при закрытии периода на услуги Ozon — до 99% на вознаграждение за продажу, а остальные баллы распределим пропорционально между логистикой, возвратами и другими услугами. [Подробнее о баллах за скидки](/finances-documents/additional-information/bally-za-skidki) |
| **5. Доля рекламных расходов** |  |  |
| процент расходов на продвижение от суммы полученных заказов за последние 30 дней | Считаем, сколько вы потратили на продвижение через инструменты **Оплата за клик **и **Оплата за заказ**, а затем делим на общую сумму полученных заказов за последние 30 дней | За последние 30 дней вы потратили на продвижение: на оплату за клик— 1000 ₽;на оплату за заказ — 1500 ₽. За этот же период вы получили заказов всего на общую сумму 50 000 ₽. Тогда «Доля рекламных расходов»: (1000 + 1500) / 50 000 × 100% = 5% |
| **6. Доля товаров с рассрочкой** |  |  |
| мы самостоятельно принимаем решение о предоставлении беспроцентной рассрочки на некоторые товары для покупателя и без комиссии за рассрочку для продавца | Количество доступных* к продаже товаров из акции «Беспроцентная рассрочка» делим на количество доступных к продаже товаров. | К продаже доступны 10 товаров — 3 из них участвуют в акции «Беспроцентная рассрочка». Тогда «Доля товаров с рассрочкой»: 3 / 10 × 100% = 30% |

**Считаем доступными товары:*

*в наличии — без учёта зарезервированных к заказу;*

*с активной карточкой — доступны к показу на сайте.*

# Что влияет на размер скидок, за которые начисляем баллы

На размер скидки влияют рыночные факторы: общее количество доступных предложений, ценовая политика продавцов, динамика спроса в категории товаров. Вместе с этими факторами на скидку влияет ваше продвижение через инструменты **[Оплата за клик](https://seller-edu.ozon.ru/how-to-sell-effectively/advertising-of-goods/oplata-za-klik)** и **[Оплата за заказ](https://seller-edu.ozon.ru/how-to-sell-effectively/advertising-of-goods/oplata-za-zakaz)**** **и наличие подписки Premium Plus.
