# Отчёт по предоплатам за товары

_Главная / Финансы, налоги и документооборот / Документы_

Зачем нужен отчёт по предоплатам за товары и как рассчитывать НДС с предоплат от покупателей

# Что такое отчёт по предоплатам за товары

Начисляем выплаты только за реализованные товары — не учтём суммы из отчёта по предоплатам при расчёте ближайшей выплаты.

Это справочный документ: отражаем в нём информацию о предоплатах от покупателей — она поможет в том числе корректно рассчитывать НДС, который начисляется с предоплат согласно Налоговому кодексу РФ.

Показываем:

какая сумма предварительной оплаты получена;

какие предоплаченные товары покупатель забрал;

какая сумма предварительной оплаты была возвращена покупателю, если он не забрал товар.

**Отчёт по предоплатам** поможет рассчитать НДС с предоплат, а НДС с продажи товаров лучше рассчитывать, опираясь на **Отчёт о реализации** — там учитываем возвраты, которых нет в отчёте по предоплатам.

# Где найти отчёт по предоплатам за товары

Новый отчет доступен в разделе **[Финансы → Документы → Аналитические отчеты](https://seller.ozon.ru/app/finances/documents?type=analyticalReports)**.

Формируем отчёт по предоплатам в течение первых пяти рабочих дней месяца, но не позднее 8 числа.

# Из чего состоит отчёт по предоплатам за товары

| Название столбца | Что означает |
| --- | --- |
| **Месяц отправления** | Когда заказ был отправлен покупателю |
| **Название товара** | Полное название товара в карточке |
| **Артикул** | ID товара в вашей базе |
| **Месяц получения предварительной оплаты за заказ** | Когда была получена предоплата за конкретный товар |
| **Сумма предварительной оплаты (с учетом НДС)** | Какая сумма предоплаты была получена за конкретный товар |
| **Месяц реализации** | Когда покупатель получил товар |
| **Сумма реализации** | Товар на какую сумму покупатель забрал |
| **Месяц возвращения предварительной оплаты** | Когда вернули предоплату покупателю |
| **Сумма возвращенной предварительной оплаты** | Товар на какую сумму покупатель вернул |

# Как пользоваться отчётом по предоплатам за товары

Если применяете общую систему налогообложения, то с помощью отчёта сможете рассчитать:

Какую сумму НДС нужно начислить с предоплат. Рассчитывайте налог от суммы в столбце **Сумма предварительной оплаты (с учётом НДС)** по соответствующей ставке — 10/110 или 22/122, зависит от категории товара.

Какую сумму НДС по предоплатам можно принять к вычету:
в периоде, когда произошла реализация — если покупатель забрал товары (столбец **Сумма реализации**);

в течение года — если предоплату вернули покупателю (столбец **Сумма возвращённой предварительной оплаты**).

**Пример 1: как рассчитать НДС с предоплаты к начислению**

В столбце **Сумма предварительной оплаты (с учетом НДС)** указана сумма 1200 рублей. Сумма НДС к начислению будет равна 216,39 рублей, если товар облагается по ставке НДС 22% — считаем по формуле 1200 ÷ 122 × 22.

**Пример 2: как рассчитать НДС с предоплаты к вычету**

В столбце **Сумма реализации** указана сумма 900 рублей, а в столбце **Сумма возвращённой предварительной оплаты** — 300 рублей. Сумма НДС к вычету будет равна 216,39 рублей, если НДС был исчислен по ставке 22/122 — считаем по формуле (900 + 300) ÷ 122 × 22.
