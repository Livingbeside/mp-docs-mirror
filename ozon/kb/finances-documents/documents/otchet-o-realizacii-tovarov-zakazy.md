# Позаказный отчёт о реализации

_Главная / Финансы, налоги и документооборот / Документы_

Как посмотреть информацию по каждому проданному товару за месяц

Позаказный отчёт о реализации — вспомогательный отчёт, из которого можно узнать подробности о проданных товарах и номера отправлений. Не относится к закрывающим документам.

Формируем отчёт по итогам месяца и загружаем в личный кабинет в течение первых 5 рабочих дней следующего месяца, но не позднее 8 числа. Отчёт можно найти в разделе **[Финансы → Документы → Отчёты о реализации](https://seller.ozon.ru/app/finances/documents)** на вкладке **Справочные**. Там же, но на вкладке **Закрывающие **находится [отчёт о реализации товаров](https://seller-edu.ozon.ru/finances-documents/documents/otchet-o-realizacii-tovarov).

Особенности отчёта:

учитываем только доставленные и возвращённые товары — отмены и невыкупы в расчёте не участвуют;

дополнительно отражаем номера и даты всех отправлений, а при продаже юрлицам — номера и даты счетов-фактур.

Услуги Ozon отражаем в **[Акте выполненных работ](https://seller-edu.ozon.ru/finances-documents/documents/act-vypolnenyh-rabot)**.

# Из каких блоков состоит отчёт

**Название товара** — наименование реализованного товара. Если товар уценённый, в скобках будет пометка об этом.

**Артикул** — ID товара в вашей базе.

**SKU** — ID товара в базе Ozon. SKU уценённых позиций отличается от SKU таких же новых товаров.

**Штрих-код товара** — штрихкод реализованного товара.

## Блок Реализовано

Содержит информацию о товарах, доставленных покупателям за отчётный период.

**Реализовано на сумму** — стоимость проданного товара с учётом количества, программ лояльности, [баллов за скидки](https://seller-edu.ozon.ru/finances-documents/additional-information/bally-za-skidki) и [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price). Рассчитывается по цене реализации.

**Выплаты по механикам лояльности партнёров** — сумма выплат от партнёра за товары, приобретённые по программам лояльности. Посмотреть детали по выплатам можно [отчёте по механикам лояльности партнёров](https://seller-edu.ozon.ru/finances-documents/documents/otchet-o-realizacii-tovarov#%D0%BE%D1%82%D1%87%D1%91%D1%82-%D0%BF%D0%BE-%D0%BC%D0%B5%D1%85%D0%B0%D0%BD%D0%B8%D0%BA%D0%B0%D0%BC-%D0%BB%D0%BE%D1%8F%D0%BB%D1%8C%D0%BD%D0%BE%D1%81%D1%82%D0%B8-%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%BE%D0%B2).

**Количество** — количество товара, проданного по цене реализации.

**Цена реализации** — цена, по которой покупатель приобрёл товар.

## Блок Возвращено клиентом

Содержит информацию о товарах, которые вернули покупатели. Например, если товар не подошёл по размеру или цвету.

**Возвращено на сумму** — стоимость возвращённого товара с учётом количества, программ лояльности, [баллов за скидки](https://seller-edu.ozon.ru/finances-documents/additional-information/bally-za-skidki) и [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price). Расчёт осуществляется по цене реализации.

**Выплаты по механикам лояльности партнёров** — сумма выплат от партнёра, которую мы спишем в случае возврата товаров, приобретённых по программам лояльности. Посмотреть детали по выплатам можно [отчёте по механикам лояльности партнёров](https://seller-edu.ozon.ru/finances-documents/documents/otchet-o-realizacii-tovarov#%D0%BE%D1%82%D1%87%D1%91%D1%82-%D0%BF%D0%BE-%D0%BC%D0%B5%D1%85%D0%B0%D0%BD%D0%B8%D0%BA%D0%B0%D0%BC-%D0%BB%D0%BE%D1%8F%D0%BB%D1%8C%D0%BD%D0%BE%D1%81%D1%82%D0%B8-%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%BE%D0%B2).

**Количество** — количество возвращённого товара.

**Цена реализации** — цена, по которой покупатель приобрёл товар.

## Блок Отправление

**Номер** — номер отправления, в котором был товар.

**Дата** — дата оформления заказа покупателем.

## Блок Продажа юридическому лицу

**Номер счёт-фактуры** — номер счёта-фактуры, в котором был товар.

**Дата** — дата выставления счёта-фактуры, в котором был товар.

**Название товара** — наименование реализованного товара. Если товар уценённый, в скобках будет пометка об этом.

**Артикул** — ID товара в вашей базе.

**SKU** — ID товара в базе Ozon. SKU уценённых позиций отличается от SKU таких же новых товаров.

**Штрих-код товара** — штрихкод реализованного товара.

## Блок Реализовано

Содержит информацию о товарах, доставленных покупателям за отчётный период.

**Реализовано на сумму** — стоимость проданного товара с учётом количества, программ лояльности, [баллов за скидки](https://seller-edu.ozon.ru/finances-documents/additional-information/bally-za-skidki) и [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price). Рассчитывается по цене реализации.

**Выплаты по механикам лояльности партнёров** — сумма выплат от партнёра за товары, приобретённые по программам лояльности. Посмотреть детали по выплатам можно [отчёте по механикам лояльности партнёров](https://seller-edu.ozon.ru/finances-documents/documents/otchet-o-realizacii-tovarov#%D0%BE%D1%82%D1%87%D1%91%D1%82-%D0%BF%D0%BE-%D0%BC%D0%B5%D1%85%D0%B0%D0%BD%D0%B8%D0%BA%D0%B0%D0%BC-%D0%BB%D0%BE%D1%8F%D0%BB%D1%8C%D0%BD%D0%BE%D1%81%D1%82%D0%B8-%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%BE%D0%B2).

**Баллы за скидки **— баллы, которые мы начисляем вам за предоставленные покупателям скидки в отчётном периоде. Эти баллы будут использованы для оплаты услуг площадки, оказанных в этом же периоде. [Подробнее о баллах за скидки](https://seller-edu.ozon.ru/finances-documents/additional-information/bally-za-skidki)

**Количество** — количество товара, проданного по цене реализации.

**Цена реализации** — цена, по которой покупатель приобрёл товар.

**Вознаграждение за продажу по категории (справочно)** — ставка комиссии для товара данной категории.

**Цена до скидок по поручению продавца (справочно)** — цена товара, установленная продавцом в личном кабинете, с учётом [акций продавца](https://seller-edu.ozon.ru/how-to-sell-effectively/promo/my-promo).

**Базовая комиссия** — сумма комиссии в рублях с учётом количества товара, акций продавца и наценок.

**Итого к начислению** — сумма, которую выплатим после вычета вознаграждения за продажу.

Ставка комиссии фиксируется в момент создания заказа. Например, если у категории товара на момент заказа ставка комиссии была 5%, а на момент доставки товара стала 10%, то комиссия на товар составит 5%.

[Подробнее о комиссии в разделе Комиссии и тарифы Ozon](https://seller-edu.ozon.ru/commissions-tariffs)

## Блок Возвращено клиентом

Содержит информацию о товарах, которые вернули покупатели. Например, если товар не подошёл по размеру или цвету.

**Возвращено на сумму** — стоимость возвращённого товара с учётом количества, программ лояльности, [баллов за скидки](https://seller-edu.ozon.ru/finances-documents/additional-information/bally-za-skidki) и [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price). Расчёт осуществляется по цене реализации.

**Выплаты по механикам лояльности партнёров** — сумма выплат от партнёра, которую мы спишем в случае возврата товаров, приобретённых по программам лояльности. Посмотреть детали по выплатам можно [отчёте по механикам лояльности партнёров](https://seller-edu.ozon.ru/finances-documents/documents/otchet-o-realizacii-tovarov#%D0%BE%D1%82%D1%87%D1%91%D1%82-%D0%BF%D0%BE-%D0%BC%D0%B5%D1%85%D0%B0%D0%BD%D0%B8%D0%BA%D0%B0%D0%BC-%D0%BB%D0%BE%D1%8F%D0%BB%D1%8C%D0%BD%D0%BE%D1%81%D1%82%D0%B8-%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%BE%D0%B2).

**Баллы за скидки **— количество баллов, которое мы спишем в случае возврата. Спишем баллы только за возврат тех товаров, за продажу которых начисляли вам баллы. [Подробнее о баллах за скидки](https://seller-edu.ozon.ru/finances-documents/additional-information/bally-za-skidki)

**Количество** — количество возвращённого товара.

**Цена реализации** — цена, по которой покупатель приобрёл товар.

**Базовая комиссия** — сумма комиссии в рублях с учётом количества товара, акций продавца и наценок, которую мы вам вернём в случае возврата товара.

**Итого возвращено** — сумма, которую вернём вам за возвращённый товар после вычета вознаграждения за продажу.

## Блок Отправление

**Номер** — номер отправления, в котором был товар.

**Дата** — дата оформления заказа покупателем.

## Блок Продажа юридическому лицу

**Номер счёт-фактуры** — номер счёта-фактуры, в котором был товар.

**Дата** — дата выставления счёта-фактуры, в котором был товар.

## Поле Всего к начислению

Отображает вашу выплату с вычетом вознаграждения за продажу, скидок и наценок, но без учёта услуг Ozon. Вычисляем по формуле:

**Всего к начислению** = Итого к начислению, руб. (столбец Реализовано) − Итого возвращено, руб (столбец Возвращено клиентом).
