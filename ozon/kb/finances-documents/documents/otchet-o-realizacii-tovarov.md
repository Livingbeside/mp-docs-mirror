# Отчёт о реализации товаров

_Главная / Финансы, налоги и документооборот / Документы_

Из чего состоит отчёт о реализации и как рассчитываем выплаты при продаже товара со скидкой и наценкой

Отчёт о реализации — закрывающий документ, в котором учитываем информацию за прошедший месяц о товарах:

заказанных и полученных покупателями;

возвращённых клиентами после вручения — отмены и невыкупы в расчёте не участвуют.

Подписанный отчёт формируем по итогам месяца в течение 5 рабочих дней следующего месяца и до 8 числа загружаем на страницу **[Финансы → Документы → Отчёты о реализации](https://seller.ozon.ru/app/finances/documents)****. **

На вкладке **Закрывающие **собираем отчёт о реализации товаров и другие закрывающие документы: отчёт о реализации услуг и корректировка отчёта о реализации.

На вкладке **Справочные** находятся остальные документы: [позаказный отчёт о реализации](https://seller-edu.ozon.ru/finances-documents/calculations-documents/otchet-o-realizacii-tovarov-zakazy), отчёт о реализации прослеживаемых товаров, отчёт о реализации товара (расшифровка) и поэкземплярный отчёт о реализации.

# Из каких блоков состоит отчёт о реализации

## Блок Реализовано

Показываем информацию о товарах, доставленных покупателям за прошлый месяц:

**Реализовано на сумму** — стоимость всего проданного товара с учётом [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price). Для расчёта используется цена реализации.

**Выплаты по механикам лояльности партнёров** — сумма выплат от партнёра за товары, приобретённые по [программам лояльности](https://seller-edu.ozon.ru/how-to-sell-effectively/loyalty).

**Количество** — сколько единиц товара продано по цене реализации.

**Цена реализации** — цена, по которой покупатель приобрёл товар, с учётом [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price).

## Блок Возвращено клиентом

Показываем информацию о позициях, возвращённых покупателями за прошлый месяц. Например, если товар не подошёл по размеру или цвету.

**Возвращено на сумму** — стоимость всего возвращённого товара с учётом [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price). Для расчёта используется цена реализации.

**Выплаты по механикам лояльности партнёров** — сумма выплат от партнёра, которую мы спишем в случае возврата товаров, приобретённых по программам лояльности.

**Количество** — сколько единиц товара вернули покупатели.

**Цена реализации** — цена, по которой покупатель приобрёл товар, с учётом [региональных коэффициентов](https://seller-edu.ozon.ru/work-with-goods/rabota-s-tsenami/regional-price).

Если покупатель отменил заказ или отказался его выкупать, начислений и списаний по отправлениям не будет. Поэтому отмены и невыкупы в отчёте о реализации не учитываются.

## Итоговые расчёты

Под таблицей отобразим итоговые суммы:

**Итого реализовано (за вычетом возвратов)** = Реализовано на сумму, руб − Возвращено на сумму, руб.

**Всего выплат от партнёров** = Выплаты по механикам лояльности партнёров (блок Реализовано) − Выплаты по механикам лояльности партнёров (блок Возвращено клиентом).

# Почему товар может быть продан по другой цене

## Продажа с наценкой

Иногда товар может быть реализован дороже — например, из-за [регионального коэффициента](/prices/regional-price) или покупки позиции в [рассрочку](/how-to-sell-effectively/loyalty/besprotsentnaya-rassrochka). В любом из этих случаев для вас итоговая сумма начислений не меняется.

## Продажа со скидкой за баллы

Иногда Ozon устанавливает дополнительную скидку на ваши товары, чтобы привлекать больше покупателей к вашему магазину или бренду. Если товар продастся дешевле с одной из таких скидок, скидка будет от вашего имени, а разницу начислим баллами. Эти баллы дадут вам скидку до 99% на услуги площадки. [Подробнее о баллах за скидки](https://seller-edu.ozon.ru/finances-documents/additional-information/bally-za-skidki)

## Продажа со скидкой по программам лояльности партнёров

Благодаря действующим программам лояльности партнёров, покупатели могут приобрести некоторые товары дешевле или всего за 1% от стоимости — например при оплате заказа [звёздами](/how-to-sell-effectively/loyalty/star-goods). В этом случае итоговая сумма начислений для вас не меняется, так как разницу покрывает партнёр.

# Отчёт по механикам лояльности партнёров

Отчёт детализирует информацию столбца **Выплаты по механикам лояльности партнёров **в блоках «Реализовано» и «Возвращено клиентом». Пока документ содержит данные по двум программам лояльности: «[Звёздные товары](/how-to-sell-effectively/loyalty/star-goods)», «[Зелёная цена](/how-to-sell-effectively/loyalty/zelenaya-cena)» и «[Скидки от ПВЗ](/how-to-sell-effectively/loyalty/skidki-pvz)».

Отчёт доступен в разделе** ****[Финансы → Документы → Аналитические отчеты](https://seller.ozon.ru/app/finances/documents?type=analyticalReports)**. Формируем документ в течение первых пяти рабочих дней месяца, но не позднее 8 числа.

Отчёт состоит из:

| **Название столбца** | **Что означает** |
| --- | --- |
| **Партнёрская программа лояльности** | Название программы |
| **Наименование партнёра** | Название партнёра, который выплачивает продавцу деньги за товары по программе лояльности |
| **ИНН партнёра** | ИНН партнёра |
| **К начислению, руб.** | Сумма по столбцу **Выплаты по механикам лояльности партнёров, руб.** в блоке «Реализовано» |
| **К возврату, руб.** | Сумма по столбцу **Выплаты по механикам лояльности партнёров, руб.** в блоке «Возвращено клиентом» |
| **Итого, руб.** | Разница между суммами **К начислению, руб. **и** К возврату, руб.** |

# Как получать отчёт о реализации товаров за день через API

Доступно только по подпискам [Premium Plus](https://seller-edu.ozon.ru/seller-rating/about-rating/subscription-premium-plus?search=premium) и [Premium Pro](/libra/seller-rating/podpiska-premium-pro).

С помощью метода Seller API [/v1/finance/realization/by-day](https://docs.ozon.ru/api/seller/#operation/FinanceAPI_GetRealizationByDayReportV1) можете получать данные о продажах за день из отчёта о реализации товаров. Данные доступны не более чем за 32 календарных дня от текущей даты и не включают информацию об отменах и невыкупах.

[Подробнее о Seller API](https://seller-edu.ozon.ru/api-ozon/how-to-api?search=api)
