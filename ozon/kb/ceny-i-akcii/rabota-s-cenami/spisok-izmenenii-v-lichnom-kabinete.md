# Список изменений в личном кабинете

_Главная / Цены и акции / Работа с ценами_

Список всех изменений терминов цен и метрик с 7 сентября 2026 года

С 7 сентября 2026 года меняется терминология цен по всему кабинету и логика расчёта ряда метрик. Стало проще понять, какую цену видят покупатели и как считаются расходы. Изменения затронут все основные разделы — от главной страницы до мобильного приложения.

# Общие изменения по всему кабинету

Теперь каждый термин точно будет отражать своё значение — так проще ориентироваться в ценах и расходах. Два ключевых понятия, на которых строится вся логика:

**Предельная цена** — выше этого значения цена на сайте не поднимется. Эта цена учитывает акции, если товар в них участвует. То, что вы устанавливаете вручную до акций — предельная цена без акций.

**Цена на сайте** — цена, которую видит покупатель в карточке с учётом всех акций и дополнительных скидок, за которые начисляем баллы. Если цена по картам банков-партнёров ниже, показываем её.

Основные термины изменим так:

Ваша цена → Предельная цена без акций

Ваша цена с учётом акций → Предельная цена

Цена для покупателя → Цена на сайте

Минимальная цена → Ограничение для акций и стратегий

Цена до скидки → Зачёркнутая цена

Скидка от вашей цены → Скидка

Добавим новые термины:

**Цена реализации** — цена, по которой покупатель купил товар с учётом региональных коэффициентов и без учёта стоимости обработки заказа в ПВЗ

**Предельная цена по этой акции** — предельная цена для участия в конкретной акции

**Предельная цена с промокодом** — предельная цена после применения промокода

# Главная

Перейдём на расчёт графика «Заказано товаров» по цене реализации — раньше использовалась цена с учётом акций за счёт продавца.

# Товары

Переименуем поля в форме создания товара и Excel-шаблоне: «Ваша цена» → «Предельная цена без акций», «Цена до скидки» → «Зачёркнутая цена».

В списке товаров, обзоре карточки, объединениях товаров и шаблоне товаров вместо «Вашей цены» будем показывать «Цену на сайте» — ту, которую видят покупатели в карточке товара.

# Цены

Обновим все термины цен на новые. [Подробнее](#общие-изменения-по-всему-кабинету)

Маржинальность и процент расходов будем считать от предельной цены.

# Акции

Переименуем столбцы в интерфейсе и Excel-шаблоне — для собственных и глобальных акций.

В разделе глобальных акций вместо «Текущая цена с учётом акций» будем отображать столбец «Цена на сайте» с ценами, что видят покупатели на сайте и в приложении.

# Разделы FBO и FBS

В заказах заменим «Стоимость» → «Предельная цена».

В возвратах переименуем «Цена» → «Предельная цена», в настройках возврата будем отображать «Цену на сайте».

В разделе **Управление логистикой** вместо «Текущей цены» начнём показывать «Цену на сайте» — ту, что видят покупатели на сайте и в приложении.

# Покупатели

Для метрики «Куплено на сумму» перейдём на расчёт по предельной цене.

# Продвижение

В разделах **Оплата за клик** и **Оплата за заказ** заменим «Ваша цена» → «Предельная цена без акций».

В разделе **Внешнее продвижение **обновим:
«Цена» → «Предельная цена»

при создании задания «Стоимость образцов товара» → «Предельная цена товара»

в таблице с заданиями добавим «Предельная цена образцов товара»

В разделе **Внешний трафик **в отчётах заменим значения:
«Стоимость» → «Предельная цена»

«Цена» → «Предельная цена без акций»

# Кабинет бренда

В списке товаров уберём столбец «Цена продавца», заменили «Цена для покупателя» → «Цена на сайте».

В блоке «Товары в продаже» заменим «Цена» → «Цена на сайте».

# Интеграции с ВК
