# Подборки товаров бренда

_Главная / Кабинет бренда_

Как создать страницу с товарами продавцов вашего бренда, чтобы делиться ей в рекламных кампаниях или добавлять на официальную витрину бренда

Бесплатный инструмент, с помощью которого вы можете самостоятельно формировать страницы с товарами продавцов вашего бренда для рекламных кампаний, внешних коммуникаций и акций. Подборка товаров бренда будет доступна на сайте по прямой ссылке — её можно добавить на [витрину бренда](/account-brand/oficialnaya-vitrina-brenda), в [баннер](/how-to-sell-effectively/media-advertising) на Ozon, указать в рассылке, разместить в своих соцсетях или у популярного блогера.

# Как создать подборку товаров бренда

Как создавать подборку в кабинете продавца, описываем в [статье](/how-to-sell-effectively/advertising-of-goods/podborki-tovarov).

1. В кабинете бренда откройте **[Список товаров → Подборки товаров](https://seller.ozon.ru/app/seller-highlights/list)** и нажмите **Создать подборку**.
2. Придумайте название подборки, которое поможет вам быстро ориентироваться в списке. Например, «Подборка для соцсетей».
3. Укажите дату начала и окончания — период, в течение которого страница с подборкой товаров будет размещена на Ozon.
4. Выберите бренд, для которого хотите создать подборку. У бренда должен быть хотя бы один выбранный продавец на витрине. Если выберете несколько брендов — добавить на витрину её не получится.
5. Уточните список товаров для подборки с помощью фильтров.
6. Нажмите **Создать подборку**.

В блоке **Основные настройки** появится ссылка на страницу с выбранными товарами. Её можно скопировать и разместить в нужном канале коммуникации с покупателями.

## Как настроить порядок товаров в подборке

Управлять порядком товаров в подборке могут только продавцы с [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-pro).

1. Откройте нужную подборку.
2. В блоке **Список товаров** нажмите **Настроить**.
3. В новом окне нажмите **Добавить товары** и выберите не больше 100 позиций из подборки, для которых хотите настроить порядок.
4. Распределите товары по порядку: зажмите  и перетащите товар на нужное место или укажите позицию в столбце **№**.
5. Когда настроите порядок у товаров, нажмите **К подборке.**

Покупатели могут видеть товары в подборке в разном порядке. Например, если в каком-то регионе товар недоступен для продажи — он не отобразится в подборке.

# Какие статусы бывают у подборки товаров бренда

**На витрине** — ваша подборка отображается на витрине бренда.

**Нет продавцов** — отображается пустая подборка. Добавьте продавцов бренда на витрину.

# Как отредактировать подборку товаров бренда

1. Откройте раздел **[Список товаров → Подборки товаров](https://seller.ozon.ru/app/seller-highlights/list)**.
2. На вкладке **Активные** нажмите на нужную подборку.
3. Вы можете:
  поменять название;
  
  изменить период;
  
  изменить настройки фильтров — у автоматической подборки;
  
  добавить или удалить товары — у ручной подборки.
  Когда внесёте изменения, нажмите **Сохранить**.

Подборка обновится, ссылка на страницу с ней останется прежней. Понадобится около 24 часов, чтобы все изменения, которые вы внесли, подгрузились на страницу подборки.

# Как удалить подборку товаров бренда

1. Откройте раздел **[Список товаров → Подборки товаров](https://seller.ozon.ru/app/seller-highlights/list)**.
2. На вкладке **Активные** нажмите на нужную подборку.
3. Нажмите удалить и подтвердите действие.
