# Создание заказа в личном кабинете продавца

_Главная / Ozon Доставка / Ozon Доставка для продавцов_

Как создать заказ в Ozon Доставке для продавцов, какие есть ограничения и требования

# Видео «Ozon Доставка»

# Что такое создание заказа в личном кабинете продавца

Это способ передать заказ с вашей площадки в Ozon Доставку без настройки API и интеграций. В личном кабинете продавца на Ozon укажите данные покупателя, товары и способ доставки. Доставку мы возьмём на себя.

# Как создать заказ

1. Откройте **[FBO → Заказы со склада Ozon](https://seller.ozon.ru/app/postings/fbo)** или **[FBS → Заказы с моих складов](https://seller.ozon.ru/app/postings/fbs)** и нажмите **Создать заказ**.
2. Укажите номер телефона покупателя — к нему должен быть привязан личный кабинет покупателя на Ozon.
3. Выберите способ доставки — в пункт выдачи Ozon или курьером до двери.
4. Укажите город доставки и пункт выдачи или адрес покупателя, если выбрали доставку курьером.
5. Выберите товары для отправки — добавьте вручную или загрузите через XLS-шаблон.
6. Для каждого товара укажите количество и цену, по которой вы продали товар покупателю на своей площадке. Клиент увидит эту стоимость в личном кабинете при получении заказа. Из схем продаж (FBO или FBS) автоматически выберем ту, которая позволит быстрее доставить товар покупателю. При необходимости можете её изменить.
7. После заполнения информации нажмите **Рассчитать доставку**.
8. Проверьте информацию о заказе, ознакомьтесь с предварительными сроком и стоимостью доставки — после создания заказа изменить данные не получится.
9. Нажмите **Создать заказ**.

FBO-заказы будут доступны в разделе **[FBO → Заказы со склада Ozon](https://seller.ozon.ru/app/postings/fbo)**, FBS-заказы — в разделе **[FBS → Заказы с моих складов](https://seller.ozon.ru/app/postings/fbs)****.** Под номером отправления будет бейдж «Создан вручную».

Также создать заказ и посмотреть предварительную стоимость доставки можно с помощью метода Seller API [/v2/delivery/checkout](https://docs.ozon.ru/api/seller/?__rr=3#operation/OrderAPI_OrderCreate). [Подробнее о Seller API](https://docs.ozon.ru/api/seller/#tag/OzonLogistics)

# Какие есть ограничения

## Требования к покупателю

У покупателя должен быть аккаунт Ozon, привязанный к номеру телефона из данных заказа — без этого оформить заказ не получится.

## Изменение и отмена заказа

После создания нельзя изменить телефон покупателя, товары, количество, стоимость и способ доставки. Внимательно проверьте данные перед отправкой.

Если указали неверные данные, создайте новый заказ с правильной информацией. Для заказа с ошибкой будет действовать процесс отмены или возврата — в зависимости от схемы работы и статуса заказа.

### Отмена заказа

Отменить заказ можно самостоятельно в личном кабинете продавца. Для этого в списке заказов нажмите **⋮ → Отменить отправление**:

**на FBS** — в разделе **[Заказы с моих складов](https://seller.ozon.ru/app/postings/fbs)** по отправлениям в статусах **Ожидает сборки**, **Ожидает отгрузки** и **Готов к отгрузке**. Если отменить заказ самостоятельно не получается, обратитесь в поддержку Ozon;

**на FBO** — в разделе **[Заказы со склада Ozon](https://seller.ozon.ru/app/postings/fbo)** по отправлениям во всех статусах кроме **Передаем курьеру** и** Курьер в пути**.

После отмены восстановить заказ не получится. Отмены не повлияют на ваш рейтинг.

Также покупатель может отказаться от заказа при получении или не забирать его из пункта выдачи — после окончания срока хранения вернём заказ обратно.

## Как работать с маркировкой «Честный знак»

Если создаёте заказ с товарами, подлежащими маркировке, заранее проверьте правила работы с кодами маркировки для вашей схемы: [инструкция для FBO](https://seller-edu.ozon.ru/ozon-logistika/fbo#как-продавать-товары-с-маркировкои-«честныи-знак»-и-сертификациеи-«меркурии») и [инструкция для FBS](https://seller-edu.ozon.ru/ozon-logistika/fbs#как-продавать-товары-с-маркировкои-«честныи-знак»-и-сертификациеи-«меркурии»).
