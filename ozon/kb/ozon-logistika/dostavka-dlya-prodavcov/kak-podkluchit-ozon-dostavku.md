# Как подключить Ozon Доставку для продавцов

_Главная / Ozon Доставка / Ozon Доставка для продавцов_

Как начать работу с Ozon Доставкой для продавцов, какие способы интеграции бывают

# Вебинар «Сервисы Ozon для вашего онлайн-магазина»

# Создание заказа в личном кабинете продавца

Можете создать заказ самостоятельно в личном кабинете продавца. Для этого нужно указать данные покупателя, выбрать товары и способ доставки. [Подробнее о создании заказа в личном кабинете](https://seller-edu.ozon.ru/libra/ozon-logistika/sozdanie-zakaza-v-lichnom-kabinete-prodavca)

# Прямая интеграция в личном кабинете Ozon

## Этап 1. Подключите приложение в личном кабинете

1. Перейдите в раздел **[Товары → Все приложения](https://seller.ozon.ru/app/appstore/ozon-dostavka)**.
2. Выберите на витрине **Ozon Доставка** и нажмите **Подключить**.
3. Заполните информацию о магазине — её увидят покупатели в личном кабинете Ozon у оформленных на вашей площадке заказов:
  укажите название магазина и ссылку на него;
  
  загрузите логотип.
  [Посмотреть правила оформления](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-prodavcov/kak-podkluchit-ozon-dostavku#%D0%BF%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0-%D0%BE%D1%84%D0%BE%D1%80%D0%BC%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F)
4. Нажмите **Добавить**.

После этого ваша заявка отправится на проверку. Обычно она занимает не более 2 рабочих дней. Далее могут быть следующие варианты:

если всё в порядке — статус приложения изменится на «Подключено»;

если при заполнении информации о магазине вы допустили ошибку — подскажем, что нужно поправить, и попросим отправить заявку на повторную проверку.

### Правила оформления

## Этап 2. Подготовьтесь к интеграции

Далее в личном кабинете Ozon нужно создать частное приложение и настроить прямую API интеграцию. Частное приложение нужно, чтобы связать ваши системы и Ozon. Другие продавцы не увидят его на витрине приложений.

1. Откройте раздел **[Настройки → Приложения и разрешения](https://seller.ozon.ru/app/settings/private-apps)** и на вкладке «Приложения**»** нажмите **Создать**.
2. Укажите название приложения — например, «Ozon Доставка». Затем выберите уровни доступа к Seller API:
  seller-api.ozon-logistics;
  
  seller-api.posting-fbo;
  
  seller-api.posting-fbs;
  
  seller-api.returnsseller-api.report;
  
  seller-api.product;
  
  другие уровни, если они вам нужны. Если не уверены, какие именно, оставьте выбор своему разработчику — позже при настройке интеграции он сможет добавить дополнительные уровни, если они понадобятся.
3. Нажмите **Создать**. Приложение получит статус «Активно».

## Этап 3. Выдайте доступ к частному приложению своему разработчику

1. Откройте раздел **[Настройки → Приложения и разрешения](https://seller.ozon.ru/app/settings/private-apps)** и на вкладке «Разрешения**»** нажмите **Выдать**.
2. Введите фамилию, имя и адрес электронной почты разработчика.
3. В списке приложений выберите созданное на предыдущем шаге.
4. Согласитесь с политикой предоставления персональных данных и нажмите **Выдать**.

После этого на указанный адрес электронной почты придёт ссылка с доступом к настройкам приложения.

## Этап 4. Настройте интеграции Seller API

Перейдя по ссылке из письма, разработчик войдёт в приложение через личный кабинет на платформе [dev.ozon.ru](http://dev.ozon.ru/) и настроит API интеграцию. После этого сможете доставлять заказы из вашего интернет-магазина нашей логистикой.

[Подробнее о работе с частными приложениями в документации](https://docs.ozon.ru/api/applications/#section/Rabota-s-chastnym-prilozheniem)

[Подробнее о настройке интеграции с Ozon Доставкой для разработчиков](https://dev.ozon.ru/start/446-Ozon-Logistika-podkliuchenie-nastroika-i-poriadok-raboty-s-novym-funktsionalom/)

# Интеграция через наших партнёров

Подключение Ozon Доставки возможно:

через **Ozon Pay** — возьмём на себя не только эквайринг, но и доставку. [Подробнее](https://help-bank.ozon.ru/business/acquiring-online/delivery/enable)

через **ApiShip** — для подключения следуйте [инструкции](https://docs.apiship.ru/docs/delivery-services/list-delivery-services/ozonlog/);

если ваш интернет-магазин создан на платформе:
**Яндекс KITᵝ** — для подключения следуйте [инструкции](https://yandex.ru/support/kit/ru/integration/ozon);

**UDS** — для подключения следуйте [инструкции](https://cdn1.ozonusercontent.com/s3/seller-app-store-public/fc74ebf6-f26b-431b-a01a-29d509aaa183.pdf).

# Подключение к площадкам наших партнёров

Теперь нашу доставку можно подключить ещё и к заказам из Шопинга — площадки для продажи товаров внутри приложения Т-Банка. Как это сделать, можно посмотреть в [инструкции](https://shopping-seller-docs.t-static.ru/index.html#/).
