# Настройка метода доставки

_Главная / Ozon Доставка / Ozon Доставка для бизнеса_

Как добавить, изменить и удалить метод Ozon Доставки

В методе доставки хранятся данные о том, откуда вы отправляете заказы и где забираете возвраты. Заполните их один раз, а при оформлении заказов достаточно просто выбрать нужный из списка.

# Добавить метод доставки

Пока привозить заказы и забирать возвраты можно только одним способом — самостоятельно в выбранный пункт выдачи или СЦ.

1. Откройте вкладку **[Методы доставки](https://seller.ozon.ru/app/delivery/delivery-methods)**.
2. Нажмите **Добавить метод доставки**.
3. Укажите:
  название метода;
  
  телефон для связи.
4. Если доставляете КГТ товары, поставьте галочку **У меня крупногабаритные товары (более 35 кг)**. После создания метода изменить эту настройку не получится. [Подробнее об отгрузке разных типов товаров](/ozon-logistika/dostavka-dlya-biznesa/nastroika-metoda-dostavki#особенности-отгрузки-разных-типов-отправлении)
5. Укажите:
  Куда будете привозить заказы — выберите город и пункт.
  
  Откуда будете забирать возвраты — если в тот же пункт, поставьте галочку **Совпадает с пунктом отгрузки**.

Если отгружаете заказы на СЦ, для получения возврата не получится выбрать ту же точку.

1. Нажмите **Добавить метод**.

Любые настройки метода можно [отредактировать](/ozon-logistika/dostavka-dlya-biznesa/nastroika-metoda-dostavki#%D0%B8%D0%B7%D0%BC%D0%B5%D0%BD%D0%B8%D1%82%D1%8C-%D0%BC%D0%B5%D1%82%D0%BE%D0%B4-%D0%B4%D0%BE%D1%81%D1%82%D0%B0%D0%B2%D0%BA%D0%B8) — кроме галочки **У меня крупногабаритные товары (более 35 кг)**.

# Изменить метод доставки

1. Откройте вкладку **[Методы доставки](https://seller.ozon.ru/app/delivery/delivery-methods)**.
2. Нажмите **Редактировать** возле нужного метода.
3. Измените параметры метода и сохраните изменения.

Можно отредактировать любые настройки метода, кроме галочки **У меня крупногабаритные товары (более 35 кг)**.

При изменении пункта для получения возвратов:

если от заказа отказались до смены пункта, отправим его на старый адрес,

если после — на новый адрес.

В разделе **[Возвраты](https://seller.ozon.ru/app/delivery/returns/main)** будет указан актуальный адрес получения.

# Удалить метод доставки

1. Откройте вкладку **[Метод доставки](https://seller.ozon.ru/app/delivery/delivery-methods)**.
2. Нажмите три точки в строке названия метода.
3. Выберите **Удалить метод**.
4. Подтвердите удаление.

Отмены будем возвращать на адрес, который был указан в удалённом методе. В разделе **[Возвраты](https://seller.ozon.ru/app/delivery/returns/main)**** **будет указан актуальный адрес получения.

# Особенности отгрузки разных типов отправлений

С помощью одного метода доставки можно отгружать только один тип товаров. Его нужно выбрать при создании метода:

**обычные** — все товары, кроме крупногабаритной продукции и автомобильных аккумуляторов;

**крупногабаритные товары** размером в упаковке до 240 × 220 × 120 cм, которые соответствуют как минимум одному из параметров:
вес — от 35 до 125 кг включительно;

длинная сторона — от 200 см;

объём — от 500 литров.

автомобильные аккумуляторы.

Выбрать КГТ-метод для обычного товара не получится.

Если загрузить на площадку товары, не подходящие под условия по весу или размеру, мы не сможем доставить их покупателям и вернём вам отправления.

### Чем отличается работа с КГТ

Не каждый из наших пунктов работает с крупными и тяжелыми заказами. Поэтому список доступных точек будет чуть меньше, чем для обычных товаров.

### Как продавать сразу оба типа товаров

Создайте 2 метода для обоих типов товаров — для КГТ при создании метода нужно включить галочку **У меня крупногабаритные товары (более 35 кг)**.
