# Работа с Ozon Доставкой для бизнеса через API

_Главная / Ozon Доставка / Ozon Доставка для бизнеса_

С помощью **[Ozon Delivery API](https://docs.ozon.ru/api/ozon-delivery/)** можете подключить Ozon Доставку для бизнеса к своему интернет-магазину или внутренней системе и автоматизировать работу с доставкой. Например, вместо создания каждого заказа в личном кабинете вручную — можете автоматически передавать заказы в Ozon, рассчитывать условия доставки и получать статусы отправлений. Личный кабинет при этом остаётся доступен — API является дополнительным способом работы с Ozon Доставкой.

[Рекомендации по отображению доставки Ozon на сторонних сайтах](https://brandlab.ozon.ru/guide/ozondostavka)

# Что можно делать через API

Ozon Delivery API даёт возможность встроить Ozon Доставку в процесс оформления и обработки заказов вашего интернет-магазина. Это позволяет:

проверить, доступна ли Ozon Доставка покупателю;

рассчитать предварительный срок доставки;

получить доступные пункты выдачи Ozon и информацию о них;

проверить возможность доставки конкретного отправления в выбранный ПВЗ;

рассчитать предварительную стоимость доставки и страхования;

создать заказ и одно или несколько отправлений;

подтвердить готовность отправления к отгрузке;

получить этикетку отправления;

получать информацию об отправлениях;

отслеживать изменение статусов, в том числе возвратного потока;

отменить отправление до его получения покупателем.

# Как это работает

1. Покупатель оформляет заказ на вашем сайте.
2. Вы проверяете, доступна ли Ozon Доставка покупателю.
3. Если доставка доступна, показываете покупателю варианты получения заказа. Клиент выбирает подходящий ПВЗ Ozon или курьерскую доставку.
4. Рассчитываете условия. Перед созданием заказа получаете предварительные сроки и стоимость доставки, стоимость страхования. Не проверяем, какую итоговую сумму вы передадите клиенту. Спишем стоимость доставки с вашего баланса после оказания услуг. [Подробнее о расходах на Ozon Доставку](https://seller-edu.ozon.ru/libra/commissions-tariffs/commissions-tariffs-ozon/rashody-ozon-dostavka-dlya-biznesa)
5. После подтверждения покупки передаёте данные о заказе и получателе нам и создаёте заказ.
6. Готовите отправление. Когда заказ собран, подтверждаете готовность к отгрузке. Ozon проверяет, что у вас на балансе достаточно средств. Получаете этикетку и наклеиваете её на отправление.
7. Передаёте отправление Ozon. После приёмки Ozon доставит его получателю.
8. Отслеживаете доставку. Получаете актуальный статус отправления и историю его изменений.

Работа с [финансами](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-biznesa/finansy-ozon-dostavka), спорами, закрывающими документами, [настройками личного кабинета](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-biznesa/nastroika-kabineta-dostavki) и [настройками логистики](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-biznesa/nastroika-metoda-dostavki) происходит в личном кабинете.

# Как подключить API

1. Перейдите в личном кабинете в раздел **[Управление частными приложениями](https://seller.ozon.ru/app/settings/private-apps)**.
2. Нажмите **Создать**.
3. Выберите необходимые права доступа для Ozon Delivery API.
4. Создайте приложение.
5. Получите в личном кабинете Client ID и Client Secret — используйте их для настройки авторизации вашего приложения при обращении к API.
  Client Secret нужно хранить в защищённом месте и не передавать посторонним.
6. После создания приложения передайте данные и техническую документацию вашему разработчику для настройки интеграции. [Подробнее об авторизации](https://docs.ozon.ru/api/ozon-delivery/#tag/GetStarted)

# Как работать с API

## Подготовка к работе с API

Перед созданием заказов через API необходимо [настроить метод доставки](https://seller-edu.ozon.ru/ozon-logistika/dostavka-dlya-biznesa/nastroika-metoda-dostavki) в личном кабинете — он определяет, откуда и каким способом вы будете передавать нам отправления. Пока для работы с API доступен только один способ передачи отправлений — самостоятельная отгрузка в пункт Ozon.

## Рассчёт условий доставки

Перед созданием заказа рекомендуем выполнить предварительный расчёт. При расчёте учитываются:

[метод доставки](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-biznesa/nastroika-metoda-dostavki);

[размеры и вес отправления](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-biznesa/nastroika-metoda-dostavki#%D0%BE%D1%81%D0%BE%D0%B1%D0%B5%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D0%B8-%D0%BE%D1%82%D0%B3%D1%80%D1%83%D0%B7%D0%BA%D0%B8-%D1%80%D0%B0%D0%B7%D0%BD%D1%8B%D1%85-%D1%82%D0%B8%D0%BF%D0%BE%D0%B2-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B8);

выбранный покупателем способ получения;

место получения;

[объявленная стоимость](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-biznesa/rabota-s-zakazami#%D1%87%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-%D0%BE%D0%B1%D1%8A%D1%8F%D0%B2%D0%BB%D0%B5%D0%BD%D0%BD%D0%B0%D1%8F-%D1%81%D1%82%D0%BE%D0%B8%D0%BC%D0%BE%D1%81%D1%82%D1%8C).

В ответ Ozon может вернуть предварительные:

сроки доставки;

стоимость доставки и страхования — рассчитывается по предполагаемым параметрам заказа: в тариф «Доставка» входят все базовые услуги доставки, в тариф «Страховка» — цена страховки. Итоговая стоимость определяется по фактическим параметрам доставки, поэтому суммы могут отличаться. [Подробнее о тарифах](https://seller-edu.ozon.ru/libra/commissions-tariffs/commissions-tariffs-ozon/rashody-ozon-dostavka-dlya-biznesa)

## Подготовка заказа к отгрузке

1. После создания заказа соберите отправление.
2. Перед подтверждением готовности отправления к отгрузке через API убедитесь, что на балансе достаточно средств. При подтверждении Ozon проверит баланс, если средств окажется недостаточно, подтвердить отправление не получится.
3. После успешного подтверждения получите через API этикетку в формате pdf, распечатайте её и наклейте на отправление.
4. В приложении у покупателя начнёт отображаться заказ, и клиент сможет его отслеживать.
5. Передаёте отправление в Ozon.

## Отслеживание отправления

Через API можно получить:

подробную информацию о конкретном отправлении;

список отправлений;

статус — текущий и историю изменений. Например, отправление может последовательно перейти в состояния **Создано → Готово к отгрузке → Доставляется → В пункте выдачи / У курьера → Доставлено**. Также предусмотрены отдельные статусы для ошибок, отмены и проблем при приёмке.

## Отмена отправления

Отправление можно отменить через API, пока оно не доставлено получателю. Если отменить уже переданное Ozon отправление, оно начнёт двигаться обратно к вам как возврат, через API сможете отслеживать его статус.
