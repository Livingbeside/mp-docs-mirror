# Подключение Ozon Доставки для бизнеса

_Главная / Ozon Доставка / Ozon Доставка для бизнеса_

Как начать работу на Ozon Доставке, как зарегистрироваться, как объединить кабинеты доставки и продавца

Ozon Доставку можно подключить с нового аккаунта или объединить с существующим кабинетом продавца.

**Создать новый аккаунт для работы с Ozon Доставкой.** Этот вариант подойдёт, если вы:
не продаёте на Ozon и не планируете размещать товары на площадке;

уже продаёте на Ozon, но хотите иметь отдельные баланс и закрывающие документы для кабинета доставки и продавца.

**Совмещать в одном аккаунте разные виды деятельности:** работать с Ozon Доставкой, продавать товары на Ozon и быть [представителем бренда](/account-brand/how-to-start). Нельзя объединить кабинет доставки и бренда, если у вас нет кабинета продавца.

При объединении кабинетов у них будут:

Общий баланс — его можно будет пополнять из разных кабинетов, с него будут списываться расходы из всех кабинетов.

Общая информация о доходах и расходах в разделе **[Финансы → Экономика магазина](https://seller.ozon.ru/app/finances/accruals)**.

Единый график выплат по [правилам кабинета продавца](/finances-documents/calculations-documents/payments).

Общие закрывающие документы.

# Создать отдельный кабинет доставки

## Если у вас нет кабинета продавца

### Шаг 1. Пройдите регистрацию

Заполните форму [регистрации](/how-to-start/step-1-register). В поле **Сфера деятельности на Ozon **выберите:

**Доставка** — если хотите работать с Ozon Доставкой: размещать товары у себя, вести продажи самостоятельно, а Ozon использовать только для логистики.

**Продавец товаров **— если помимо Ozon Доставки, хотите использовать Ozon как площадку для продажи товаров.

**Представитель бренда** — если кроме продажи товаров и доставки заказов, хотите отслеживать продажу товаров своего бренда. [Подробнее о кабинете бренда](/account-brand/account-brand)

### Шаг 2. Укажите реквизиты

Предложим указать основную информацию — для удобства разбили анкету на несколько шагов. Большую часть информации загрузим автоматически по ИНН. Заполните данные и нажмите **Отправить на проверку**.

Если с вашим ИНН уже зарегистрирован другой магазин на Ozon, попросим подтвердить регистрацию с его аккаунта. Отправим запрос сотруднику с ролью **Управляющий**. Без подтверждения продолжить регистрацию не получится.

Проверим ваши данные в течение 15 минут. Если всё в порядке, пришлём ответ и текст оферты по email и уведомлением в личном кабинете. Вы автоматически примете оферту, когда совершите любое действие в личном кабинете. Чтобы начать работу, [заключите договор страхования](/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#%D1%88%D0%B0%D0%B3-3-%D0%B7%D0%B0%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D0%B5-%D0%B4%D0%BE%D0%B3%D0%BE%D0%B2%D0%BE%D1%80-%D1%81%D1%82%D1%80%D0%B0%D1%85%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F).

После регистрации вы попадёте в личный кабинет продавца. Предложим указать основную информацию — для удобства разбили анкету на несколько шагов. Большую часть информации загрузим автоматически по ИНН. Заполните данные и нажмите **Отправить на проверку**.

Эти данные нужно будет указать один раз — сохраним их в обоих кабинетах.

Если с вашим ИНН уже зарегистрирован другой магазин на Ozon, попросим подтвердить регистрацию с его аккаунта. Отправим запрос сотруднику с ролью **Управляющий**. Без подтверждения продолжить регистрацию не получится.

Проверим ваши данные в течение 15 минут. Если всё в порядке, пришлём ответ и текст оферты по email и уведомлением в личном кабинете. Можете сразу начинать работу на площадке — создавать товары, выбирать схему работы, добавлять склады. Вы автоматически примете оферту, когда совершите любое действие в личном кабинете.

Чтобы начать работу с Ozon Доставкой, вам нужно [переключиться](/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#переключаться-между-кабинетами-продавца-и-доставки) в кабинет доставки и [заключить договор страхования](/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#%D1%88%D0%B0%D0%B3-3-%D0%B7%D0%B0%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D0%B5-%D0%B4%D0%BE%D0%B3%D0%BE%D0%B2%D0%BE%D1%80-%D1%81%D1%82%D1%80%D0%B0%D1%85%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F).

### Шаг 3. Заключите договор страхования

Если данные прошли проверку, предложим заключить договор страхования — без него не получится начать работу.

Страхуем каждое отправление. Для этого при создании заказа вы указываете объявленную ценность — стоимость товаров в заказе, которую вы оцениваете сами. Это нужно, чтобы мы могли выплатить вам компенсацию в случае утраты или повреждения товара.

Как заключить договор:

1. Перейдите в раздел **[Настройки → Договоры](https://seller.ozon.ru/app/settings/contracts)**.
2. Нажмите **Заключить договор страхования**.
3. Укажите паспортные данные в открывшемся окне.
4. Дождитесь окончания проверки. Пришлём ответ и текст договора по email и уведомлением в личном кабинете. Можете сразу начинать работу на площадке. Вы автоматически примете договор, когда совершите любое действие в личном кабинете.

[Договор страхования](https://docs.ozon.ru/common/pravila-prodayoi-i-rekvizity/insuranceb2c-terms/?country=RU)

## Если у вас есть кабинет продавца

Создать кабинет доставки может только сотрудник с ролью **Управляющий **— для сотрудников с другими ролями раздел «Кабинет доставки» не будет отображаться в личном кабинете продавца. [Подробнее о ролях](https://seller-edu.ozon.ru/libra/ozon-logistika/dostavka-dlya-biznesa/nastroika-kabineta-dostavki#%D1%81%D0%BE%D1%82%D1%80%D1%83%D0%B4%D0%BD%D0%B8%D0%BA%D0%B8)

1. Перейдите в раздел **[Настройки → Кабинет доставки](https://seller.ozon.ru/app/settings/delivery)**.
2. Нажмите **Создать новый кабинет**. Нужно будет пройти [регистрацию](/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#%D1%88%D0%B0%D0%B3-1-%D0%BF%D1%80%D0%BE%D0%B8%D0%B4%D0%B8%D1%82%D0%B5-%D1%80%D0%B5%D0%B3%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%86%D0%B8%D1%8E), указать [реквизиты](/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#%D1%88%D0%B0%D0%B3-2-%D1%83%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5-%D1%80%D0%B5%D0%BA%D0%B2%D0%B8%D0%B7%D0%B8%D1%82%D1%8B), заключить оферту и договор [страхования](/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#%D1%88%D0%B0%D0%B3-3-%D0%B7%D0%B0%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D0%B5-%D0%B4%D0%BE%D0%B3%D0%BE%D0%B2%D0%BE%D1%80-%D1%81%D1%82%D1%80%D0%B0%D1%85%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F).

Чтобы зарегистрировать ещё один магазин:

1. Нажмите на название магазина в правом верхнем углу экрана. Выберите **Добавить компанию**.
2. Выберите **Новую**.
3. Пройдите [регистрацию](https://seller-edu.ozon.ru/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#%D1%88%D0%B0%D0%B3-1-%D0%BF%D1%80%D0%BE%D0%B8%D0%B4%D0%B8%D1%82%D0%B5-%D1%80%D0%B5%D0%B3%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%86%D0%B8%D1%8E) — выберите доставку.

Для создания нового магазина можем попросить подтверждение в другом аккаунте с этими же ИНН и КПП — для этого отправим в существующий личный кабинет запрос сотруднику с ролью **Управляющий**.

[Как переключаться между аккаунтами](/ozon-logistika/dostavka-dlya-biznesa/podkluchenie-ozon-dostavki#переключаться-между-кабинетами-продавца-и-доставки)

# Переключаться между кабинетами продавца и доставки

Если кабинеты доставки и продавца привязаны к одному аккаунту, нажмите **Продавец** или **Доставка** возле названия магазина и выберите **Доставка **или** Продавец**.

Если кабинеты привязаны к разным аккаунтам, нужно будет переключиться в другую компанию — для этого нажмите на название магазина и выберите нужную компанию из списка.
