# Как посмотреть собранные отзывы и их стоимость

Мы можем сформировать для вас отчёт со всеми собранными отзывами. Там будут:

тексты отзывов, если оставлена просто оценка без отзыва — это поле будет пустым;

оценки товара;

сумма к оплате за каждый привлечённый отзыв. [Как рассчитываем стоимость услуги](https://seller-edu.ozon.ru/libra/commissions-tariffs/legal-information/full-actual-commissions#2-20-вознаграждение-за-услугу-«ускоренныи-сбор-отзывов»)

Скачанные отзывы и их содержимое нельзя размещать на сторонних сайтах или других ресурсах — они предназначены только для личного использования.

Чтобы получить отчёт:

1. Откройте раздел **[Товары → Ускоренный сбор отзывов](https://seller.ozon.ru/app/reviews/promotions)** и в блоке **Аналитика** нажмите кнопку **Перейти к отчётам**.
2. Выберите период для отчёта и нажмите **Сформировать**.
3. Если заявка на формирование отчёта:
  успешно создана — сформируем отчёт в течение 1 часа;
  
  не создана — появится сообщение об ошибке. Тогда попробуйте заново, а если не получится — напишите в [поддержку](https://seller.ozon.ru/app/messenger?channel=SCRM): **Продвижение и Акции → Маркетинг → Акции → Ускоренный сбор отзывов**.
4. Пришлём оповещение в личный кабинет, когда отчёт будет готов. Скачать его можно по ссылке из уведомления или в разделе **[Товары → Ускоренный сбор отзывов](https://seller.ozon.ru/app/reviews/promotions)**. Для этого в блоке **Аналитика** нажмите **Перейти к отчётам**, а после на название нужного отчёта — загрузится файл в формате XLS.

# Где посмотреть расходы по ускоренному сбору отзывов

Покажем информацию за расчётный период:

в разделе **[Финансы → Экономика магазина](https://seller.ozon.ru/app/finances/transactions-order)**. [Подробнее об отчёте](/analytics-and-metrics/fulfillment-reports/otchet-po-nachisleniyam#%D0%B8%D0%B7-%D1%80%D0%B0%D0%B7%D0%B4%D0%B5%D0%BB%D0%B0-%D1%84%D0%B8%D0%BD%D0%B0%D0%BD%D1%81%D1%8B)

на странице **[Финансы → Баланс](https://seller.ozon.ru/app/finances/report/current)** в блоке **Услуги**.

Данные обновляем ежедневно.
