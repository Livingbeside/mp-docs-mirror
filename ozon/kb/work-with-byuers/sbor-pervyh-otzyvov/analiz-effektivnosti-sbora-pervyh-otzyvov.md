# Как посмотреть, сколько отзывов собрано

В разделе **[Товары → Сбор первых отзывов](https://seller.ozon.ru/app/reviews/collect-reviews)**[ ](https://seller.ozon.ru/app/reviews/collect-reviews)в виджете **Параметры кампании **показываем:

сколько товаров собирают сейчас отзывы;

сколько отзывов уже собрано;

сколько потрачено на сбор отзывов (фиксированная часть);

сколько начислено баллов топ-авторам (переменная часть).

Показываем на странице информацию только по активным сборам. Если какой-то товар уже достиг цели по отзывам, информацию о нём здесь не учитываем.

# Как посмотреть собранные отзывы

1. Откройте раздел **[Товары → Сбор первых отзывов](https://seller.ozon.ru/app/reviews/collect-reviews)****.**
2. Выберите товар, у которого хотите посмотреть отзывы. Увидеть их можно двумя способами:
  нажмите  и выберите **Посмотреть отзывы**;
  
  нажмите на количество отзывов в столбце **Рейтинг.**

Откроем раздел **Отзывы** с фильтрацией по вашему товару и покажем все отзывы по нему.

# Где посмотреть расходы по сбору первых отзывов

Чтобы получить отчёт:

1. Откройте[ ](https://seller.ozon.ru/app/reviews/collect-reviews)**[Товары → Сбор первых отзывов](https://seller.ozon.ru/app/reviews/collect-reviews)** и нажмите **Скачать отчет.**
2. Выберите период для отчёта и нажмите **Сформировать**.

Отразим начисления за услугу в УПД-1, которые отправляем вам раз в месяц, а также покажем информацию за расчётный период:

в разделе **[Финансы → Экономика магазина](https://seller.ozon.ru/app/finances/transactions-order)**. [Подробнее об отчёте](https://seller-edu.ozon.ru/analytics-and-metrics/fulfillment-reports/otchet-po-nachisleniyam#%D0%B8%D0%B7-%D1%80%D0%B0%D0%B7%D0%B4%D0%B5%D0%BB%D0%B0-%D1%84%D0%B8%D0%BD%D0%B0%D0%BD%D1%81%D1%8B)

на странице **[Финансы → Баланс](https://seller.ozon.ru/app/finances/report/current)** в блоке **Услуги**.

Данные обновляем ежедневно.
