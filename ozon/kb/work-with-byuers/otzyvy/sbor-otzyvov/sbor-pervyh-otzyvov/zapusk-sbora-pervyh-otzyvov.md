# Запуск сбора первых отзывов

_Главная / Работа с покупателями / Отзывы / Инструменты сбора отзывов / Сбор первых отзывов_

Как впервые запустить сбор первых отзывов или начать сбор с помощью рекомендаций

Рассказываем, как впервые запустить для товаров сбор отзывов с помощью инструмента **Сбор первых отзывов.** Подробнее о том, что это такое, можно узнать в [статье](https://seller-edu.ozon.ru/work-with-byuers/sbor-pervyh-otzyvov/chto-takoe-sbor-pervyh-otzyvov).

1. Откройте раздел **[Товары → Сбор первых отзывов](https://seller.ozon.ru/app/reviews/collect-reviews)**[ ](https://seller.ozon.ru/app/reviews/collect-reviews)и нажмите **Добавить товары**.
2. Выберите цель по отзывам — сколько видеообзоров вы хотите собрать для каждого товара. Цель должна быть не менее 3.
3. Выберите товары, на которые хотите собрать отзывы. В таблице можно:
  искать по названию или SKU;
  
  отфильтровать по категории, бренду, рейтингу и числу отзывов;
  
  увидеть стоимость сбора и размер начисления автору баллов по каждому товару.
4. В блоке **Прогноз расходов** рассчитаем итоговую стоимость сбора. Проверьте данные и нажмите **Запустить сбор отзывов**.

# Как запустить сбор через рекомендации

1. Откройте **[Товары → Сбор первых отзывов](https://seller.ozon.ru/app/reviews/collect-reviews)****.**
2. В блоке **Рекомендуем собрать отзывы** выберите одну из рекомендаций:
  Товары без отзывов;
  
  Товары, у которых менее 10 отзывов.
3. Откроется страница добавления, где уже выбраны подходящие товары — вы можете проверить и отредактировать список.
4. В блоке **Прогноз расходов** рассчитаем итоговую стоимость сбора. Проверьте данные и нажмите **Запустить сбор отзывов**.
