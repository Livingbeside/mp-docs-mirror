# Запуск ускоренного сбора отзывов

_Главная / Работа с покупателями / Отзывы / Инструменты сбора отзывов / Ускоренный сбор отзывов_

Как запустить ускоренный сбор отзывов и какие ставки можно устанавливать

Рассказываем, как запустить для товаров сбор отзывов с помощью инструмента **Ускоренный сбор отзывов.** Подробнее о том, что это такое и какие типы кампаний есть в инструменте, можно узнать в [статье](https://seller-edu.ozon.ru/work-with-byuers/otzyvy-za-bally/chto-takoe-otzyvy-za-baly).

В зависимости от [типа кампании](https://seller-edu.ozon.ru/libra/work-with-byuers/otzyvy-za-bally/chto-takoe-otzyvy-za-baly#какие-типы-кампании-есть-в-ускоренном-сборе-отзывов), запуск инструмента будет отличаться.

Не получится запустить ускоренный сбор отзывов для некоторых категорий товаров.

# Запуск автоматической кампании

1. Откройте **[Товары → Ускоренный сбор отзывов](https://seller.ozon.ru/app/reviews/promotions)**.
2. В блоке **Автоматические подборки** выберите тип кампании: «Менее 10 отзывов» или «Давно не было отзывов».
3. Укажите дату начала кампании.
4. В блоке **Товары и бюджет** проверьте:
  Количество товаров, на которые будем собирать отзывы. Для этого нажмите **Смотреть товары. **Покажем товары на момент запуска кампании,** **а** **после товары будут удаляться и добавляться автоматически — в зависимости от соответствия условиям.
  
  Количество отзывов, которое можно получить.
  
  Прогноз бюджета — сколько примерно вы потратите на кампанию. Ставку устанавливаем автоматически, изменить её не получится.
  Количество товаров меняется каждый день. Чтобы не выйти за рамки бюджета, следите за ходом кампании — отключить её можно в любой момент. [Как это сделать](https://seller-edu.ozon.ru/libra/work-with-byuers/otzyvy-za-bally/upravlenie-otzyvy-za-baly#как-отключить-ускоренныи-сбор-отзывов)
5. Если всё устраивает, нажмите **Запустить**.
6. После того, как все товары получат 10 отзывов, кампания всё ещё будет в статусе **Активна**. Но затрат на неё не будет, пока не появятся новые товары без отзывов или с момента последнего отзыва не пройдёт 14 дней. Советуем не отключать кампанию сразу — так у товаров всегда будут свежие отзывы.

# Запуск ручной кампании

1. В разделе **[Товары → Ускоренный сбор отзывов](https://seller.ozon.ru/app/reviews/promotions)** нажмите **Создать кампанию**.
2. Придумайте название кампании.
3. Укажите дату начала и окончания. Если не укажете дату окончания, кампания будет работать, пока не соберём все отзывы.
4. Нажмите **Добавить товары. **В открывшемся окне товары можно:
  искать по названию или SKU;
  
  отфильтровать категории, бренду, цене и числу отзывов;
  
  добавить списком — включите **Режим списка** и внесите сразу несколько артикулов или ID. Список можно скопировать из отчёта по товарам из раздела **[Товары → Список товаров](https://seller.ozon.ru/app/products?filter=all)**.
5. После этого нажмите **Добавить товары**. Фиксированная ставка применится автоматически.
6. В поле **Прогноз бюджета **покажем максимальную сумму, которую вы потратите на сбор отзывов.
7. Нажмите **Запустить**.

1. Откройте раздел** Меню → Отзывы и вопросы → Ускоренный сбор отзывов**.
2. Нажмите** Создать кампанию.**
3. Придумайте название кампании.
4. Укажите дату начала и окончания кампании. Если не укажете дату окончания, кампания будет работать, пока не соберём все отзывы.
5. Нажмите **Добавить товары** — создадим кампанию.
6. Выберите товары, которые будут участвовать в кампании. Товары можно отфильтровать по:
  категории;
  
  бренду;
  
  цене;
  
  количеству отзывов.
7. Когда подготовите список товаров, нажмите **Продолжить**.
8. По умолчанию для каждого товара установим 10 отзывов для сбора. Вы можете указать своё значение. [Как это сделать](https://seller-edu.ozon.ru/libra/work-with-byuers/otzyvy-za-bally/upravlenie-otzyvy-za-baly#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%BC%D0%B5%D0%BD%D1%8F%D1%82%D1%8C-%D0%BA%D0%BE%D0%BB%D0%B8%D1%87%D0%B5%D1%81%D1%82%D0%B2%D0%BE-%D0%BE%D1%82%D0%B7%D1%8B%D0%B2%D0%BE%D0%B2-%D0%B8-%D1%81%D1%82%D0%B0%D0%B2%D0%BA%D0%B8)

# Запуск кампании «Ускоренный сбор отзывов для ваших товаров»

Запустить кампанию можно при создании или редактировании товаров:

1. Начните редактировать или [создавать товар](https://seller-edu.ozon.ru/work-with-goods/zagruzka-tovarov/creating-goods/zagruzka-tovarov#%D0%B2%D1%80%D1%83%D1%87%D0%BD%D1%83%D1%8E-%D0%B2-%D0%BB%D0%B8%D1%87%D0%BD%D0%BE%D0%BC-%D0%BA%D0%B0%D0%B1%D0%B8%D0%BD%D0%B5%D1%82%D0%B5).
2. На последнем шаге в блоке **Платное продвижение** убедитесь, что в поле** Ускоренный сбор отзывов **стоит галочка.
3. Отправьте карточку на модерацию. Добавим товар в кампанию с типом «Ускоренный сбор отзывов для ваших товаров». По умолчанию для каждого товара установим цель в 10 отзывов.

1. Откройте вкладку **Товары**.
2. Выберите карточку.
3. Нажмите на блок **Продвижение и лояльность**.
4. В блоке **Ускоренный сбор отзывов** активируйте переключатель **Начнём собирать отзывы на товар.** Добавим товар в кампанию с типом «Ускоренный сбор отзывов для ваших товаров».

## Какие товары подключаем автоматически

Всем новым товарам будем подключать** Ускоренный сбор отзывов**, чтобы карточки быстрее получали свои первые отзывы. Все такие товары добавим в список с названием «Ускоренный сбор отзывов для ваших товаров» в разделе **[Товары → Ускоренный сбор отзывов](https://seller.ozon.ru/app/reviews/promotions)**. Параметры такой кампании по умолчанию:

не ограничена по срокам;

фиксированная ставка за каждый отзыв или оценку;

количество отзывов для сбора — 10.

В такой кампании нельзя управлять периодом проведения, но можно удалить товары.

Чтобы отключить подключение инструмента для новых товаров, перейдите в раздел **[Товары → Управление карточками товаров](https://seller.ozon.ru/app/products/items-management)** и в поле **Добавление новых товаров в «Ускоренный сбор отзывов» **нажмите переключатель. Если переключатель включён, при создании товара через копирование отключить участие в кампании нельзя.

Также вы можете отключить ускоренный сбор отзывов для определённого товара при создании или редактировании карточки:

[вручную](https://seller-edu.ozon.ru/work-with-goods/zagruzka-tovarov/creating-goods/sozdanie-tovarov-v-lk#%D1%88%D0%B0%D0%B3-4-%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D1%8C%D1%82%D0%B5-%D0%BA%D0%B0%D1%80%D1%82%D0%BE%D1%87%D0%BA%D1%83) — снимите галочку в пункте** Ускоренный сбор отзывов**;

[через XLS-шаблон](https://seller-edu.ozon.ru/work-with-goods/zagruzka-tovarov/creating-goods/cherez-xls-shablon) — в блоке **Платное продвижение** в столбце **Ускоренный сбор отзывов** введите **Нет**;

[через онлайн-таблицы](https://seller-edu.ozon.ru/work-with-goods/zagruzka-tovarov/creating-goods/cherez-onlajn-tablicy#%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%BE%D0%B4%D0%B2%D0%B8%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5-%D0%B2-%D1%82%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D0%B5) — в столбце **Платное продвижение **не выбирайте инструмент **Ускоренный сбор отзывов**;

через API — в методе /v3/product/import за тип кампании отвечает поле reviews_promo. Поменяйте значение на **enable**, чтобы включить кампанию. Или **disable** — чтобы отключить. [Подробнее в документации Seller API](https://docs.ozon.ru/api/seller/#section/22-maya-2025)

# Какие ставки устанавливаем

Единая ставка для всех товаров назначается по умолчанию и не зависит от цены и наличия текста отзыва, фото или видео.
