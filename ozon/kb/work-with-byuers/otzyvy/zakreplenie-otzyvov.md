# Закрепление отзыва

_Главная / Работа с покупателями / Отзывы_

Как закрепить отзыв на товар, чтобы повысить доверие покупателей

# Видео «Подписка: управление отзывами»

Закреплять отзывы можно только с подпиской [«Управление отзывами»](https://seller-edu.ozon.ru/seller-rating/podpiska-upravlenie-otzyvami) или [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-pro).

# Что такое закрепление отзыва

Закрепление отзыва — инструмент, который фиксирует выбранный отзыв о товаре на видном месте. Покупатель видит полезную обратную связь сразу — а значит, доверяет товару больше и охотнее покупает.

Закреплённый отзыв будет отображаться:

в результатах поиска при пролистывании фото товара в приложении Ozon. Показываем отзыв третьим после ваших фото или вторым, если фото только одно;

отдельным блоком в карточке товара — покупатель сможет прочитать этот отзыв, не переходя в раздел со всеми отзывами;

на первом месте в списке отзывов для всех вариантов товара.

# Как работает закрепление отзыва

Когда подключите подписку [«Управление отзывами»](https://seller-edu.ozon.ru/seller-rating/podpiska-upravlenie-otzyvami) или [Premium Pro](https://seller-edu.ozon.ru/libra/seller-rating/podpiska-premium-pro), автоматически выберем отзывы с 5 звёздами и длиной не меньше 10 символов и закрепим их у товаров. Если таких отзывов не найдётся, вы сможете самостоятельно закрепить любой понравившийся отзыв или заменить уже закреплённый. Когда у товаров появятся новые полезные отзывы — заменим их на новые.

Отзыв закрепится для всех вариантов товара, которые объединены в карточку. Закрепить отзыв только для конкретного SKU не получится.

Как будет работать инструмент, если два товара с закреплёнными отзывами объединятся в одну карточку?

Если два товара с закреплёнными отзывами объединятся в один, оставим в карточке тот отзыв, который был закреплён последним.

Что будет с закреплёнными отзывами, если я отключу подписку «Управление отзывами» или Premium Pro?

Когда закончится период действия подписки [«Управление отзывами»](https://seller-edu.ozon.ru/seller-rating/podpiska-upravlenie-otzyvami) или [Premium Pro](https://seller-edu.ozon.ru/seller-rating/podpiska-premium-pro), автоматически открепим все отзывы.

Можно ли закрепить отзыв, в котором только оценка?

Нет, отзыв без текста закрепить в карточке не получится. Чтобы отзыв можно было выбрать для закрепления, в нём обязательно должен быть текст хотя бы в одном из полей — в достоинствах, недостатках или комментарии.

Можно ли закрепить несколько отзывов на одном товаре?

Нет, на одном товаре можно закрепить только один отзыв.

# Как закрепить отзыв

Покупатели смогут увидеть отзыв отдельным блоком в карточке только в приложении версии 16.19.0 (для Android) и 16.19.1 (для iOS) или новее.

## В личном кабинете на сайте

В разделе «Закрепление отзыва»

1. Откройте раздел **[Товары ](https://seller.ozon.ru/app/reviews/reviews-pinned)**[→](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ Закрепление отзыва](https://seller.ozon.ru/app/reviews/reviews-pinned)**.
2. Выберите товар. Товары можно искать по названию или артикулу.
3. Нажмите **Выбрать отзыв** рядом с нужным товаром. Откроется страница со всеми отзывами на этот товар — кроме тех, которые содержат только оценку без текста. Для одного товара можно выбрать только один отзыв.
4. Отзыв будет закреплён для всех вариантов товара. Поэтому перед выбором убедитесь, что он подойдёт ко всем товарам, объединённым в одну карточку. Чтобы просмотреть их, нажмите на количество вариантов рядом с названием товара.
5. В списке отзывов выберите тот, который считаете самым полезным для покупателей. Нажмите на строку с текстом отзыва, чтобы просмотреть его целиком, и нажмите **Закрепить**.

В разделе «Отзывы покупателей»

1. Перейдите в раздел **[Товары ](https://seller.ozon.ru/app/reviews/reviews-pinned)**[→](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ Отзывы покупателей](https://seller.ozon.ru/app/reviews/reviews-pinned)**.
2. Откройте отзыв, который хотите закрепить. Для этого нажмите на него в столбце **Отзыв.**
3. В новом окне в блоке **Закрепление отзыва** нажмите** Закрепить**. Отзыв будет закреплён для всех вариантов товара. Поэтому перед закреплением убедитесь, что он подойдёт ко всем товарам, объединённым в одну карточку.

## В приложении

Из карточки товара

1. Перейдите на вкладку **Товары**.
2. Выберите карточку.
3. Нажмите на блок **Продвижение и лояльность**.
4. Нажмите **Выбрать отзыв** в блоке **Закрепление отзыва**.
5. Откроются отзывы и вопросы по товару. У нужного отзыва нажмите **Выбрать.**

Из раздела «Отзывы и вопросы»

1. Перейдите на вкладку **Меню**.
2. Откройте **Отзывы и вопросы**.
3. Нажмите на блок **Закрепление отзыва**. Покажем список всех товаров с отзывами.
4. Откройте нужный товар и нажмите **Выбрать отзыв**.
5. Выберите отзыв в списке и нажмите **Закрепить отзыв**.

# Как заменить отзыв

## В личном кабинете на сайте

В разделе «Закрепление отзыва»

1. Откройте раздел **[Товары ](https://seller.ozon.ru/app/reviews/reviews-pinned)**[→](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ Отзывы ](https://seller.ozon.ru/app/reviews/reviews-pinned)**[→](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ Закрепление отзыва](https://seller.ozon.ru/app/reviews/reviews-pinned)**.
2. Выберите товар, для которого уже подключена услуга — это все товары со статусами **Отзыв закреплён**. Воспользуйтесь фильтром по статусам, чтобы быстрее найти нужный товар.
3. Перейдите к отзывам на этот товар: для товара в статусе **Отзыв закреплён** нажмите на строку с выбранным отзывом.
4. Выберите другой отзыв из списка. Для этого нажмите на строку с отзывом, просмотрите детали отзыва и нажмите **Заменить на этот**.

В разделе «Отзывы покупателей»

1. Перейдите в раздел **[Товары ](https://seller.ozon.ru/app/reviews/reviews-pinned)**[→](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ Отзывы покупателей](https://seller.ozon.ru/app/reviews/reviews-pinned)**.
2. Найдите товар, у которого уже подключена услуга — для удобства используйте поиск по названию или артикулу.
3. Откройте нужный отзыв.
4. В блоке **Закрепление отзыва** нажмите на **Заменить на этот отзыв**.
5. После этого на выбранном товаре и всех его вариантах начнём показывать новый закреплённый отзыв.

После этого на выбранном товаре и всех его вариантах начнём показывать новый закреплённый отзыв — отдельным блоком в карточке товара и первым среди всех остальных отзывов на этот товар.

## В приложении

1. Перейдите в раздел **Меню**.
2. Выберите **Отзывы и Вопросы** и откройте **Закрепление отзывов**.
3. Выберите нужный товар с закреплённым отзывом и нажмите **Все отзывы**.
4. Откройте отзыв, на который хотите заменить текущий. Нажмите:
  **Посмотреть закреплённый **— чтобы прочитать текущий закреплённый отзыв;
  
  **Заменить на этот** — чтобы закрепить выбранный отзыв.

После этого на выбранном товаре и всех его вариантах начнём показывать новый закреплённый отзыв — отдельным блоком в карточке товара и первым среди всех остальных отзывов на этот товар.

# Как открепить отзыв

В разделе «Закрепление отзыва»

1. Откройте раздел **[Товары ](https://seller.ozon.ru/app/reviews/reviews-pinned)**[→](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ Закрепление отзыва](https://seller.ozon.ru/app/reviews/reviews-pinned)**.
2. Выберите товар в статусе **Отзыв закреплён**. Воспользуйтесь фильтром по статусам, чтобы быстрее найти нужный товар.
3. Откройте закреплённый отзыв, нажав на блок с ним под названием товара или на первый отзыв в таблице.
4. В открывшемся окне нажмите **Открепить отзыв**.

В разделе «Отзывы покупателей»

1. Откройте раздел **[Товары](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ →](https://seller.ozon.ru/app/reviews/reviews-pinned)**[ Отзывы покупателей](https://seller.ozon.ru/app/reviews/reviews-pinned)**.
2. Найдите и откройте отзыв, который хотите открепить. Отметим закреплённые отзывы рядом с их статусом.
3. В блоке **Закрепление отзыва** нажмите на **Открепить**.

В течение нескольких минут отзыв открепится.

# Какие статусы бывают у закреплённых отзывов

| Статус услуги | Пояснение |
| --- | --- |
| **Отзыв закреплён** | Отзыв закреплён в карточке товара. |
| **Закреплён до (дата)** | Отзыв закреплён в карточке товара до конца периода действия подписки. |
| **Нет закреплённого отзыва** | Вы открепили отзыв — после окончания периода действия подписки отзыв перейдёт в статус **Отзыв откреплён**. |
| **Отзыв откреплён** | Вы открепили отзыв. |
| **Ошибка закрепления** | Покупатели могут удалять или редактировать отзывы. Если такое произойдёт с закреплённым, товар перейдёт в статус **Ошибка закрепления **—** **в этот период отзыв не будет закреплён. Вот что нужно сделать, чтобы закреплённый отзыв снова показывался в карточке: если покупатель отредактировал отзыв, просмотрите изменённую версию и решите — сохранить этот отзыв закреплённым или выбрать другой;если покупатель удалил отзыв, выберите другой отзыв для закрепления. |

Если товар заблокирован (находится на вкладке **Сняты с продажи** в списке товаров), его статус также изменится на **Ошибка закрепления**. [Как узнать, что товар заблокирован](/policies/documents-violations/prichiny-blokirovki#%D0%BA%D0%B0%D0%BA-%D1%83%D0%B7%D0%BD%D0%B0%D1%82%D1%8C-%D0%BF%D1%80%D0%B8%D1%87%D0%B8%D0%BD%D1%83-%D0%B1%D0%BB%D0%BE%D0%BA%D0%B8%D1%80%D0%BE%D0%B2%D0%BA%D0%B8-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0)

# Как скачать данные по закреплённым отзывам

1. Откройте раздел **[Товары → Закрепление отзыва](https://seller.ozon.ru/app/reviews/reviews-pinned)**.
2. Нажмите **Дополнительно → Скачать аналитику в Excel**.
3. На ваше устройство скачается отчёт со всеми товарами, для которых вы хотя бы раз закрепляли отзыв. В отчёте покажем информацию по каждому месяцу в отдельной вкладке:
  **дата** — когда оказали услугу. Вынесем в отдельную строку каждый день, в который был закреплён отзыв;
  
  **сумма начисления в руб. с НДС** — общая сумма за закрепление отзывов в день. Для отзывов, которые были закреплены без подписки до 31 марта 2026 года;
  
  **SKU **— идентификатор товара, у которого закрепляли отзыв.
