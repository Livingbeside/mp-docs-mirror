# Электронная транспортная накладная (ЭТрН) для FBS

_Главная / Продажа со своего склада (FBS) / Отгрузка со своего склада_

# Когда потребуется электронная транспортная накладная

ЭТрН (электронная транспортная накладная) — цифровой аналог бумажной транспортной накладной.

С 1 сентября 2026 года электронная накладная станет обязательной для тех, кто отправляет, перевозит или принимает коммерческие грузы.

Для FBS порядок работы с ЭТрН зависит от способа отгрузки:

Если отгружаете отправления в пункт приёма (ПВЗ или СЦ) самостоятельно или курьеру, оформлять ЭТрН не нужно.

Если отгружаете отправления на СЦ через стороннюю транспортную компанию, потребуется оформить ЭТрН.

**Будет ли Ozon подписывать бумажные транспортные накладные?**

Продолжим подписывать бумажные накладные, если они нужны транспортной компании или для вашей внутренней отчётности.

**Примут ли заказы без ЭТрН?**

Примем отгрузку без электронной накладной, но ответственность за невыполнение требований к оформлению ЭТрН будет на вас.

# Как сформировать ЭТрН при отгрузке в пункт приёма

Электронную накладную нужно сформировать и отправить через систему ЭДО.

Укажите:

1. **Данные грузополучателя:**
  ООО «Интернет Решения»;
  
  ИНН 7704217370;
  
  КПП 997750001;
  
  оператор ЭДО — Контур.Логистика;
  
  идентификатор участника ЭДО (GUID): 2BM-7704217370-774301001-201407110916237240124.
2. **Данные грузоотправителя** — ваши данные.
3. **Данные грузоперевозчика** — данные транспортной компании.
4. **Адрес пункта приёма Ozon.**
5. Данные об отгрузке — они зависят от того, как вы передаёте заказы по FBS.

Отгрузка поштучно или доверительной приёмкой

1. Выберите заказы и сформируйте отгрузку.
2. Скопируйте **ID отгрузки**.
3. В ЭДО при создании эТрН заполните следующие поля внутри СодИнфГО → ИнфПол → ТекстИнф:
  Тип потока: **<ИнфПол> <ТекстИнф Идентиф="shipment_flow_type" Значение="FBS" /> </ИнфПол>**
  
  ID сформированной FBS-отгрузки: **<ИнфПол> <ТекстИнф Идентиф="shipment_id" Значение="123445" /> </ИнфПол>**
  Пример заполнения:** <СодИнфГО> ... <ИнфПол> <ТекстИнф Идентиф="shipment_flow_type" Значение="FBS" /> </ИнфПол> <ИнфПол> <ТекстИнф Идентиф="shipment_id" Значение="123445" /> </ИнфПол> ... </СодИнфГО>, **где** 123445** — пример, вам нужно передать ID отгрузки из ЛК Ozon.

В заголовке ЭТрН укажите** **тип потока: **FBS dropoff от DD.MM.YYYY**, например** FBS dropoff от 27.08.2026**

Отдельно перечислять грузы в ЭТрН в этом случае не нужно.

Отгрузка доверительной приёмкой с предсортировкой

1. Сформируйте грузоместа
2. Дождитесь, когда они перейдут в статус **«Готов к отгрузке»**.
3. В ЭТрН заполните поле Тип потока:** <ИнфПол> <ТекстИнф Идентиф="shipment_flow_type" Значение="FBS" /> </ИнфПол>**
4. В информации о грузе заполните ID каждого сформированного груза на основе идентификаторов грузов из личного кабинета продавца и стандартных полей в блоке описания грузов.

Интерфейс разных операторов ЭДО может отличаться. Если не можете найти нужные поля, уточните их расположение у своего оператора.

Также ЭТрН можно сформировать через API — запросите инструкцию у вашего оператора ЭДО.

# Как подписываем ЭТрН

После передачи заказов водителю не нужно ждать, пока сотрудник склада подпишет ЭТрН. Он может уехать сразу после завершения отгрузки.

Подпишем третий титул ЭТрН на следующий рабочий день после передачи заказов.

Чтобы мы смогли сопоставить ЭТрН с вашей отгрузкой и подписать документ, перед отправкой проверьте, что правильно указали **shipment_flow_type**, ID отгрузки или ID грузов.
