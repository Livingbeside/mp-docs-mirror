# Работа с кодами активации

_Главная / Благотворительность / Для НКО — добавление благотворительных программ_

Как добавлять, редактировать, удалять и скачивать коды активации

# Какими должны быть коды активации

Вы самостоятельно генерируете коды активации для своих сертификатов. Коды проходят модерацию — прежде чем добавлять их, сверьтесь с правилами:

все коды уникальные и их нельзя угадать;

состоят из цифр (0-9) и/или заглавных латинских букв (A-Z);

длина каждого кода от 8 до 32 символов.

Например, такие коды точно не пройдут модерацию:

CODE1, CODE2, CODE1 — не уникальные;

CODE1, CODE2, CODE3 — предсказуемые;

CODE_$O9tG, CODE_$HaO6, CODE_$7dCn — содержат запрещённые символы;

EE2IE, AY9AI, LOHJ1 — слишком короткие.

Мы советуем генерировать длинные коды из случайного набора символов — для этого можно использовать любой сервис или язык программирования. Например, вот код на языке Python, который генерирует 5 уникальных кодов по 12 символов каждый:

```
{
import string
import textwrap
import secrets

ALPHABET = string.ascii_uppercase + string.digits

def generate_code(length):
    return ''.join(secrets.choice(ALPHABET) for i in range(length))

for i in range(5):
    print(generate_code(12))
}

```

# Как добавить коды активации

Вы можете добавить коды активации на этапе [загрузки сертификата в личном кабинете](/charity/zagruzka/sertifikaty-lk) или к уже загруженному сертификату на странице **[Услуги → Список услуг](https://seller.ozon.ru/app/digital-services/create)**.

Для этого в строке с нужным нажмите  и выберите **Управление кодами активации**.

Добавьте коды:

1. Выберите опцию **Вручную**.
2. Введите коды через пробел и нажмите **Добавить коды**.
3. Проверьте данные и нажмите **Загрузить**.

1. Выберите опцию **Файлом**.
2. Скачайте и заполните шаблон.
3. Добавьте заполненный файл.
4. Нажмите **Загрузить**.

Мы получим и проверим ваши коды активации. Если всё в порядке, сертификат появится на сайте — покупатели увидят его и смогут приобрести.

Результаты проверки можно найти на странице **[Услуги → История обновлений → Коды активации](https://seller.ozon.ru/app/digital-services/import-history/file?currentType=digital_code)**. В таблице будут статус проверки и количество кодов активации с ошибками для каждого сертификата. Чтобы скачать их, нажмите  и выберите **Скачать коды с ошибками**.

# Как удалить или отредактировать коды активации

У Ozon нет доступа к кодам активации. Вы можете их редактировать только на этапе загрузки. Чтобы изменить уже добавленные коды, их нужно удалить и снова загрузить.

Чтобы удалить коды:

1. На странице **[Услуги → Список услуг](https://seller.ozon.ru/app/digital-services/create)** в строке с нужным сертификатом нажмите  и выберите **Управление кодами активации**.
2. Нажмите **Очистить**.

# Как скачать проданные коды активации

1. На странице **[Услуги → Список услуг](https://seller.ozon.ru/app/digital-services/import-history/file?currentType=digital_code)** в строке нужного сертификата нажмите  и выберите **Управление кодами активации**.
2. Нажмите **Скачать**.
3. Выберите период, за который хотите получить данные.
