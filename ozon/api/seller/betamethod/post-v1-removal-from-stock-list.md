# Отчёт по вывозу и утилизации со стока FBO

`POST /v1/removal/from-stock/list`

Метод соответствует разделу [**FBO → Вывоз и утилизация**](https://seller.ozon.ru/app/fbo-operations/returns) в личном кабинете. Вы можете оставить обратную связь по этому методу в комментариях к [обсуждению](https://dev.ozon.ru/community/1608-Novye-metody-po-vyvozu-i-utilizatsii) в сообществе разработчиков Ozon for dev.

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `Client-Id` | header | string | да | Идентификатор клиента. |
| `Api-Key` | header | string | да | API-ключ. |

## Запрос

**Тело запроса** (`application/json`):

- `date_from` — string **обязательный**. Дата начала отчётного периода в формате `YYYY-MM-DD`.
- `date_to` — string **обязательный**. Дата окончания отчётного периода в формате `YYYY-MM-DD`.
- `last_id` — string. Идентификатор последнего значения на странице. Чтобы получить следующие значения, укажите `last_id` из ответа предыдущего запроса.
- `limit` — integer<int32> **обязательный**. Количество элементов в ответе.

## Ответы

**200** — Отчёт по вывозу и утилизации со стока FBO

- `last_id` — string. Идентификатор последнего значения на странице.
- `returns_summary_report_rows` — array[object]. Информация о товарах.
  - `barcode` — string. Штрихкод товара.
  - `box_barcode` — string. Штрихкод коробки.
  - `box_height` — number<double>. Высота коробки в метрах.
  - `box_id` — integer<int64>. Идентификатор коробки.
  - `box_length` — number<double>. Длина коробки в метрах.
  - `box_state` — string. Статус коробки: - `доступно к вывозу`; - `уже в заявке на вывоз`; - `подготовка к вывозу`; - `потеряна`; - `в пути`; - `компенсировано продавцу`; - `утилизирована`; - `собрано`; - `на СЦ`; - `у курьера`; - `неудачная попытка доставки`; - `получена`; - `отменено`; - `в процессе утилизации`; - `в пункте выдачи`; - `расформирована`.
  - `box_volume` — number<double>. Объём коробки в литрах.
  - `box_weight` — number<double>. Вес коробки в килограммах.
  - `box_width` — number<double>. Ширина коробки в метрах.
  - `clearing_warehouse_name` — string. Склад, на котором подготовили товары для вывоза.
  - `delivery_date` — string. Дата доставки товара в ПВЗ, СЦ или курьером.
  - `delivery_type` — string. Способ вывоза: - `самовывоз`; - `ПВЗ`; - `СЦ`; - `курьерская доставка`.
  - `destination_warehouse_address` — string. Адрес склада назначения.
  - `destination_warehouse_name` — string. Название склада назначения.
  - `given_out_date` — string. Дата, когда продавец забрал товары самовывозом со склада Ozon.
  - `is_auto_return` — boolean. Признак, что заявка на вывоз была создана автоматически. [Подробнее об автовывозе в Базе знаний продавца](https://seller-edu.ozon.ru/fbo/vozvraty-utilizaciya-izlishki/vyvoz-tovarov-so-sklada-ozon/avtovyvoz-tovarov-so-sklada-ozon)
  - `name` — string. Название товара.
  - `offer_id` — string. Артикул товара.
  - `preliminary_delivery_price` — number<double>. Предварительная стоимость вывоза товара со склада силами Ozon.
  - `quant_count` — integer<int32>. Количество квантов в заявке на вывоз.
  - `quantity_for_return` — integer<int32>. Количество единиц товара в коробке или заявке на вывоз.
  - `return_created_at` — string. Дата создания заявки на вывоз.
  - `return_id` — integer<int64>. Идентификатор заявки на вывоз.
  - `return_state` — string. Статус заявки на вывоз. Возможные значения для самовывоза со стока: - `создана`; - `собирается на складе`; - `собрана складом`; - `завершена`; - `заполнение данных`; - `утилизирована`. Возможные значения для СЦ, ПВЗ и курьерской доставки со стока: - `создаётся`; - `собирается на складке`; - `передаём в логистику`; - `в пути`; - `завершено`; - `можно забирать часть`; - `можно забирать все`; - `утилизирована`. Возможные значения для вывоза с поставок: - `заполнение данных`; - `подготовка к выдаче`; - `выдача`; - `завершено`; - `отклонено складом`; - `готово к вывозу`; - `утилизировано`; - `обрабатывается`; - `собирается на складе`; - `передаётся в логистику`; - `в пути`; - `можно забрать часть`; - `можно забрать все`.
  - `sku` — integer<int64>. Идентификатор товара в системе Ozon — SKU.
  - `stock_type` — string. Тип остатков для товаров стока: - `доступно к продаже`; - `маркируемые товары, ожидающие действий`; - `истекает срок годности`; - `брак, доступный к вывозу со стока`. Тип остатков для товаров в коробках: - `брак`; - `опознанные излишки`; - `неопознанные излишки без SKU`.
  - `utilization_date` — string. Дата утилизации.

**default** — Ошибка

- `code` — integer<int32>. Код ошибки.
- `details` — array[object]. Дополнительная информация об ошибке.
  - `typeUrl` — string. Тип протокола передачи данных.
  - `value` — string<byte>. Значение ошибки.
- `message` — string. Описание ошибки.
