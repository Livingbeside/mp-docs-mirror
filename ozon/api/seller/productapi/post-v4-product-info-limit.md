# Лимиты на ассортимент, создание и обновление товаров

`POST /v4/product/info/limit`

Метод для получения информации о лимитах:
- На ассортимент — сколько всего товаров можно создать в вашем личном кабинете.
- На создание товаров — сколько товаров можно создать в сутки.
- На обновление товаров — сколько товаров можно отредактировать в сутки.
- На работу с товарами — сколько товаров можно создать в минуту.
- На разархивацию — сколько товаров можно восстановить из архива за сутки.

Если у вас есть лимит на ассортимент и вы израсходуете его, вы не сможете создавать новые товары.

[Подробнее о лимитах в Базе знаний продавца](https://seller-edu.ozon.ru/libra/work-with-goods/zagruzka-tovarov/creating-goods/limit)

## Ответы

**200** — Лимиты на ассортмент, создание и обновление товаров

- `daily_create` — object. Суточный лимит на создание товаров.
  - `limit` — integer<int64>. Количество товаров, которое можно создать за сутки. Если значение `-1`, лимит не ограничен.
  - `reset_at` — string<date-time>. Время в формате UTC, когда сбросится значение счётчика за текущие сутки.
  - `usage` — integer<int64>. Сколько товаров создано за текущие сутки.
- `daily_update` — object. Суточный лимит на обновление товаров.
  - `limit` — integer<int64>. Количество товаров, которое можно обновить за сутки. Если значение `-1`, лимит не ограничен.
  - `reset_at` — string<date-time>. Время в формате UTC, когда сбросится значение счётчика за текущие сутки.
  - `usage` — integer<int64>. Сколько товаров обновлено за текущие сутки.
- `operation_limits` — object. Доступный лимит на работу с товарами.
  - `limit` — integer<int64>. Количество товаров, которое можно создать за минуту.
  - `limit_type` — string (UNSPECIFIED, RATE_LIMIT_PER_MINUTE). Текущий лимит: - `UNSPECIFIED` — не указан; - `RATE_LIMIT_PER_MINUTE` — поминутный лимит. По умолчанию: `UNSPECIFIED`.
- `total` — object. Лимит на ассортимент.
  - `limit` — integer<int64>. Количество товаров, которое можно создать в личном кабинете. Если значение `-1`, лимит не ограничен.
  - `usage` — integer<int64>. Сколько товаров уже создано.
