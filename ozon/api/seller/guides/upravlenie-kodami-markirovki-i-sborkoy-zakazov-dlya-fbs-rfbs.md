# Управление кодами маркировки и сборкой заказов для FBS/rFBS

Коды маркировки товара в системе «Честный ЗНАК» передаются с криптохвостом. Проверьте, что в запросе коды маркировки сериализованы в соответствии с пунктом 7 [стандарта RFC 8259](https://datatracker.ietf.org/doc/html/rfc8259#section-7).

Символ \ должен кодироваться как последовательность `\u001d`. Двойное экранирование в виде `\\u001d` не допускается. Эта логика уже содержится в большинстве JSON-библиотек — проверьте корректность формируемого запроса.
