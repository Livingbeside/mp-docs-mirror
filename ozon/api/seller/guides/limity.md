# Лимиты

Лимиты на количество запросов защищают сервис от перегрузки и обеспечивают стабильную работу для всех пользователей. Если превысите их, вернётся ошибка `429 Too Many Requests`.

Чтобы контролировать лимиты, в ответах возвращаются заголовки с информацией о текущем состоянии лимитов метода:

- `Ratelimit-Remaining` — сколько запросов ещё можно выполнить до ошибки `429 Too Many Requests`.
- `Retry-After` — через сколько секунд можно сделать повторный запрос. 
Возвращается при получении ошибки `429 Too Many Requests`.

У некоторых методов есть свой лимит на количество запросов — он указан в описании метода. 
Если лимит не указан в описании метода, вы можете сделать не больше 50 запросов в секунду с одного Client ID.
