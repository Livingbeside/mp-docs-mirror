# Авторизация через API-ключ

API-ключи хранятся в личном кабинете в скрытом виде. Вы увидите API-ключ только при создании. Сохраните его в надёжном месте или сразу укажите в своих системах. 

Вы не сможете восстановить доступ к несохранённым API-ключам. Чтобы продолжить работу с API, создайте новый ключ.

Ozon может отозвать ключ, если обнаружит подозрительную активность или слишком большую нагрузку на свои системы.

## Как получить доступ к Seller API 

1. Зарегистрируйтесь в [Ozon Seller](https://seller.ozon.ru/app/signup). Подробнее о регистрации 
 в [Базе знаний продавца](https://seller-edu.ozon.ru/docs/how-to-start/step-1-register.html).
2. Примите оферту.
3. Получите API-ключ.

## Как получить API-ключ

Не передавайте API-ключ посторонним людям 

Запросы к API изменяют данные в вашем магазине на Ozon. Если доступ к ключу будет у посторонних, они смогут управлять 
вашим магазином.

Чтобы получить API-ключ:
1. В личном кабинете перейдите в [**Настройки → Seller API**](https://seller.ozon.ru/app/settings/api-keys).
2. Нажмите **Сгенерировать ключ**.
3. Придумайте название для ключа и выберите его уровень доступа.
4. Выберите цель использования ключа: 
 - для личного пользования;
 - для внешнего сервиса, приложения — введите название сервиса, для которого выпускается ключ.
5. Нажмите **Сгенерировать**.

Срок действия ключа — 3 месяца. После истечения срока действия сгенерируйте новый ключ в личном кабинете.

Получите дату истечения срока действия ключа в параметре `expires_at` метода [/v1/roles](#operation/AccessAPI_RolesByToken).

Вы можете создать несколько API-ключей. Например, если у вас несколько пользователей с разными уровнями доступа.

### Отредактировать ключ

Если вы хотите изменить разрешённые сети для ключа, в [списке API-ключей](https://seller.ozon.ru/app/settings/api-keys) выберите нужный и нажмите .
Внесите изменения и нажмите **Обновить**.

## API-ключ попал в посторонние руки

1. В личном кабинете перейдите в [**Настройки → Seller API**](https://seller.ozon.ru/app/settings/api-keys).
2. Удалите текущий API-ключ и создайте новый.
