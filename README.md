# mp-docs-mirror — само зеркало

Документация Ozon, Wildberries, Яндекс Маркета и Uzum Market в markdown. Файлы генерируются
автоматически, руками их не правят: следующий прогон качалок затрёт правку.

Инструменты, установщик и инструкция для агента — в репозитории
[mp-docs](https://github.com/Livingbeside/mp-docs). Обычный способ пользоваться этим
зеркалом — не клонировать его отдельно, а поставить mp-docs: он положит зеркало
в `mirror/` и подключит поиск.

```
ozon/api/seller/   Seller API: файл на метод + сырая спека spec.json
ozon/kb/           база знаний seller-edu: регламенты, тарифы, габариты, лимиты
wb/api/            Wildberries: 13 разделов OpenAPI
ym/api/, ym/doc/   Яндекс Маркет: Partner API и справка
uzum/api/seller/   Uzum Market: Seller API, файл на метод + spec.json
uzum/kb/           Uzum Market: инструкция для продавцов
```

Ценность репозитория — в истории: маркетплейсы объявляют не все изменения,
и молчаливые правки лимитов и схем видны только в диффе.

```bash
git log -p --since=1.month -- ozon/api/seller/
```

У каждого файла в frontmatter есть `source_url` и `updated` — дата правки на стороне
маркетплейса, а не дата скачивания.

Содержимое принадлежит Ozon, Wildberries, Яндекс Маркету и Uzum: это их публичная
документация, скачанная как есть. Если срез разошёлся с официальным источником,
право за официальным.
