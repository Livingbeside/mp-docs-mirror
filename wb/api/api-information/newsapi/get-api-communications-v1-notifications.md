# Получить уведомления портала продавцов

`GET /api/communications/v1/notifications`

Описание метода

Метод возвращает список уведомлений из [профиля](https://seller.wildberries.ru) продавца на русском языке. Порядок уведомлений в ответе — от новых к старым.

Доступно только для продавцов из РФ.

Лимит запросов на один профиль продавца:

| Тип | Период | Лимит | Интервал | Всплеск |
| --- | --- | --- | --- | --- |
| Персональный | 1 мин | 1 запрос | 1 мин | 10 запросов |
| Сервисный | 1 мин | 1 запрос | 1 мин | 10 запросов |
| Базовый с секретом | 1 мин | 1 запрос | 1 мин | 10 запросов |
| Базовый | 1 ч | 1 запрос | 1 ч | 1 запрос |

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `from` | query | string<date-time> | нет | Фильтр по дате и времени: в ответе возвращаются только уведомления, полученные до указанной даты и времени. Указывайте значения не позднее текущих. Чтобы получить самые новые уведомления, не передавайте в запросе этот параметр. Используйте параметр для пагинации: 1. Отправьте первый запрос запрос без параметра `from`. 2. В следующих запросах передайте в параметре `from` значение `date` последнего уведомления в ответе. |
| `timezone` | query | string | нет | Временная зона в формате [IANA](https://nodatime.org/TimeZones) |
| `limit` | query | integer<int64> | нет | Количество уведомлений в ответе |

## Ответы

**200** — Успешно

- `data` — array[object] **обязательный**. Список уведомлений
  - `date` — string<date-time> **обязательный**. Дата и время отправки уведомления
  - `id` — string<uuid> **обязательный**. ID уведомления
  - `linkData` — object. Данные кнопки в уведомлении
    - `linkHref` — string **обязательный**. URL кнопки в уведомлении
    - `linkText` — string **обязательный**. Текст кнопки в уведомлении
  - `text` — string **обязательный**. Текст уведомления
  - `title` — string **обязательный**. Заголовок уведомления

**400** — Неправильный запрос

- `status` — integer **обязательный**. HTTP статус-код
- `title` — string **обязательный**. Заголовок ошибки
- `detail` — string **обязательный**. Детали ошибки
- `origin` — string **обязательный**. ID внутреннего сервиса WB
- `errors` — array[object]. Список ошибок

- `code` — string **обязательный**. Внутренний код ошибки
- `requestId` — string **обязательный**. ID запроса
