# Продажи по регионам

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Аналитика

 Узнать больше об отчётах о продажах по регионам можно в [справочном центре](https://seller.wildberries.ru/instructions/material/A-235?categoryId=5f2162c5-069b-416d-a4e1-48da2a76e6b0)

Чтобы получить отчёт о [продажах по регионам](https://seller.wildberries.ru/analytics-reports/region-sale), воспользуйтесь [методом загрузки](./reports#tag/salesByRegions/operation/getV1AnalyticsRegionSale).
