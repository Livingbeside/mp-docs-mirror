# Отчёт о товарах c обязательной маркировкой

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Аналитика

 Узнать больше об отчётах по товарам с обязательной маркировкой можно в [справочном центре](https://seller.wildberries.ru/instructions/material/A-243?categoryId=5f2162c5-069b-416d-a4e1-48da2a76e6b0)

Чтобы получить отчёт с [операциями по товарам с обязательной маркировкой](https://seller.wildberries.ru/analytics-reports/excise-report), воспользуйтесь [методом загрузки](./reports#tag/reportOnItemsWithMandatoryLabeling/operation/postV1AnalyticsExciseReport).
