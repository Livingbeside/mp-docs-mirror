# Доля бренда в продажах

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Аналитика

 Узнать больше об отчётах о доле бренда в продажах можно в [справочном центре](https://seller.wildberries.ru/instructions/material/A-234?categoryId=5f2162c5-069b-416d-a4e1-48da2a76e6b0)

Отчёты о [доле бренда продавца в продажах](https://seller.wildberries.ru/analytics-reports/brand-share).

Для [получения отчёта](./reports#tag/shareOfBrandInSales/operation/getV1AnalyticsBrandShare) вам понадобятся:
 1. [Названия брендов](./reports#tag/shareOfBrandInSales/operation/getV1AnalyticsBrandShareBrands).
 2. [ID категорий](./reports#tag/shareOfBrandInSales/operation/getV1AnalyticsBrandShareParentSubjects).

Можно получить отчёт максимум за 365 дней.
