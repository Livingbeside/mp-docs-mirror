# Отчёт о возвратах и перемещении товаров

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Аналитика

 Узнать больше об отчётах о возвратах и перемещении товаров можно в [справочном центре](https://seller.wildberries.ru/instructions/material/returns-and-item-transfer-perort)

Чтобы получить отчёт о [возвратах товаров](https://seller.wildberries.ru/return-transfer-reports), воспользуйтесь [методом загрузки](./reports#tag/returnsAndItemMovementReport/operation/getV1ItemReturns).
