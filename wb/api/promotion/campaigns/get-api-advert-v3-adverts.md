# Информация о кампаниях

`GET /api/advert/v3/adverts`

Описание метода

Метод возвращает информацию о кампаниях с единой или ручной ставкой по их статусам, типам оплаты или списку ID.

Чтобы получить все кампании:
 1. Сделайте первый запрос без параметра `next`.
 2. Повторяйте запрос со значением параметра `next` из ответа на предыдущий запрос, пока `next` не вернётся пустым `""`. Это будет означать, что вы получили все кампании.

Чтобы получить конкретные кампании, передайте их ID в параметре `advertIds`.
Не передавайте `advertIds` в одном запросе с другими параметрами.

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `advertIds` | query | string | нет | ID кампаний |
| `statuses` | query | string | нет | Статусы кампаний: - `4` — готова к запуску - `7` — кампания завершена - `9` — идут показы - `11` — кампания на паузе |
| `next` | query | string | нет | Параметр пагинации |
| `limit` | query | integer | нет | Количество кампаний в ответе |
| `paymentType` | query | string (cpm, cpc) | нет | Тип оплаты: - `cpm` — за показы - `cpc` — за клик |

## Ответы

**200** — Успешно

- `adverts` — array[object] **обязательный**. Кампании
  - `advertId` — integer **обязательный**. ID кампании
  - `status` — integer (4, 7, 9, 11) **обязательный**. Статус кампании: - `4` — готова к запуску - `7` — завершена - `9` — активна - `11` — на паузе
  - `timestamps` — object **обязательный**. Временные отметки
    - `created` — string<date-time> **обязательный**. Время создания кампании
    - `updated` — string<date-time> **обязательный**. Время последнего изменения кампании
    - `started` — string<date-time> **обязательный**. Время последнего запуска кампании
    - `ended` — string<date-time> **обязательный**. Время завершения кампании
  - `settings` — object **обязательный**. Настройки кампании
    - `paymentType` — string **обязательный**. Тип оплаты: - `cpm` — за показы - `cpc` — за клик
    - `name` — string **обязательный**. Название кампании
    - `placements` — ? **обязательный**
  - `nms` — array[object] **обязательный**. Настройки товаров
    - `nmId` — integer **обязательный**. Артикул WB
    - `subject` — object **обязательный**
      - `id` — integer<int64> **обязательный**. ID предмета
      - `name` — string **обязательный**. Название предмета
    - `bids` — array[object] **обязательный**. Ставки
      - `type` — string (search, recommendations, combined) **обязательный**. Место размещения кампании: - `search` - поиск - `recommendations` - рекомендации - `combined` - поиск и рекомендации с единой ставкой
      - `value` — integer<int64> **обязательный**. Ставка
  - `currency` — string<ISO 4217> **обязательный**. Код валюты
  - `restrictions` — object **обязательный**. Ограничения кампании
    - `canChangeNms` — boolean. Можно ли изменять список товаров кампании: - `true` — да - `false` — нет
- `next` — string **обязательный**. Параметр пагинации. Укажите это значение в запросе, чтобы получить следующий пакет кампаний. Если поле пустое `""`, вы получили все кампании

**400** — Неправильный запрос

- `detail` — string **обязательный**. Детали ошибки
- `origin` — string **обязательный**. ID внутреннего сервиса WB
- `request_id` — string **обязательный**. Уникальный ID запроса
- `status` — integer **обязательный**. HTTP статус-код
- `title` — string **обязательный**. Заголовок ошибки

**401** — Не авторизован

- `title` — string. Заголовок ошибки
- `detail` — string. Детали ошибки
- `code` — string. Внутренний код ошибки
- `requestId` — string. Уникальный ID запроса
- `origin` — string. ID внутреннего сервиса WB
- `status` — number. HTTP статус-код
- `statusText` — string. Расшифровка HTTP статус-кода
- `timestamp` — string<date-time>. Дата и время запроса

**429** — Слишком много запросов

- `title` — string. Заголовок ошибки
- `detail` — string. Детали ошибки
- `code` — string. Внутренний код ошибки
- `requestId` — string. Уникальный ID запроса
- `origin` — string. ID внутреннего сервиса WB
- `status` — number. HTTP статус-код
- `statusText` — string. Расшифровка HTTP статус-кода
- `timestamp` — string<date-time>. Дата и время запроса
