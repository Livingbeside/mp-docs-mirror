# Календарь акций

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Цены и скидки

 Узнать больше о календаре акций можно в [справочном центре](https://seller.wildberries.ru/instructions/material/A-259?goBackOption=prevRoute&categoryId=cddf8f00-821e-4a42-8d6d-80f2601bb7b3)

С помощью этих методов можно получить:
 1. [Список акций](./promotion#tag/promoCalendar/operation/getV1CalendarPromotions)
 2. [Детальную информацию об акциях](./promotion#tag/promoCalendar/operation/getV1CalendarPromotionsDetails)
 3. [Список товаров для участия в акциях](./promotion#tag/promoCalendar/operation/getV1CalendarPromotionsNomenclatures)

Также можно [добавить товар для участия в акции](./promotion#tag/promoCalendar/operation/postV1CalendarPromotionsUpload).
