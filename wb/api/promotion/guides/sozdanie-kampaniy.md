# Создание кампаний

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Продвижение

Метод создания кампаний с [единой или ручной](./promotion#tag/creatingCampaigns/operation/postV2SeacatSaveAd) ставкой, а также получения:
 1. [Минимальных ставок для карточек товаров](./promotion#tag/creatingCampaigns/operation/postV1BidsMin)
 2. [Предметов для кампаний](./promotion#tag/creatingCampaigns/operation/getV1SupplierSubjects)
 3. [Карточек товаров для кампаний](./promotion#tag/creatingCampaigns/operation/postV2SupplierNms)
