# Финансы

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Продвижение

Вы можете посмотреть ваш [баланс](./promotion#tag/finances/operation/getV1Balance) и [бюджет ваших рекламных кампаний](./promotion#tag/finances/operation/getV1Budget). Бюджет рекламных кампаний можно [пополнить](./promotion#tag/finances/operation/postV1BudgetDeposit).

Также вы можете узнать историю ваших [затрат](./promotion#tag/finances/operation/getV1Upd) и [пополнений счёта](./promotion#tag/finances/operation/getV1Payments).
