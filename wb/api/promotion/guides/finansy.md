# Финансы

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Продвижение

С помощью методов этого раздела вы можете:
 - получить информацию о [балансе и счёте](./promotion#tag/finances/operation/getV1Balance)
 - получить информацию об [остатках бюджетов кампаний](./promotion#tag/finances/operation/postV2Budget)
 - получить историю ваших [затрат](./promotion#tag/finances/operation/getV1Upd)
 - получить историю [пополнений счёта](./promotion#tag/finances/operation/getV1Payments)
 - [пополнить бюджет](./promotion#tag/finances/operation/postV1BudgetDeposit)
