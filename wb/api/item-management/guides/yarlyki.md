# Ярлыки

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Контент

 Узнать, как использовать методы в бизнес-кейсах, можно в [инструкции](/knowledge-base/articles/019d49a4-1320-71bb-9dac-8ba07e7177ce/rabota-s-tovarami) по работе с товарами

 Узнать больше о ярлыках можно в [справочном центре](https://seller.wildberries.ru/instructions/material/A-166?categoryId=3a795fe1-d5cb-4120-be1a-387eed6494e5)

Ярлыки позволяют быстро фильтровать и искать карточки товаров в личном кабинете. В разделе вам доступны методы:
 1. [Получения списка ярлыков продавца](./work-with-products#tag/labels/paths/~1content~1v2~1tags/get). Эти ярлыки можно использовать в карточках товаров.
 2. [Добавления новых ярлыков](./work-with-products#tag/labels/paths/~1content~1v2~1tag/post).
 3. [Изменения существующих ярлыков](./work-with-products#tag/labels/paths/~1content~1v2~1tag~1%7Bid%7D/patch).
 4. [Удаления ярлыков](./work-with-products#tag/labels/paths/~1content~1v2~1tag~1%7Bid%7D/delete).
 5. [Управления ярлыками в карточке товара](./work-with-products#tag/labels/paths/~1content~1v2~1tag~1nomenclature~1link/post): добавления или удаления ярлыка.
