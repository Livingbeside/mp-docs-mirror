# Рекомендации

Для доступа к методам используйте [токен](./api-information#tag/authorization/Kak-sozdat-personalnyj-bazovyj-ili-testovyj-token) для категории Контент

 Узнать больше о рекомендациях можно в [справочном центре](https://seller.wildberries.ru/instructions/ru/ru/material/sellers-recomendation-module-in-card)

С помощью этих методов можно:
 1. [Получить](./item-management#tag/recommendations/operation/postV1RecommendationsList) список рекомендаций в карточках товаров
 2. [Установить](./item-management#tag/recommendations/operation/postV1RecommendationsSet) рекомендации для товаров

 Вы можете использовать эти методы только с тарифом Продвинутый или Премиальный в подписке Джем либо с опцией Блок «Продавец рекомендует» в карточке товара в Конструкторе тарифов
