# Как работать с уведомлениями

Вы можете подключить API-уведомления и Маркет будет отправлять вам запрос [POST notification](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.md) с информацией о [событии](*notification-type) каждый раз, когда оно будет происходить.

Это необязательная интеграция, вы можете не подключать уведомления. Однако с их помощью вы сможете оперативно реагировать на изменения в заказах, невыкупах и возвратах, а также на появление заявки на отмену заказа.

Маркет обменивается данными только с магазинами, которые работают по протоколу HTTPS с использованием SSL-сертификата. Он должен быть подписан официальным центром сертификации, самоподписанный сертификат не подойдет. Информацию о центрах сертификации можно найти в интернете.

{% note tip "Проверяйте каждый запрос по диапазонам IP-адресов" %}

От этого зависит безопасность вашей интеграции — так вы убедитесь, что запрос пришел именно от Маркета.

Диапазоны IP-адресов, которые использует Маркет:

* [5.45.207.0/25](*ip-range-5-45-207)
* [141.8.142.0/25](*ip-range-141-8-142)
* [5.255.253.0/25](*ip-range-5-255-253)

{% endnote %}


## Подключение интеграции {#how-to-start}

![Скриншот подключения интеграции](../_images/new-notification.png)

Чтобы получать уведомления от Маркета:

1. В кабинете продавца на Маркете нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули** → вкладка **API-уведомления**.

1. Нажмите кнопку **Подключить уведомления**.

1. Укажите название уведомления — оно понадобится только для поиска уведомления в списке.

1. Выберите, вы настраиваете уведомления для кабинета или магазина:

    <br>

    #|
    || | **Уведомления приходят** | **Роль, необходимая для настройки уведомления**

    [Какие бывают роли](https://yandex.ru/support2/marketplace/ru/account/permissions/roles)||
    || кабинет | для всех магазинов кабинета| владелец кабинета или менеджер кабинета ||
    || магазин | для конкретного магазина | любая роль, кроме контент-менеджера ||
    |#

1. Выберите типы уведомлений, которые хотите получать:

    | **Уведомление**                         | **Приходит для кабинета** | **Приходит для магазина** |
    | -------------------------------------   | ------------------------- | ------------------------- |
    | создание заказа                         | ✔️ | ✔️ |
    | изменение заказа                        | ✔️ | ✔️ |
    | изменение статуса заказа                | ✔️ | ✔️ |
    | отмена заказа                           | ✔️ | ✔️ |
    | создание заявки на отмену заказа        | ✔️ | ✔️ |
    | создание возврата или невыкупа          | ✔️ | ✔️ |
    | изменение статуса возврата или невыкупа | ✔️ | ✔️ |
    | новый отзыв                             | ✔️ | |
    | новый комментарий к отзыву              | ✔️ | |
    | новый чат с покупателем                 | ✔️ | |
    | новое сообщение в чате                  | ✔️ | |
    | начало спора                            | ✔️ | |
    | завершение спора                        | ✔️ | |

    ⚠️ Если уведомления, связанные с заказами, настроены для кабинета, они приходят и по FBY-заказам.

   {% note warning "Если уведомления настроены и для кабинета, и для магазина" %}

    Если вы подключили уведомление и для кабинета, и для магазина — Маркет отправит **только одно уведомление** на URL магазина.

    Уведомление на URL кабинета придёт, только если у магазина этот тип уведомления не подключён.

    {% endnote %}

1. Введите ссылку, куда Маркет будет отправлять уведомления. Укажите ее целиком, включая протокол HTTPS.

1. Нажмите кнопку **Подключить**. Созданные уведомления появятся в кабинете сразу, но приходить они начнут **в течение 2 минут**.

### Проверка интеграции {#check}

Чтобы проверить работоспособность интеграции, Маркет отправит запрос [POST notification](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.md), где в теле будет проверочное уведомление с типом `PING`.

{% cut "Пример тела запроса" %}

```json translate=no
{
  "notificationType": "PING",
  "time": "2025-01-16T10:09:49.759084017Z"
}
```
{% endcut %}

Верните ответ с кодом `200` и информацией об обработке уведомления в течение 1 секунды. Интеграция не подключится при передаче другого кода, некорректных или недостаточных данных. [Возможные ошибки](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/concepts/error-codes.md#shop-errors)

{% cut "Пример тела ответа" %}

```json translate=no
{
  "version": "1.0.0",
  "name": "name",
  "time": "2025-01-16T10:09:49.759084017Z"
}
```
{% endcut %}

## Ответ на запрос {#how-to-response}

Таймаут на ответ для обычных уведомлений составляет 10 секунд, для проверочных уведомлений типа `PING` — 1 секунда.

* Если запрос был корректным, верните код `200` с информацией об обработке уведомления. [Тело ответа](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.md#200-ok)

* Если Маркет прислал некорректное уведомление, верните код `400` с описанием ошибки. Маркет проанализирует такие ответы и доработает API со своей стороны. [Тело ответа](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.md#400-bad-request)

* Если произошла техническая ошибка на вашей стороне, верните код `500`. [Тело ответа](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.md#500-internal-server-error)

Подробную информацию по запросам и ответам, в том числе ошибки, можно посмотреть в кабинете продавца на Маркете — нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули** → вкладка **Лог уведомлений**. Подробнее об этом читайте в разделе [Логи запросов](https://yandex.ru/dev/market/partner-api/doc/ru/concepts/debug.md).

[Возможные ошибки](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/concepts/error-codes.md#shop-errors)


### API магазина не отвечает {#no-answer}

Если магазин не укладывается в десятисекундный таймаут или на запрос [POST notification](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.md) возвращает ошибку, кроме `400`, Маркет:

* Перестает присылать другие уведомления до тех пор, пока не получит подходящий ответ на проблемный запрос.
* Повторяет проблемный запрос:

  1. Каждую минуту в течение первого часа.
  1. Раз в 15 минут в течение первого дня.
  1. Далее раз в час.

Если API магазина недоступен в течение 14 дней с момента отправки первого уведомления, магазин отключается **от интеграции**, но продолжает размещать и продавать товары. Маркет отменит все уведомления, которые не смог отправить до отключения, и не будет присылать новые.

Чтобы продолжить получать уведомления, подключите их снова. О том, как это сделать, читайте в разделе [Управление уведомлениями](#manage).


## Управление уведомлениями {#manage}

{% note warning "После изменения уведомления" %}

В кабинете информация обновится сразу, но уведомления начнут приходить или отключатся **в течение 2 минут**.

{% endnote %}

![Скриншот подключенных интеграций](../_images/all-notifications.png)

{% cut "Изменить" %}

Вы можете редактировать название и типы уведомлений, а также ссылку для их отправки. Для этого:

1. В кабинете продавца на Маркете нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули** → вкладка **API-уведомления**.

1. Найдите нужное уведомление, нажмите три точки рядом с ним и выберите **Редактировать**.

1. Измените необходимую информацию.

1. Нажмите **Подключить**.

{% endcut %}

{% cut "Отключить" %}

Вы можете отключить отправку уведомлений, не удаляя их. Для этого:

1. В кабинете продавца на Маркете нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули** → вкладка **API-уведомления**.

1. Найдите нужное уведомление, нажмите три точки рядом с ним и выберите **Отключить**.

{% endcut %}


{% cut "Подключить" %}

Чтобы отключенное уведомление снова заработало:

1. В кабинете продавца на Маркете нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули** → вкладка **API-уведомления**.

1. Найдите нужное уведомление, нажмите три точки рядом с ним и выберите **Подключить**.

1. Если уведомления были отключены Маркетом, придет запрос [POST notification](https://yandex.ru/dev/market/partner-api/doc/ru/push-notifications/reference/sendNotification.md), где в теле будет проверочное уведомление с типом `PING`. Верните ответ с кодом `200` и информацией об обработке уведомления в течение 1 секунды.

{% endcut %}

{% cut "Дублировать настройки" %}

Чтобы не создавать уведомления для магазина с нуля, продублируйте уже созданные настройки для другого магазина:

1. В кабинете продавца на Маркете нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули** → вкладка **API-уведомления**.

1. Найдите нужное уведомление, нажмите три точки рядом с ним и выберите **Дублировать настройки**.

1. Укажите нужный магазин.

1. Нажмите **Дублировать**.

{% endcut %}

{% cut "Удалить" %}

Чтобы удалить уведомление:

1. В кабинете продавца на Маркете нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули** → вкладка **API-уведомления**.

1. Найдите нужное уведомление, нажмите три точки рядом с ним и выберите **Удалить**.

1. Подтвердите удаление.

{% endcut %}

[*notification-type]: События, по которым Маркет присылает уведомления:<ul><li>создание нового заказа;</li><li>изменение заказа;</li><li>изменение статуса заказа;</li><li>создание нового чата с покупателем;</li><li>добавление нового сообщения в чате;</li><li>начало спора;</li><li>завершение спора;</li><li>создание нового отзыва о товаре;</li><li>создание нового комментария к отзыву;</li><li>создание заявки на отмену заказа;</li><li>отмена заказа;</li><li>создание нового невыкупа или возврата;</li><li>изменение статуса невыкупа или возврата.</li></ul>Уведомления будут приходить в том числе и по тестовым заказам.
