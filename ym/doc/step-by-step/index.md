# Пошаговые инструкции

Этот раздел содержит пошаговые инструкции для решения задач, с которыми сталкиваются большинство продавцов. К некоторым задачам нельзя приступать с нуля — в таких случаях вы увидите, какую пошаговую инструкцию нужно пройти перед той, что вы открыли.

Любая задача потребует настройки авторизации для отправки запросов Маркету — поэтому первым делом выполните [инструкцию](https://yandex.ru/dev/market/partner-api/doc/ru/concepts/api-key.md) из раздела «Подготовка к работе».
