# Получение информации об одной отгрузке

`GET /v2/campaigns/{campaignId}/first-mile/shipments/{shipmentId}`

{% include notitle [access](../../_auto/method_scopes/getShipment.md) %} Возвращает информацию об отгрузке по ее идентификатору. {% include notitle [limit](../../_auto/method_limits/getShipment.md) %}

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `campaignId` | path | integer<int64> | да | Идентификатор кампании (магазина) — технический идентификатор, который представляет ваш магазин в системе Яндекс Маркета при работе через API. Он однозначно связывается с вашим магазином, но предназначен только для автоматизированного взаимодействия. Его можно узнать с помощью запроса [GET v2/campaigns](../../reference/campaigns/getCampaigns.md) или найти в кабинете продавца на Маркете. Нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули**: * блок **Идентификатор кампании**; * вкладка **Лог запросов** → выпадающий список в блоке **Показывать логи**. ⚠️ Не путайте его с: - идентификатором магазина, который отображается в личном кабинете продавца; - рекламными кампаниями. |
| `shipmentId` | path | integer<int64> | да | Идентификатор отгрузки. |
| `cancelledOrders` | query | boolean | нет | Возвращать ли отмененные заказы. Значение по умолчанию: `true`. Если возвращать отмененные заказы не нужно, передайте значение `false`. |

## Ответы

**200** — Найденная отгрузка.

- `status` — string (OK, ERROR) **обязательный**. Тип ответа. Возможные значения: * `OK` — ошибок нет. * `ERROR` — при обработке запроса произошла ошибка.
- `result` — object. Информация об отгрузке.
  - `id` — integer<int64> **обязательный**. Идентификатор отгрузки.
  - `planIntervalFrom` — string<date-time> **обязательный**. Начало планового интервала отгрузки. Формат даты: ISO 8601 со смещением относительно UTC.
  - `planIntervalTo` — string<date-time> **обязательный**. Конец планового интервала отгрузки. Формат даты: ISO 8601 со смещением относительно UTC.
  - `shipmentType` — string (IMPORT, WITHDRAW). Способ отгрузки заказов.
  - `warehouse` — object. Данные о складе отправления.
    - `id` — integer<int64> **обязательный**. Идентификатор склада отправления.
    - `name` — string. Наименование склада отправления.
    - `address` — string. Адрес склада отправления.
  - `warehouseTo` — object. Данные о складе назначения.
    - `id` — integer<int64> **обязательный**. Идентификатор склада отправления.
    - `name` — string. Наименование склада отправления.
    - `address` — string. Адрес склада отправления.
  - `externalId` — string. Идентификатор отгрузки в вашей системе. Если вы еще не передавали идентификатор, вернется идентификатор из параметра `id`.
  - `deliveryService` — object. Служба доставки.
    - `id` — integer<int64>. Идентификатор службы доставки.
    - `name` — string. Название службы доставки.
  - `palletsCount` — object. Данные о палетах в отгрузке.
    - `planned` — integer<int32>. Количество палет, которое заявил продавец.
    - `fact` — integer<int32>. Количество палет, которое приняли в сортировочном центре.
  - `orderIds` — array[integer<int64>] **обязательный**. Идентификаторы заказов в отгрузке.
  - `draftCount` — integer<int32> **обязательный**. Количество заказов, которое Маркет запланировал к отгрузке.
  - `plannedCount` — integer<int32> **обязательный**. Количество заказов, которое Маркет подтвердил к отгрузке.
  - `factCount` — integer<int32> **обязательный**. Количество заказов, принятых в сортировочном центре или пункте приема.
  - `signature` — object **обязательный**. Информация о подписи акта приема-передачи.
    - `signed` — boolean **обязательный**. Подписан ли акт приема-передачи.
  - `currentStatus` — object. Статус отгрузки.
    - `status` — string (OUTBOUND_CREATED, OUTBOUND_READY_FOR_CONFIRMATION, OUTBOUND_CONFIRMED, OUTBOUND_SIGNED, FINISHED, ACCEPTED, ACCEPTED_WITH_DISCREPANCIES, ERROR). Статус отгрузки.
    - `description` — string. Описание статуса отгрузки.
    - `updateTime` — string<date-time>. Время последнего изменения статуса отгрузки. Формат даты: ISO 8601 со смещением относительно UTC.
  - `availableActions` — array[string (CONFIRM, DOWNLOAD_ACT, DOWNLOAD_INBOUND_ACT, DOWNLOAD_DISCREPANCY_ACT, DOWNLOAD_TRANSPORTATION_WAYBILL, CHANGE_PALLETS_COUNT)] **обязательный**. Доступные действия над отгрузкой.
