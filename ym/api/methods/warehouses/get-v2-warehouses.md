# Идентификаторы фулфилмент-складов Маркета

`GET /v2/warehouses`

{% include notitle [access](../../_auto/method_scopes/getFulfillmentWarehouses.md) %}

Возвращает список фулфилмент-складов Маркета с их идентификаторами.

{% include notitle [limit](../../_auto/method_limits/getFulfillmentWarehouses.md) %}

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `campaignId` | query | integer<int64> | нет | Идентификатор кампании магазина. Указывается, если нужно вернуть все склады Маркета, которые привязаны к определенной кампании магазина. |

## Ответы

**200** — Список складов.

- `status` — string (OK, ERROR) **обязательный**. Тип ответа. Возможные значения: * `OK` — ошибок нет. * `ERROR` — при обработке запроса произошла ошибка.
- `result` — object. Список фулфилмент-складов Маркета.
  - `warehouses` — array[object] **обязательный**. Список фулфилмент-складов Маркета.
    - `id` — integer<int64> **обязательный**. Идентификатор склада.
    - `name` — string **обязательный**. Название склада.
    - `address` — object. Адрес склада.
      - `city` — string **обязательный**. Город.
      - `street` — string. Улица.
      - `number` — string. Номер дома.
      - `building` — string. Номер строения.
      - `block` — string. Номер корпуса.
      - `gps` — object **обязательный**. GPS-координаты широты и долготы.
        - `latitude` — number **обязательный**. Широта.
        - `longitude` — number **обязательный**. Долгота.
