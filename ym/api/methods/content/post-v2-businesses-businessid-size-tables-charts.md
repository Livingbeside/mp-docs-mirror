# Размерные сетки и обмеры для таблиц размеров

`POST /v2/businesses/{businessId}/size-tables/charts`

{% include notitle [access](../../_auto/method_scopes/getContentSizeCharts.md) %}

Возвращает размерные сетки и обмеры, из которых можно составить таблицу размеров для указанной размерной
характеристики. Их идентификаторы передаются в `sizeChartId` ячеек в методах создания и обновления таблиц
размеров `POST v2/businesses/{businessId}/size-tables/create` и `POST v2/businesses/{businessId}/size-tables/update`.

В список входят:

* стандартные размерные сетки Маркета — значения в них выбираются из справочника `sizeValues`;
* размерные сетки, значения в которых задаются текстом;
* обмеры — значения в них тоже задаются текстом.

Брендовые размерные сетки в список не входят, и использовать их в своих таблицах нельзя: для них
возвращается ошибка `UNKNOWN_SIZE_CHART`.

Обязательные размерные сетки отмечены `required: true`. В таблице должна быть хотя бы одна из них,
а каждую обязательную сетку в таблице нужно заполнить во всех строках.

Для неизвестного идентификатора размерной характеристики возвращается ошибка `UNKNOWN_SIZE_PARAMETER`.

## Запрос

**Тело запроса** (`application/json`):

- `sizeParameterId` — integer<int64> **обязательный**. Идентификатор размерной характеристики.

## Ответы

**200** — Размерные сетки и обмеры размерной характеристики.

- `status` — string (OK, ERROR) **обязательный**. Тип ответа. Возможные значения: * `OK` — ошибок нет. * `ERROR` — при обработке запроса произошла ошибка.
- `result` — object. Размерные сетки и обмеры размерной характеристики.
  - `sizeParameterId` — integer<int64> **обязательный**. Идентификатор размерной характеристики из запроса.
  - `sizeCharts` — array[object] **обязательный**. Размерные сетки и обмеры, которые можно использовать в таблицах размеров: сначала сетки, затем обмеры.
    - `sizeChartId` — integer<int64> **обязательный**. Идентификатор размерной сетки или обмера. Передавайте его в `sizeChartId` ячейки таблицы.
    - `sizeChartName` — string **обязательный**. Название размерной сетки или обмера.
    - `columnType` — string (SIZE_CHART, MEASUREMENT) **обязательный**. Тип колонки таблицы размеров: * `SIZE_CHART` — размерная сетка, по которой определяется размер товара. * `MEASUREMENT` — обмер, например обхват груди или длина стопы. В определении размера товара не участвует.
    - `required` — boolean **обязательный**. Обязательная ли размерная сетка. В таблице должна быть хотя бы одна обязательная сетка, а каждую обязательную сетку в таблице нужно заполнить во всех строках. У обмеров всегда `false`.
    - `sizeValues` — array[object] **обязательный**. Справочник значений размерной сетки. Заполнен только у стандартных размерных сеток Маркета: в ячейке такой колонки передавайте значение из справочника. Если список пустой, значение задается текстом.
      - `sizeValueId` — integer<int64> **обязательный**. Идентификатор значения. Передавайте его в `sizeValueId` ячейки таблицы.
      - `sizeValue` — string **обязательный**. Текст значения.
