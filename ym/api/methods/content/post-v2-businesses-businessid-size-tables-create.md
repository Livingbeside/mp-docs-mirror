# Создание таблиц размеров

`POST /v2/businesses/{businessId}/size-tables/create`

{% include notitle [access](../../_auto/method_scopes/createContentSizeTables.md) %}

Создает таблицы размеров бизнеса. За один запрос можно создать до 10 таблиц, в которых суммарно не больше
5000 ячеек. Если таблиц или ячеек больше, запрос отклоняется с ошибкой `BAD_REQUEST` и ни одна таблица
не создается.

Таблица относится к размерной характеристике, а не к категории: она подбирается для всех категорий
с той же размерной характеристикой.

Размерную характеристику категории возвращает метод подбора таблиц размеров
`POST v2/businesses/{businessId}/size-tables/suggest` в поле `result.sizeParameterId`, характеристику
существующей таблицы — метод `POST v2/businesses/{businessId}/size-tables` в поле `sizeParameterId`.
Если в запросе есть неизвестный идентификатор размерной характеристики, запрос отклоняется с ошибкой
`UNKNOWN_SIZE_PARAMETER` и ни одна таблица не создается.

Размерные сетки и обмеры, которые можно использовать в таблице, их значения и обязательные сетки
возвращает метод `POST v2/businesses/{businessId}/size-tables/charts`.

Чтобы привязать таблицу к товару, передайте ее идентификатор в `value` характеристики с `parameterId: 73979829`
в запросе [POST v2/businesses/{businessId}/offer-cards/update](../../reference/content/updateOfferContent.md).
Когда таблица изменяется, новое содержимое применяется к привязанным товарам автоматически.

{% note warning "Повторный запрос создает таблицы еще раз" %}

Метод не идемпотентен: каждый запрос создает новые таблицы, даже если такие же уже есть.

Если запрос завершился ошибкой с кодом 5xx, часть таблиц могла сохраниться. Получите таблицы бизнеса методом
`POST v2/businesses/{businessId}/size-tables` и только после этого повторите запрос для таблиц, которых там нет.

{% endnote %}

Количество таблиц у бизнеса ограничено — суммарно по всем размерным характеристикам. Удалить таблицу нельзя.
Если лимит исчерпан, таблица не создается и для нее возвращается ошибка `LIMIT_TABLES`. При одновременных
запросах лимит проверяется нестрого, и таблиц может создаться больше.

## Запрос

**Тело запроса** (`application/json`):

- `sizeTables` — array[object] **обязательный**. Таблицы размеров. Обрабатываются по порядку, каждая независимо от остальных. Суммарно во всех таблицах — не больше 5000 ячеек. Если ячеек больше, запрос не обрабатывается.
  - `sizeParameterId` — integer<int64> **обязательный**. Идентификатор размерной характеристики, к которой относятся размеры из таблицы.
  - `sizeTableName` — string **обязательный**. Название таблицы размеров. Пробелы в начале и в конце удаляются. Название из одних пробелов — ошибка `INVALID_REQUEST`.
  - `rows` — array[object] **обязательный**. Строки таблицы: каждая описывает один размер. При сохранении порядок строк может измениться.
    - `values` — array[object] **обязательный**. Ячейки строки в любом порядке. Каждая размерная сетка или обмер — не больше одного раза в строке, иначе вернется ошибка `INVALID_REQUEST`. Ячейку без значения можно не передавать или передать с пустым `sizeValue`: она сохранится как «нет значения». В обязательной размерной сетке это ошибка `EMPTY_CELL`.
      - `sizeChartId` — integer<int64>. Идентификатор размерной сетки или обмера из ответа метода `POST v2/businesses/{businessId}/size-tables/charts`. У сеток и обмеров общее пространство идентификаторов. Обязателен, если не передан `sizeChartName`.
      - `sizeChartName` — string. Название размерной сетки или обмера из ответа метода `POST v2/businesses/{businessId}/size-tables/charts`. Сравнивается без учета регистра и пробелов в начале и в конце. Обязательно, если не передан `sizeChartId`.
      - `sizeValueId` — integer<int64>. Идентификатор значения из справочника размерной сетки. Справочник есть только у стандартных размерных сеток Маркета.
      - `sizeValue` — string. Значение размера или обмера. В колонках без справочника — не длиннее 20 символов.

## Ответы

**200** — Результаты создания таблиц в порядке запроса. Если хотя бы одну таблицу не удалось создать, поле `status` принимает значение `ERROR`. Остальные таблицы при этом обрабатываются и сохраняются.

- `status` — string (OK, ERROR) **обязательный**. Тип ответа. Возможные значения: * `OK` — ошибок нет. * `ERROR` — при обработке запроса произошла ошибка.
- `result` — object. Результаты сохранения таблиц размеров.
  - `results` — array[object] **обязательный**. Результаты по таблицам из запроса в том же порядке: `results[i]` относится к `sizeTables[i]`.
    - `sizeTableId` — integer<int64>. Идентификатор сохраненной таблицы размеров.
    - `sizeTableName` — string. Название сохраненной таблицы размеров.
    - `errors` — array[object]. Ошибки, из-за которых таблица не сохранена. Сначала проверяются структура таблицы, ее колонки и значения ячеек — ошибки `INVALID_REQUEST`, `UNKNOWN_SIZE_CHART` и `INVALID_SIZE_VALUE`. Если они есть, остальные проверки не выполняются, поэтому после исправления могут вернуться другие ошибки.
      - `code` — string (INVALID_REQUEST, UNKNOWN_SIZE_CHART, INVALID_SIZE_VALUE, EMPTY_TABLE, EMPTY_CELL, NONE_COLUMN, DUPLICATE_ROWS, DUPLICATE_SIZES, DUPLICATE_MEASURES, ABSENT_MANDATORY_SIZE_CHART, LIMIT_TABLES, NOT_FOUND…) **обязательный**. Код ошибки сохранения таблицы размеров: * `INVALID_REQUEST` — нарушена структура таблицы: название из одних пробелов, ячейка без `sizeChartId` и `sizeChartName` (`rowIndex`), повтор колонки в строке, ячейка без `sizeValueId` и `sizeValue` или ячейка, в которой `sizeChartName` не совпадает с названием колонки `sizeChartId` (`rowIndex`, `sizeChartId`). * `UNKNOWN_SIZE_CHART` — размерных сеток или обмеров из `sizeChartIds` нет среди доступных для размерной характеристики таблицы, а названиям из `sizeChartNames` не нашлось ровно одной такой колонки. * `INVALID_SIZE_VALUE` — значение не подходит колонке (`rowIndex`, `sizeChartId`). * `EMPTY_TABLE` — в таблице нет ни одной ячейки. Для запросов, которые соответствуют схеме, не возвращается. Если в колонке только «нет значения», возвращается `NONE_COLUMN`. * `EMPTY_CELL` — не заполнена ячейка обязательной размерной сетки (`rowIndex`, `sizeChartId`). * `NONE_COLUMN` — в колонках из `sizeChartIds` нет ни одного значения, кроме «нет значения». * `DUPLICATE_ROWS` — строки из `rowIndices` совпадают. * `DUPLICATE_SIZES` — значения повторяются в размерных сетках из `sizeChartIds`. Зависит от размерной характеристики: для одних характеристик ошибка возвращается при повторах в любой сетке, для других — только если повторы есть во всех сетках таблицы. * `DUPLICATE_MEASURES` — значения повторяются в обмерах из `sizeChartIds`. Зависит от размерной характеристики: для некоторых характеристик повторы в обмерах допускаются. * `ABSENT_MANDATORY_SIZE_CHART` — в таблице нет обязательной размерной сетки. * `LIMIT_TABLES` — у бизнеса уже максимальное количество таблиц. Только при создании. * `NOT_FOUND` — таблицы нет. Только при обновлении. * `FORBIDDEN` — это таблица Маркета (`sizeTableType: STANDARD`), ее нельзя изменить. Только при обновлении. * `CONCURRENT_MODIFICATION` — таблицу изменили во время обработки запроса. Повторите запрос. Только при обновлении. * `INTERNAL_ERROR` — внутренняя ошибка, таблица не сохранена.
      - `rowIndex` — integer<int32>. Номер строки с ошибкой в `rows` запроса, начиная с 0. Может не совпадать с `rowIndex` сохраненной таблицы.
      - `sizeChartId` — integer<int64>. Идентификатор размерной сетки или обмера, в колонке которого ошибка.
      - `sizeChartIds` — array[integer<int64>]. Идентификаторы размерных сеток и обмеров, в колонках которых ошибка.
      - `sizeChartNames` — array[string]. Названия колонок из `sizeChartName` запроса, которым не нашлось ровно одной размерной сетки или обмера.
      - `rowIndices` — array[integer<int32>]. Номера совпадающих строк в `rows` запроса, начиная с 0.

**400** — Запрос содержит неправильные данные, ни одна таблица не создается.
