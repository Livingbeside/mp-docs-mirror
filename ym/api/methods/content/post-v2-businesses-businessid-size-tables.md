# Таблицы размеров по идентификаторам

`POST /v2/businesses/{businessId}/size-tables`

{% include notitle [access](../../_auto/method_scopes/getContentSizeTables.md) %}

Возвращает таблицы размеров по их идентификаторам. Идентификаторы возвращает метод
подбора таблиц размеров. Если `sizeTableIds` не передан, возвращает все таблицы размеров,
созданные бизнесом.

Сначала возвращаются созданные бизнесом, затем брендовые, затем стандартные таблицы;
внутри каждой группы — по убыванию идентификатора.

Результаты возвращаются постранично. Для навигации используйте параметры `pageToken` и `limit`.
В каждом следующем запросе передавайте тот же набор `sizeTableIds`, что и в первом:
`pageToken` привязан к нему, и с другим набором запрос будет отклонен. Порядок
идентификаторов значения не имеет.

Идентификаторы, по которым таблицу вернуть не удалось — такой таблицы нет или она
принадлежит другому бизнесу, — возвращаются в `notFoundSizeTableIds` на первой странице.

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `businessId` | path | integer<int64> | да | Идентификатор кабинета. {% if audience == "partner" %} Чтобы его узнать, воспользуйтесь запросом [GET v2/campaigns](../../reference/campaigns/getCampaigns.md). ℹ️ [Что такое кабинет и магазин на Маркете](https://yandex.ru/support/marketplace/account/introduction.html) {% endif %} |
| `pageToken` | query | string | нет | Идентификатор страницы c результатами. Если параметр не указан, возвращается первая страница. Передавайте значение выходного параметра `nextPageToken`, полученное при последнем запросе. |
| `limit` | query | integer<int32> | нет | — |

## Запрос

**Тело запроса** (`application/json`):

- `sizeTableIds` — array[integer<int64>]. Идентификаторы таблиц размеров. Если параметр не передан, возвращаются все таблицы, созданные бизнесом.

## Ответы

**200** — Таблицы размеров.

- `status` — string (OK, ERROR) **обязательный**. Тип ответа. Возможные значения: * `OK` — ошибок нет. * `ERROR` — при обработке запроса произошла ошибка.
- `result` — object. Таблицы размеров.
  - `sizeTables` — array[object] **обязательный**. Таблицы размеров: сначала созданные бизнесом, затем брендовые, затем стандартные; внутри каждой группы — по убыванию идентификатора.
    - `sizeTableId` — integer<int64> **обязательный**. Идентификатор таблицы размеров.
    - `sizeTableName` — string **обязательный**. Название таблицы размеров.
    - `sizeTableType` — string (CUSTOM, STANDARD) **обязательный**. Тип таблицы размеров: * `CUSTOM` — таблица, созданная бизнесом. * `STANDARD` — таблица Маркета: стандартная или подобранная под бренд.
    - `sizeParameterId` — integer<int64> **обязательный**. Идентификатор размерной характеристики, к которой относятся размеры из таблицы.
    - `editable` — boolean **обязательный**. Может ли бизнес редактировать таблицу: `true` — для таблиц, созданных бизнесом, `false` — для таблиц Маркета.
    - `key` — object. Условия подбора таблицы. Возвращаются, только если таблица подобрана по категории.
      - `categoryId` — integer<int64> **обязательный**. Идентификатор категории из запроса.
      - `vendorId` — integer<int64>. Идентификатор бренда на Маркете. Возвращается только для таблиц бренда.
      - `genderId` — integer<int64>. Идентификатор пола на Маркете.
    - `sizeCharts` — array[object] **обязательный**. Колонки таблицы: размерные сетки и обмеры. Колонки без значений не возвращаются.
      - `sizeChartId` — integer<int64> **обязательный**. Идентификатор размерной сетки или обмера. У сеток и обмеров общее пространство идентификаторов.
      - `sizeChartName` — string **обязательный**. Название размерной сетки или обмера.
      - `columnType` — string (SIZE_CHART, MEASUREMENT) **обязательный**. Тип колонки таблицы размеров: * `SIZE_CHART` — размерная сетка, по которой определяется размер товара. * `MEASUREMENT` — обмер, например обхват груди или длина стопы. В определении размера товара не участвует.
      - `sizes` — array[object] **обязательный**. Значения колонки в порядке строк таблицы. Пустые ячейки не возвращаются.
        - `sizeValueId` — integer<int64>. Идентификатор значения размера. Возвращается, только если у колонки есть справочник значений — это стандартные размерные сетки Маркета. В сетках, созданных бизнесом, брендовых сетках и обмерах значение задается только текстом.
        - `sizeValue` — string **обязательный**. Значение размера или обмера.
        - `rowIndex` — integer<int32> **обязательный**. Номер строки таблицы, начиная с 0. Значения с одинаковым `rowIndex` в разных колонках описывают один размер. Номера могут идти с пропусками, а порядок строк может не совпадать с порядком размеров. Собирайте строки по значению `rowIndex`, а не по позиции значения в `sizes`.
  - `notFoundSizeTableIds` — array[integer<int64>] **обязательный**. Идентификаторы из запроса, по которым таблицу вернуть не удалось: такой таблицы нет или она принадлежит другому бизнесу. Заполняется только на первой странице. На следующих страницах и в запросе без `sizeTableIds` список пустой.
  - `paging` — object **обязательный**. Идентификатор следующей страницы.
    - `nextPageToken` — string. Идентификатор следующей страницы результатов.
