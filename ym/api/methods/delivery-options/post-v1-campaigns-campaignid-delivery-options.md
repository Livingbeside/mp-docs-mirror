# Получение доступных вариантов доставки заказов

`POST /v1/campaigns/{campaignId}/delivery-options`

{% include notitle [access](../../_auto/method_scopes/getDeliveryOptions.md) %} Возвращает список вариантов для доставки заказов. Выберите подходящий вариант доставки из ответа и передайте его при создании заказа. Укажите `courierDelivery` для курьерской доставки или `pickupDelivery` для доставки в пункт выдачи. Не передавайте оба параметра одновременно. {% include notitle [limit](../../_auto/method_limits/getDeliveryOptions.md) %}

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `campaignId` | path | integer<int64> | да | Идентификатор кампании (магазина) — технический идентификатор, который представляет ваш магазин в системе Яндекс Маркета при работе через API. Он однозначно связывается с вашим магазином, но предназначен только для автоматизированного взаимодействия. Его можно узнать с помощью запроса [GET v2/campaigns](../../reference/campaigns/getCampaigns.md) или найти в кабинете продавца на Маркете. Нажмите на иконку вашего аккаунта → **Настройки** и в меню слева выберите **API и модули**: * блок **Идентификатор кампании**; * вкладка **Лог запросов** → выпадающий список в блоке **Показывать логи**. ⚠️ Не путайте его с: - идентификатором магазина, который отображается в личном кабинете продавца; - рекламными кампаниями. |

## Запрос

**Тело запроса** (`application/json`):

- `items` — array[object] **обязательный**. Товары на складах, для которых нужно вернуть варианты доставки. В рамках одного запроса все значения `offerId` должны быть уникальными. Не допускается передача двух объектов с одинаковым `offerId`.
  - `offerId` — string **обязательный**. Ваш SKU — идентификатор товара в вашей системе. Правила использования SKU: * У каждого товара SKU должен быть свой. * Уже заданный SKU нельзя освободить и использовать заново для другого товара. Каждый товар должен получать новый идентификатор, до того никогда не использовавшийся в вашем каталоге. SKU товара можно изменить в кабинете продавца на Маркете. О том, как это сделать, читайте [в Справке Маркета для продавцов](https://yandex.ru/support2/marketplace/ru/assortment/operations/edit-sku). {% note warning %} Пробельные символы в начале и конце значения автоматически удаляются. Например, `" SKU123 "` и `"SKU123"` будут обработаны как одинаковые значения. {% endnote %} [Что такое SKU и как его назначать](https://yandex.ru/support/marketplace/assortment/add/index.html#fields)
  - `count` — integer<int32> **обязательный**. Количество единиц товара.
  - `warehouseId` — integer<int64>. Идентификатор фулфилмент-склада Маркета. Передайте этот параметр, чтобы вернулись варианты доставки для указанного склада. Иначе Маркет сам выберет склад. [Как узнать остатки товаров на складах](../../reference/stocks/getStocks.md)
- `pickupDelivery` — object. Информация о доставке в пункт выдачи. Не передавайте вместе с `courierDelivery`.
  - `logisticPointsIds` — array[integer<int64>] **обязательный**. Идентификаторы пунктов выдачи.
- `courierDelivery` — object. Информация о курьерской доставке. Не передавайте вместе с `pickupDelivery`.
  - `fullAddress` — string **обязательный**. Полный адрес с точностью до номера дома.

## Ответы

**200** — Список доступных вариантов доставки с разных складов.

- `status` — string (OK, ERROR) **обязательный**. Тип ответа. Возможные значения: * `OK` — ошибок нет. * `ERROR` — при обработке запроса произошла ошибка.
- `result` — object. Список доступных вариантов для разных складов.
  - `warehousesDeliveryOptions` — array[object] **обязательный**. Варианты доставки для разных складов.
    - `warehouseId` — integer<int64> **обязательный**. Идентификатор фулфилмент-склада Маркета.
    - `deliveryOptions` — object **обязательный**. Варианты доставки.
      - `pickupDelivery` — object. Информация о доставке в пункт выдачи.
        - `pickupOptions` — array[object] **обязательный**. Информация о доставке в пункт выдачи.
          - `logisticPointId` — integer<int64> **обязательный**. Идентификатор пункта выдачи. Его можно узнать с помощью метода [POST v1/businesses/{businessId}/logistics-points](../../reference/logistic-points/getLogisticPoints.md).
          - `options` — array[object] **обязательный**. Варианты доставки в ПВЗ.
            - `deliveryDateInterval` — object **обязательный**. Интервал дат доставки.
            - `price` — object **обязательный**. Стоимость, которую магазин должен заплатить за доставку с выбранным вариантом.
      - `courierDelivery` — object. Информация о курьерской доставке.
        - `courierDeliveryOptions` — array[object] **обязательный**. Информация о курьерской доставке.
          - `deliveryDateInterval` — object **обязательный**. Интервал дат доставки.
            - `fromDate` — string<date> **обязательный**. Начало интервала. Формат даты: `ГГГГ-ММ-ДД`.
            - `toDate` — string<date> **обязательный**. Конец интервала. Формат даты: `ГГГГ-ММ-ДД`.
          - `deliveryTimeInterval` — object **обязательный**. Интервал времени доставки.
            - `fromTime` — string **обязательный**. Начало интервала. Формат: `ЧЧ:ММ`.
            - `toTime` — string **обязательный**. Конец интервала. Формат: `ЧЧ:ММ`.
          - `price` — object **обязательный**. Стоимость, которую магазин должен заплатить за доставку с выбранным вариантом.
            - `value` — number **обязательный**. Значение.
            - `currencyId` — string (RUR, USD, EUR, UAH, AUD, GBP, BYR, BYN, DKK, ISK, KZT, CAD…) **обязательный**. Валюта.
    - `items` — array[object] **обязательный**. Товары в заказе.
      - `offerId` — string **обязательный**. Ваш SKU — идентификатор товара в вашей системе. Правила использования SKU: * У каждого товара SKU должен быть свой. * Уже заданный SKU нельзя освободить и использовать заново для другого товара. Каждый товар должен получать новый идентификатор, до того никогда не использовавшийся в вашем каталоге. SKU товара можно изменить в кабинете продавца на Маркете. О том, как это сделать, читайте [в Справке Маркета для продавцов](https://yandex.ru/support2/marketplace/ru/assortment/operations/edit-sku). {% note warning %} Пробельные символы в начале и конце значения автоматически удаляются. Например, `" SKU123 "` и `"SKU123"` будут обработаны как одинаковые значения. {% endnote %} [Что такое SKU и как его назначать](https://yandex.ru/support/marketplace/assortment/add/index.html#fields)
      - `count` — integer<int32> **обязательный**. Количество единиц товара.
