# Привязка идентификаторов к товарам заказа

`POST /v1/fbs/order/{orderId}/identifier`

Пакетно привязывает идентификаторы к позициям заказа продавца.

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `orderId` | path | integer<int64> | да | Идентификатор заказа, для позиций которого привязываются идентификаторы. |

## Запрос

**Тело запроса** (`application/json`):

- `items` — array[object] **обязательный**. Список позиций заказа с привязываемыми идентификаторами. Не должен быть пустым; позиции не должны повторяться.
  - `orderItemId` — integer<int64> **обязательный**. Идентификатор позиции заказа.
  - `values` — array[string]. Список значений идентификаторов. Значения не должны повторяться.

## Ответы

**200** — Success

- `payload` — array[object]. Список информации об идентификаторах по позициям заказа.
  - `type` — string. Тип идентификатора (IMEI, ASL_BELGISI).
  - `required` — boolean. Обязателен ли идентификатор для данной позиции.
  - `values` — array[string]. Привязанные значения идентификаторов.
- `errors` — array[object]. Список ошибок.
  - `code` — string **обязательный**. Код ошибки, который может помочь в определении причины.
  - `message` — string **обязательный**. Сообщение об ошибке, предназначенное для отображения пользователю.
  - `detailMessage` — string. Более подробное сообщение об ошибке. Возможно, устарело и больше не используется.
  - `payload` — object. Дополнительные данные, связанные с ошибкой.
- `timestamp` — string<date-time>. Метка времени ответа.
- `trace` — string. Трассировочная информация для отладки.
- `error` — string. Описание ошибки, если она произошла.

**400** — Ошибки выполнения: - `seller-order-01`: заказ не найден; - `seller-order-02`: неподходящий статус заказа для привязки идентификатора; - `seller-order-05`: у позиции заказа не задан тип идентификатора; - `seller-order-06`: передано слишком много идентификаторов; - `seller-order-07`: невалидное значение идентификатора; - `seller-order-08`: идентификатор принадлежит другому SKU; - `seller-order-09`: не указан тип идентификатора; - `seller-order-10`: непредвиденная ошибка от WMS; - `seller-order-11`: сервис идентификаторов недоступен, повторите позже; - `seller-order-36`: позиция заказа не найдена.

- `payload` — object. Данные ответа, содержит информацию об объекте, возвращаемом сервисом.
- `errors` — array[object]. Список ошибок, если запрос не был успешно выполнен.
  - `code` — string **обязательный**. Код ошибки, который может помочь в определении причины.
  - `message` — string **обязательный**. Сообщение об ошибке, предназначенное для отображения пользователю.
  - `detailMessage` — string. Более подробное сообщение об ошибке. Возможно, устарело и больше не используется.
  - `payload` — object. Дополнительные данные, связанные с ошибкой.
- `timestamp` — string<date-time>. Время формирования ответа, формат даты и времени.
- `trace` — string. Трассировка для отладки ошибок.
- `error` — string. Сообщение об ошибке, если оно имеется.
