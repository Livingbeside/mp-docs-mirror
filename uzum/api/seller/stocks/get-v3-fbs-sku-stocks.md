# Получение остатков по SKU (постранично)

`GET /v3/fbs/sku/stocks`

Возвращает доступные для обновления остатки FBS и DBS SKU.
Поддерживает два режима постраничной выдачи:
page - по номеру страницы, выдача по убыванию skuId;
skuIdFrom - по курсору, выдача по возрастанию skuId.
Курсорный режим не зависит от глубины листания и рекомендуется для полного обхода каталога.
Одновременная передача page и skuIdFrom запрещена.

## Параметры

| Имя | Где | Тип | Обяз. | Описание |
|---|---|---|---|---|
| `page` | query | integer<int32> | нет | Номер страницы для постраничного просмотра остатков SKU (начиная с 0). Не сочетается с skuIdFrom. |
| `size` | query | integer<int32> | нет | Количество записей на странице (1-100). |
| `skuIdFrom` | query | integer<int64> | нет | Курсор: вернуть SKU со skuId строго больше указанного, для первой страницы 0. Включает курсорный режим, выдача идет по возрастанию skuId, page не применяется. Курсор следующей страницы - skuId последнего элемента ответа; обход завершен, когда вернулось меньше size записей. |
